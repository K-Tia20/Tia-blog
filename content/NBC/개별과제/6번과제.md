## 1. 프로젝트 생성 및 Rider 개발 환경 세팅

1. **언리얼 에디터 실행** → `Games` → `Blank` (빈 프로젝트) 선택
2. **설정**:
   - `C++` 선택
   - 프로젝트 이름: `BassBallGame` (또는 본인 프로젝트명)
   - `Create` 클릭
3. **JetBrains Rider 연결**:
   - 에디터 상단 메뉴 `Tools` → `Options` → `Source Code` → `Preferred Source Code Editor`를 **JetBrains Rider**로 설정
   - `Tools` → `Open in JetBrains Rider` 실행

#### `Public/BBPlayerState.h`

```cpp
// Fill out your copyright notice in the Description page of Project Settings.

#pragma once
#include "CoreMinimal.h"
#include "GameFramework/PlayerState.h"
#include "BBPlayerState.generated.h"

// 각 플레이어의 시도 횟수를 독립적으로 관리하고 서버-클라이언트 간 동기화하는 클래스
UCLASS()
class BASSBALLGAME_API ABBPlayerState : public APlayerState
{
	GENERATED_BODY()

public:
	ABBPlayerState();
	virtual void GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const override;

	// 시도 횟수 조작
	void AddTryCount();
	void ResetTryCount();

	// 시도 횟수 Getter
	UFUNCTION(BlueprintCallable, Category = "Baseball")
	int32 GetCurrentTryCount() const { return CurrentTryCount; }
	
	UFUNCTION(BlueprintCallable, Category = "Baseball")
	int32 GetMaxTryCount() const { return MaxTryCount; }

protected:
	// 서버에서 변경 시 클라이언트에 자동 동기화되는 현재 시도 횟수
	UPROPERTY(Replicated, VisibleAnywhere, BlueprintReadOnly)
	int32 CurrentTryCount;

	// 최대 시도 횟수 (기본값: 3회)
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)
	int32 MaxTryCount = 3;

public:
	// 이번 턴에 숫자를 제출했는지 여부
	bool bDidParticipateThisTurn = false;
};
```

### 2-3. BBGameMode

#### `Public/BBGameMode.h`
```cpp
// Fill out your copyright notice in the Description page of Project Settings.

#pragma once
#include "CoreMinimal.h"
#include "GameFramework/GameModeBase.h"
#include "BBGameMode.generated.h"

class ABBPlayerController;

// 숫자 야구 게임의 전체 규칙을 서버 측에서 제어하는 GameMode
UCLASS()
class BASSBALLGAME_API ABBGameMode : public AGameModeBase
{
	GENERATED_BODY()

public:
	ABBGameMode();
	virtual void BeginPlay() override;
	virtual void PostLogin(APlayerController* NewPlayer) override;
	virtual void Logout(AController* Exiting) override;

	// 플레이어의 입력을 받아 판정하는 핵심 함수
	void ProcessPlayerAnswer(ABBPlayerController* PC, const FString& Answer);

private:
	void GenerateRandomNumbers();                    // 정답 숫자 3자리 생성
	FString CheckInputError(const FString& Input);   // 입력 유효성 검사
	void ResetNumberBaseballGame();                  // 게임 초기화
	void PassTurn();                                 // 다음 플레이어에게 턴 넘기기
	void NotifySystemToAll(const FString& Message);  // 전체 플레이어에게 공지 전송
	void OnTurnTimerElapsed();                       // 1초마다 호출되는 타이머 콜백

public:
	TArray<int32> TargetNumbers;                     // 서버가 생성한 정답 배열

	UPROPERTY()
	TArray<ABBPlayerController*> AlivePlayers;       // 현재 접속 중인 플레이어 목록

	UPROPERTY()
	ABBPlayerController* CurrentTurnPlayer;          // 현재 턴인 플레이어

	int32 TurnRemainTime;                            // 현재 턴의 남은 시간 (초)
	int32 CurrentTurnPlayerIndex;                    // 현재 턴 플레이어의 배열 인덱스
	
	FTimerHandle TurnTimerHandle;                    // 매초 실행되는 턴 타이머
	FTimerHandle GameResetTimerHandle;               // 승리/무승부 후 3초 대기 타이머
	
	bool bIsGameOver = false;                        // 게임 종료 후 입력 차단 플래그
};
```

#### `Private/BBGameMode.cpp`
```cpp
// Fill out your copyright notice in the Description page of Project Settings.

#include "BBGameMode.h"
#include "BBPlayerController.h"
#include "BBPlayerState.h"

ABBGameMode::ABBGameMode()
{
	TurnRemainTime = 15;
	CurrentTurnPlayerIndex = 0;
}

void ABBGameMode::BeginPlay()
{
	Super::BeginPlay();
	ResetNumberBaseballGame();
	// 1초 간격으로 반복 실행되는 턴 타이머 시작
	GetWorld()->GetTimerManager().SetTimer(TurnTimerHandle, this, &ABBGameMode::OnTurnTimerElapsed, 1.0f, true);
}

// 플레이어 접속 시 목록에 추가하고, 첫 번째 접속자를 첫 턴으로 지정
void ABBGameMode::PostLogin(APlayerController* NewPlayer)
{
	Super::PostLogin(NewPlayer);
	ABBPlayerController* PC = Cast<ABBPlayerController>(NewPlayer);
	if (PC)
	{
		AlivePlayers.Add(PC);
		if (AlivePlayers.Num() == 1) CurrentTurnPlayer = PC;
	}
}

// 플레이어 퇴장 시 목록에서 제거
void ABBGameMode::Logout(AController* Exiting)
{
	Super::Logout(Exiting);
	if (ABBPlayerController* PC = Cast<ABBPlayerController>(Exiting)) AlivePlayers.Remove(PC);
}

// 매초 호출: 제한 시간 감소 및 UI 갱신, 시간 초과 시 기회 차감 후 턴 넘김
void ABBGameMode::OnTurnTimerElapsed()
{
	if (AlivePlayers.Num() == 0) return;
	TurnRemainTime--;
	FString TurnPlayerName = CurrentTurnPlayer ? CurrentTurnPlayer->GetName() : TEXT("없음");

	// 모든 플레이어에게 제한 시간과 현재 턴 정보를 전송
	for (ABBPlayerController* PC : AlivePlayers)
	{
		if (PC == CurrentTurnPlayer)
		{
			PC->ClientRPC_UpdateTime(TurnRemainTime);
			PC->ClientRPC_UpdateTurnPlayer(TEXT("현재 턴: 내 차례")); 
		}
		else if (PC)
		{
			PC->ClientRPC_UpdateTime(TurnRemainTime);
			PC->ClientRPC_UpdateTurnPlayer(FString::Printf(TEXT("현재 턴: %s 님"), *TurnPlayerName));
		}
	}

	// 시간 초과 시: 기회 1회 차감 후 무승부 판정, 아니면 턴 넘김
	if (TurnRemainTime <= 0)
	{
		if (CurrentTurnPlayer)
		{
			ABBPlayerState* PS = CurrentTurnPlayer->GetPlayerState<ABBPlayerState>();
			if (PS && PS->GetCurrentTryCount() < PS->GetMaxTryCount())
			{
				// 이번 턴에 숫자를 제출하지 않았을 때만 기회 차감
				if (!PS->bDidParticipateThisTurn)
				{
					PS->AddTryCount();
					NotifySystemToAll(FString::Printf(TEXT("시간 초과! %s 님의 기회가 차감되었습니다."), *TurnPlayerName));
				}
				// 기회 차감 후 전원 소진 여부 확인 (무승부 판정)
				bool bIsDraw = true;
				for (ABBPlayerController* AlivePC : AlivePlayers)
				{
					ABBPlayerState* AlivePS = AlivePC->GetPlayerState<ABBPlayerState>();
					if (AlivePS && AlivePS->GetCurrentTryCount() < AlivePS->GetMaxTryCount())
					{
						bIsDraw = false;
						break;
					}
				}

				if (bIsDraw)
				{
					bIsGameOver = true;
					GetWorld()->GetTimerManager().PauseTimer(TurnTimerHandle);
					NotifySystemToAll(TEXT("모든 플레이어가 기회를 소진했습니다. 무승부!"));
					GetWorld()->GetTimerManager().SetTimer(GameResetTimerHandle, this, &ABBGameMode::ResetNumberBaseballGame, 3.0f, false);
					return;
				}
			}
		}
		PassTurn();
	}
}

// 다음 플레이어에게 턴을 넘기고, 각 플레이어에게 개인화된 턴 안내 전송
void ABBGameMode::PassTurn()
{
	TurnRemainTime = 15;
	if (AlivePlayers.Num() > 0)
	{
		CurrentTurnPlayerIndex = (CurrentTurnPlayerIndex + 1) % AlivePlayers.Num();
		CurrentTurnPlayer = AlivePlayers[CurrentTurnPlayerIndex];
		
		// 다음 턴 플레이어의 참여 플래그 초기화
		ABBPlayerState* NextPS = CurrentTurnPlayer->GetPlayerState<ABBPlayerState>();
		if (NextPS) NextPS->bDidParticipateThisTurn = false;
		
		for (ABBPlayerController* PC : AlivePlayers)
		{
			if (PC == CurrentTurnPlayer)
			{
				PC->ClientRPC_UpdateSystemNotice(TEXT("당신의 턴입니다! 숫자를 입력하세요."));
			}
			else if (PC)
			{
				PC->ClientRPC_UpdateSystemNotice(FString::Printf(TEXT("다음 턴은 %s 님입니다."), *CurrentTurnPlayer->GetName()));
			}
		}
	}
}

// 전체 플레이어에게 동일한 시스템 공지를 전송
void ABBGameMode::NotifySystemToAll(const FString& Message)
{
	for (ABBPlayerController* PC : AlivePlayers)
	{
		if (PC) PC->ClientRPC_UpdateSystemNotice(Message);
	}
}

// 1~9 범위에서 중복 없는 3자리 정답 숫자를 랜덤 생성
void ABBGameMode::GenerateRandomNumbers()
{
	TargetNumbers.Empty();
	while (TargetNumbers.Num() < 3)
	{
		int32 RandomNum = FMath::RandRange(1, 9);
		if (!TargetNumbers.Contains(RandomNum)) TargetNumbers.Add(RandomNum);
	}
	UE_LOG(LogTemp, Warning, TEXT("서버 정답 생성: %d %d %d"), TargetNumbers[0], TargetNumbers[1], TargetNumbers[2]);
}

// 입력값 유효성 검사: 문제가 있으면 에러 문자열 반환, 정상이면 빈 문자열 반환
FString ABBGameMode::CheckInputError(const FString& Input)
{
	if (Input.Len() != 3) return TEXT("3자리 숫자를 입력해주세요.");
	
	TArray<int32> UsedNums;
	for (int32 i = 0; i < Input.Len(); ++i)
	{
		if (!FChar::IsDigit(Input[i])) return TEXT("문자가 포함되어 있습니다. 다시 입력하세요.");
		int32 Num = Input[i] - '0';
		if (Num == 0) return TEXT("1~9 사이의 숫자를 입력해주세요.");
		if (UsedNums.Contains(Num)) return TEXT("중복되지 않은 숫자를 입력해주세요.");
		UsedNums.Add(Num);
	}
	return TEXT("");
}

// 플레이어 입력을 받아 Strike/Ball 판정 후 승리/무승부/턴 넘김을 처리
void ABBGameMode::ProcessPlayerAnswer(ABBPlayerController* PC, const FString& Answer)
{
	if (!PC) return;

	// 게임 종료 후 3초 대기 중에는 입력 무시
	if (bIsGameOver) return;
	
	// 현재 턴이 아닌 플레이어의 입력 차단
	if (PC != CurrentTurnPlayer)
	{
		PC->ClientRPC_UpdateSystemNotice(TEXT("당신의 턴이 아닙니다. 대기하세요!"));
		return;
	}

	// 시도 횟수 초과 확인
	ABBPlayerState* PS = PC->GetPlayerState<ABBPlayerState>();
	if (!PS || PS->GetCurrentTryCount() >= PS->GetMaxTryCount())
	{
		PC->ClientRPC_UpdateSystemNotice(TEXT("기회를 모두 소진했습니다."));
		return;
	}

	// 입력값 유효성 검사 (통과 실패 시 기회 차감 없이 재입력 요청)
	FString ErrorMsg = CheckInputError(Answer);
	if (!ErrorMsg.IsEmpty())
	{
		PC->ClientRPC_UpdateSystemNotice(ErrorMsg);
		return; 
	}

	// 유효한 입력이므로 시도 횟수 1 증가
	PS->AddTryCount();
	PS->bDidParticipateThisTurn = true;  // 이번 턴에 참여함 표시
	int32 Strike = 0, Ball = 0;

	// Strike/Ball 판정
	for (int32 i = 0; i < 3; ++i)
	{
		int32 Num = Answer[i] - '0';
		if (Num == TargetNumbers[i]) Strike++;
		else if (TargetNumbers.Contains(Num)) Ball++;
	}

	// 3Strike 달성 시: 승리 처리 후 3초 뒤 게임 리셋
	if (Strike == 3)
	{
		bIsGameOver = true;
		GetWorld()->GetTimerManager().PauseTimer(TurnTimerHandle);
		NotifySystemToAll(FString::Printf(TEXT("%s 님이 3S0B로 승리하셨습니다!"), *PC->GetName()));
		PC->ClientRPC_UpdateResult(TEXT("3S0B 달성!")); 
		GetWorld()->GetTimerManager().SetTimer(GameResetTimerHandle, this, &ABBGameMode::ResetNumberBaseballGame, 3.0f, false);
		return;
	}

	// 판정 결과를 "[현재 시도 / 최대 시도] 결과" 형식으로 전송
	FString ResultStr = (Strike == 0 && Ball == 0) ? TEXT("OUT") : FString::Printf(TEXT("%dS%dB"), Strike, Ball);
	PC->ClientRPC_UpdateResult(FString::Printf(TEXT("[%d / %d] %s"), PS->GetCurrentTryCount(), PS->GetMaxTryCount(), *ResultStr));
	
	// 모든 플레이어의 기회 소진 여부를 확인하여 무승부 판정
	bool bIsDraw = true;
	for (ABBPlayerController* AlivePC : AlivePlayers)
	{
		ABBPlayerState* AlivePS = AlivePC->GetPlayerState<ABBPlayerState>();
		if (AlivePS && AlivePS->GetCurrentTryCount() < AlivePS->GetMaxTryCount())
		{
			bIsDraw = false;
			break;
		}
	}

	// 무승부 시: 3초 뒤 게임 리셋 / 아닐 시: 다음 턴으로 넘김
	if (bIsDraw)
	{
		bIsGameOver = true;
		GetWorld()->GetTimerManager().PauseTimer(TurnTimerHandle);
		NotifySystemToAll(TEXT("모든 플레이어가 기회를 소진했습니다. 무승부!"));
		GetWorld()->GetTimerManager().SetTimer(GameResetTimerHandle, this, &ABBGameMode::ResetNumberBaseballGame, 3.0f, false);
	}
	else 
	{
		PassTurn();
	}
}

// 게임 상태 초기화: 새 정답 생성, 시도 횟수 리셋, 결과창 비우기, 타이머 재개
void ABBGameMode::ResetNumberBaseballGame()
{
	bIsGameOver = false;
	GenerateRandomNumbers();
	TurnRemainTime = 15;
	CurrentTurnPlayerIndex = 0;
	if (AlivePlayers.Num() > 0) CurrentTurnPlayer = AlivePlayers[0];

	// 모든 플레이어의 시도 횟수 초기화 및 이전 결과 텍스트 제거
	for (ABBPlayerController* PC : AlivePlayers)
	{
		if (ABBPlayerState* PS = PC->GetPlayerState<ABBPlayerState>()) 
		{
			PS->ResetTryCount();
		}
		if (PC)
		{
			PC->ClientRPC_UpdateResult(TEXT("")); 
		}
	}
		
	// 본인에게는 "당신의 턴", 상대에게는 "OO님의 턴"으로 개인화된 안내 전송
	if (CurrentTurnPlayer)
	{
		for (ABBPlayerController* PC : AlivePlayers)
		{
			if (PC == CurrentTurnPlayer)
			{
				PC->ClientRPC_UpdateSystemNotice(TEXT("새 게임 시작! 지금 당신의 턴입니다."));
			}
			else if (PC)
			{
				PC->ClientRPC_UpdateSystemNotice(FString::Printf(TEXT("새 게임 시작! 첫 턴은 %s 님입니다."), *CurrentTurnPlayer->GetName()));
			}
		}
	}

	// 일시정지했던 턴 타이머 재개
	GetWorld()->GetTimerManager().UnPauseTimer(TurnTimerHandle);
}
```

### 5-2. BP_PlayerController 그래프 (UI 띄우기 & 4종 RPC 받기)

`BP_PlayerController` 블루프린트 그래프를 엽니다.

#### 1) Event BeginPlay (위젯 띄우기 & 커서 고정)
```
Event BeginPlay
  └─▶ Branch (Condition: Is Local Player Controller)
        └─▶ [True] Create Widget (Class: WBP_Baseball)
              └─▶ Return Value 우클릭 -> Promote to Variable (이름: MyUI)
                    └─▶ Add to Viewport (Target: MyUI)
                          └─▶ Set Input Mode UI Only (In Widget to Focus: MyUI, Player Controller: Self)
                                └─▶ Set Show Mouse Cursor (Show Mouse Cursor: True, Target: Self)
```

#### 2) 4개의 RPC 이벤트 (Accessed None 방지 적용)

> ⚠️ `MyUI` 변수를 가져올 때 우클릭하여 **`Convert to Validated Get`**을 적용하고, 반드시 **`Is Valid`** 핀에서 실행 선을 연결해야 합니다.

```
1. 제한 시간 업데이트
Event On Update Time 
  └─▶ MyUI (Validated Get) 
        └─▶ [Is Valid] Set Text (Text) [Target: TimerText / In Text: Remain Time]

2. 턴 플레이어 업데이트
Event On Update Turn Player 
  └─▶ MyUI (Validated Get) 
        └─▶ [Is Valid] Set Text (Text) [Target: TurnPlayerText / In Text: Turn Player Name]

3. S/B 결과 업데이트
Event On Update Result 
  └─▶ MyUI (Validated Get) 
        └─▶ [Is Valid] Set Text (Text) [Target: ResultText / In Text: Result Msg]

4. 시스템 공지 업데이트
Event On Update System Notice 
  └─▶ MyUI (Validated Get) 
        └─▶ [Is Valid] Set Text (Text) [Target: SystemNoticeText / In Text: Notice Msg]
```

## 6. 핵심 트러블슈팅 & 버그 해결 모음

| 트러블슈팅 이슈 | 원인 | 해결 방법 |
|---|---|---|
| **C2061: `ABBPlayerController` undeclared identifier** | `BBGameMode.h`에서 `ABBPlayerController` 선언을 모름 | `BBGameMode.h` 상단 `UCLASS()` 바로 위에 `class ABBPlayerController;` (전방 선언) 추가 |
| **Only Local Player Controllers can be assigned to widgets** | 서버 측 PlayerController 복제본에서 Create Widget 시도 | `Event BeginPlay` 시 `Is Local Player Controller` 노드로 분기하여 Local일 때만 위젯 생성 |
| **Accessed None... property MyUI** | 서버가 타이머 RPC를 쏘는데 클라이언트의 위젯 생성이 찰나 더 늦어 UI가 비어있음 | `MyUI` 변수를 `Validated Get`으로 전환하고 `Is Valid` 일 때만 `Set Text` 수행 |
| **마우스 클릭 시 커서 사라짐** | 허공 클릭 시 엔진이 Input Mode를 Game으로 가로챔 | `Add to Viewport` 직후 `Set Input Mode UI Only` 및 `Set Show Mouse Cursor (true)` 호출 |
| **승리 메시지 0.001초만에 사라짐** | `ResetNumberBaseballGame()` 내 공지 텍스트가 승리 텍스트를 즉시 덮어씀 | 승리 시 타이머를 `PauseTimer` 하고 `bIsGameOver = true` 지정 후 3초 디레이 타이머 실행 |
| **시간 초과 시 무한 루프 / 이중 기회 차감** | 시간 초과 후 무승부 체크 누락 및 한 턴에 중복 차감 발생 | `bDidParticipateThisTurn` 플래그로 미참여자만 기회 차감 후 즉시 무승부 조건 검사 |
