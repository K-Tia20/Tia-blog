# 🎮 언리얼 엔진 모듈 및 플러그인 구축 종합 가이드 (Rider 기준)

이 문서는 언리얼 엔진에서 프로젝트의 기본 단위인 **모듈(Module)**과 확장 가능한 패키지인 **플러그인(Plugin)**을 직접 구축하고, 서로 상호작용하도록 연결하는 전체 과정을 담은 완벽한 가이드입니다. 

**JetBrains Rider IDE** 환경을 기준으로 작성되었으며, 문서에 포함된 코드를 복사해서 붙여넣고 순서대로 따라오시면 누구나 맨 처음부터 끝까지 막힘없이 진행하실 수 있습니다.

---

## 🎯 학습 목표
- **프로젝트 구조 파악:** Config, Content, Source를 넘어 Plugins 폴더의 역할 이해
- **모듈(Module)의 개념:** 언리얼 엔진의 최소 단위, 레고 블록처럼 조립할 수 있는 특성 파악 (DLL과 유사)
- **플러그인(Plugin)의 특징:** 독자적 빌드는 불가능하지만 재사용이 가능한 독립 패키지의 이해
- **언리얼의 관리 계층 구조:** `프로젝트/플러그인` > `모듈` > `소스코드`

---

## 1단계 : 새 프로젝트 만들기
가장 먼저 실습을 진행할 베이스 프로젝트를 생성합니다.

1. 언리얼 엔진 에디터를 실행합니다.
2. **Games** 카테고리에서 **Third Person (3인칭)** 템플릿을 선택합니다.
3. 프로젝트 설정은 **C++**, **Scalable(확장 가능)**로 설정합니다.
4. 프로젝트 이름은 **`ModuleAndPlugin`**으로 지정하고 생성합니다.

> [!NOTE]
> **블루프린트 프로젝트 VS C++ 프로젝트**
> 블루프린트 프로젝트는 C++ 코드를 작성하지 않습니다. 우리가 직접 모듈을 추가하고 임포트하려면 반드시 **C++ 프로젝트**로 생성해야 합니다.

## 2단계 : 새로운 모듈(Test) 생성 및 설정
언리얼 엔진의 기본 단위인 모듈을 프로젝트 소스 폴더에 직접 수동으로 만들어 봅니다.

> [!WARNING]  
> 2단계와 3단계 작업은 언리얼 에디터나 **Rider**를 모두 종료한 상태에서 윈도우 탐색기(File Explorer)를 통해 진행하시는 것이 가장 안전합니다.

### 2.1 폴더 및 파일 생성
1. 프로젝트 루트 폴더 안의 `Source` 폴더로 이동합니다.
2. 우클릭하여 **새 폴더**를 만들고 이름을 `Test`로 지정합니다.
3. `Test` 폴더 안에서 우클릭하여 3개의 **새 텍스트 문서**를 만들고, 이름을 다음과 같이 정확히 변경합니다. (파일 확장명이 보이도록 윈도우 탐색기 설정이 되어있어야 합니다.)
   - `Test.Build.cs`
   - `Test.h`
   - `Test.cpp`

### 2.2 코드 작성
메모장이나 텍스트 에디터를 열고 아래 코드들을 각각 복사해서 붙여넣은 뒤 저장합니다.

**`Test.Build.cs`** (모듈의 종속성을 정의합니다)
```csharp
using UnrealBuildTool;

public class Test : ModuleRules
{
    public Test(ReadOnlyTargetRules Target) : base(Target)
    {
        PCHUsage = PCHUsageMode.UseExplicitOrSharedPCHs;

        // 필수 모듈들을 여기에 추가합니다.
        PublicDependencyModuleNames.AddRange(new string[] { "Core", "CoreUObject", "Engine", "InputCore" });
    }
}
```

**`Test.h`** (모듈의 헤더입니다)
```cpp
#pragma once

#include "CoreMinimal.h"
#include "Modules/ModuleManager.h"
```

**`Test.cpp`** (모듈의 구현부이자 매크로 선언부입니다)
```cpp
#include "Test.h"

// 일반 모듈(게임 모듈)로 사용할 때 사용하는 기본 매크로입니다.
IMPLEMENT_MODULE(FDefaultModuleImpl, Test);
```

## 3단계 : 모듈 연결 및 빌드 대상 등록
만든 모듈을 기존 메인 프로젝트(`ModuleAndPlugin`)와 연결하여 빌드 프로세스에 포함시킵니다.

### 3.1 Target.cs 파일 수정
`Source` 폴더 바로 아래에 있는 2개의 Target.cs 파일을 엽니다. `ExtraModuleNames`에 방금 만든 `"Test"` 모듈을 추가합니다. 

> [!CAUTION]
> C#의 `Add()` 함수는 인자를 1개만 받습니다. `Add("A", "B")` 형태로 쓰면 오류가 발생하므로, 아래와 같이 두 번 쓰거나 `AddRange()`를 사용해야 합니다.

**`ModuleAndPlugin.Target.cs`** (기존 코드에 아래 내용 반영)
```csharp
// ... 
        IncludeOrderVersion = EngineIncludeOrderVersion.Unreal5_3; 
        
        ExtraModuleNames.Add("ModuleAndPlugin");
        ExtraModuleNames.Add("Test"); // 이 줄을 추가합니다!
// ...
```

**`ModuleAndPluginEditor.Target.cs`** (기존 코드에 아래 내용 반영)
```csharp
// ...
        IncludeOrderVersion = EngineIncludeOrderVersion.Unreal5_3;
        
        ExtraModuleNames.Add("ModuleAndPlugin");
        ExtraModuleNames.Add("Test"); // 이 줄을 추가합니다!
// ...
```

### 3.2 .uproject 파일 갱신 (가장 중요)
프로젝트 루트 폴더의 `ModuleAndPlugin.uproject` 파일을 텍스트 에디터로 엽니다.
`"Modules"` 배열 항목에 `"Test"` 모듈 정보를 추가합니다. 

> [!IMPORTANT]
> Test 모듈의 `"LoadingPhase"`는 반드시 **`"PreDefault"`**로 설정해야 합니다.

**`ModuleAndPlugin.uproject` 예시**
```json
	"Modules": [
		{
			"Name": "ModuleAndPlugin",
			"Type": "Runtime",
			"LoadingPhase": "Default"
		},
		{
			"Name": "Test",
			"Type": "Runtime",
			"LoadingPhase": "PreDefault"
		}
	],
```

### 3.3 프로젝트 재생성
모든 파일을 저장한 뒤, 윈도우 탐색기에서 `ModuleAndPlugin.uproject` 파일을 우클릭하고 엔진 설정에 따라 **[Generate Visual Studio project files]** 또는 **[Generate Rider project files]**를 실행합니다.

## 4단계 : 모듈 간 상호작용 구현 (TestActor)
기본 모듈이 새로 만든 Test 모듈의 액터를 월드에 소환해보는 실습입니다. 

### 4.1 메인 모듈의 종속성(Dependency) 추가
서로 다른 모듈의 코드를 사용하려면 상대방 모듈을 내 Build.cs에 허락받아야 합니다.
`Source/ModuleAndPlugin/ModuleAndPlugin.Build.cs` 파일을 엽니다. `PublicDependencyModuleNames` 목록 끝에 **`"Test"`**를 추가합니다.

**`ModuleAndPlugin.Build.cs`**
```csharp
// 끝에 "Test"를 추가합니다.
PublicDependencyModuleNames.AddRange(new string[] { "Core", "CoreUObject", "Engine", "InputCore", "EnhancedInput", "Test" });
```

### 4.2 Test 모듈에 TestActor 생성
1. `.uproject`를 실행하여 언리얼 에디터를 엽니다. (빌드 여부를 물어보면 **Yes** 클릭)
2. 상단 메뉴에서 **도구(Tools) -> 새로운 C++ 클래스(New C++ Class)** 클릭
3. 부모 클래스로 **Actor** 선택 후 다음 클릭
4. 이름은 **`TestActor`**로 지정하고, 이름 옆 우측의 **모듈 선택 드롭다운**을 눌러 반드시 **`Test`**로 변경 후 생성합니다.

### 4.3 TestActor.cpp 로그 작성
Rider에서 방금 생성된 `TestActor.cpp`의 `BeginPlay()`에 로그를 띄우는 코드를 작성합니다.

**`TestActor.cpp`**
```cpp
void ATestActor::BeginPlay()
{
	Super::BeginPlay();

	// 로그 출력 코드 추가
	UE_LOG(LogTemp, Warning, TEXT("Test 모듈의 TestActor가 성공적으로 스폰되었습니다!"));
}
```

### 4.4 메인 캐릭터에 BeginPlay 선언 및 스폰
최신 3인칭 템플릿의 캐릭터(`ModuleAndPluginCharacter`)에는 `BeginPlay`가 기본적으로 없으므로, 헤더와 cpp에 직접 추가해주어야 합니다.

**`ModuleAndPluginCharacter.h`**
```cpp
protected:

	// 아무 곳(주로 protected 섹션)에 BeginPlay 함수를 선언합니다.
	virtual void BeginPlay() override;
```

**`ModuleAndPluginCharacter.cpp`**
```cpp
// 맨 위 헤더 선언부에 TestActor를 포함시킵니다.
#include "TestActor.h"

// ... 

// 맨 아래에 BeginPlay 구현부를 작성합니다.
void AModuleAndPluginCharacter::BeginPlay()
{
	Super::BeginPlay();

	// TestActor를 월드에 스폰시킵니다!
	if (UWorld* World = GetWorld())
	{
		World->SpawnActor<ATestActor>();
	}
}
```
저장 후 **Rider에서 빌드 (상단의 🔨망치 아이콘 클릭 또는 `Ctrl + Shift + B`)**하고 언리얼 에디터에서 플레이(Play)를 눌러 출력 로그(Output Log)에 스폰 성공 메시지가 뜨는지 확인합니다!

## 5단계 : 독립 플러그인(Temporary) 구축
프로젝트에 종속되지 않는 독립적인 플러그인을 직접 폴더부터 만들어 봅니다.

### 5.1 플러그인 기본 폴더 및 명세서 생성
1. 프로젝트 루트(`ModuleAndPlugin`)에 **`Plugins`** 폴더를 만들고, 그 안에 **`Temporary`** 폴더를 만듭니다.
2. `Temporary` 폴더 안에 **`Content`**, **`Source`** 폴더와 **`Temporary.uplugin`** 파일을 생성합니다.

**`Temporary.uplugin`**
```json
{
	"FileVersion": 3,
	"Version": 1,
	"VersionName": "1.0",
	"FriendlyName": "Temporary Plugin",
	"Description": "My First Temporary Plugin",
	"Category": "Other",
	"CreatedBy": "Me",
	"CreatedByURL": "",
	"DocsURL": "",
	"MarketplaceURL": "",
	"SupportURL": "",
	"CanContainContent": true,
	"IsBetaVersion": false,
	"IsExperimentalVersion": false,
	"Installed": false,
	"Modules": [
		{
			"Name": "Temporary",
			"Type": "Runtime",
			"LoadingPhase": "Default"
		}
	]
}
```

### 5.2 플러그인 모듈 구성
1. `Plugins/Temporary/Source/` 안에 **`Temporary`** 폴더를 만듭니다.
2. 그 안에 3개의 파일을 생성합니다: `Temporary.Build.cs`, `Temporary.h`, `Temporary.cpp`

**`Temporary.Build.cs`**
```csharp
using UnrealBuildTool;

public class Temporary : ModuleRules
{
    public Temporary(ReadOnlyTargetRules Target) : base(Target)
    {
        PCHUsage = ModuleRules.PCHUsageMode.UseExplicitOrSharedPCHs;
        PublicDependencyModuleNames.AddRange(new string[] { "Core", "CoreUObject", "Engine", "InputCore" });
    }
}
```

**`Temporary.h`**
```cpp
#pragma once

#include "CoreMinimal.h"
#include "Modules/ModuleManager.h"

class FTemporaryModule : public IModuleInterface
{
public:
	virtual void StartupModule() override;
	virtual void ShutdownModule() override;
};
```

**`Temporary.cpp`**
```cpp
#include "Temporary.h"

#define LOCTEXT_NAMESPACE "FTemporaryModule"

void FTemporaryModule::StartupModule()
{
	UE_LOG(LogTemp, Warning, TEXT("Temporary 플러그인이 로드되었습니다!"));
}

void FTemporaryModule::ShutdownModule()
{
}

#undef LOCTEXT_NAMESPACE
	
IMPLEMENT_MODULE(FTemporaryModule, Temporary)
```

## 6단계 : 플러그인 최종 연결 및 검증
만들어둔 플러그인을 프로젝트에 켜주고(Enable) 확인합니다.

1. 프로젝트 루트의 **`ModuleAndPlugin.uproject`**를 열고 `"Plugins"` 목록에 추가합니다.
```json
	"Plugins": [
		{
			"Name": "ModelingToolsEditorMode",
			"Enabled": true,
			"TargetAllowList": [
				"Editor"
			]
		},
		{
			"Name": "Temporary",
			"Enabled": true
		}
	]
```
2. `.uproject` 파일을 우클릭하여 프로젝트 파일을 다시 생성(Generate)합니다.
3. 에디터를 열고 하단 콘텐츠 브라우저의 우측 상단 톱니바퀴(Settings)에서 **[플러그인 콘텐츠 표시(Show Plugin Content)]**를 체크합니다.
4. 좌측 폴더 트리에 **`Temporary`** 폴더가 나타나면 완벽히 성공입니다!

## 7단계 (도전 과제) : 순수 데이터 클래스(UObject) 활용
액터가 아닌 데이터 저장용 객체(`UObject`)를 생성하고, 메인 캐릭터에서 이 데이터를 읽어 화면에 출력해 봅니다.

### 7.1 UObject 클래스 생성하기 (언리얼 에디터)
1. 언리얼 에디터 상단 메뉴에서 **도구(Tools) -> 새로운 C++ 클래스** 클릭
2. 부모 클래스 선택 창 위쪽의 **[모든 클래스 (All Classes)]** 탭 클릭
3. 검색창에 **`Object`**를 검색하여 상속 트리가 비어있는 순수 `Object` 선택 후 다음 클릭
4. 클래스 이름: **`CharacterData`**
5. 모듈 선택: **`Test`** 모듈로 변경 후 생성

### 7.2 CharacterData 변수 및 초기값 설정
**`CharacterData.h`**
```cpp
#pragma once

#include "CoreMinimal.h"
#include "UObject/NoExportTypes.h"
#include "CharacterData.generated.h"

UCLASS()
class TEST_API UCharacterData : public UObject
{
	GENERATED_BODY()
	
public:
	UCharacterData();

	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Data")
	int32 MaxHP;

	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Data")
	int32 MaxMP;
	
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Data")
	float MoveSpeed;
};
```

**`CharacterData.cpp`**
```cpp
#include "CharacterData.h"

UCharacterData::UCharacterData()
{
	MaxHP = 1000;
	MaxMP = 500;
	MoveSpeed = 600.0f;
}
```

### 7.3 메인 캐릭터에서 데이터 읽고 출력하기
다시 `ModuleAndPluginCharacter.cpp` 파일을 열어 `BeginPlay()` 함수를 완성합니다.

**`ModuleAndPluginCharacter.cpp`**
```cpp
// 기존 #include "TestActor.h" 아래에 추가합니다.
#include "CharacterData.h"

// ...

void AModuleAndPluginCharacter::BeginPlay()
{
	Super::BeginPlay();

	if (UWorld* World = GetWorld())
	{
		World->SpawnActor<ATestActor>();
	}

	// === 도전 과제 코드 ===
	// 1. UObject는 SpawnActor가 아니라 NewObject로 생성합니다.
	UCharacterData* MyData = NewObject<UCharacterData>();

	// 2. 객체가 정상 생성되었다면 값을 읽어 화면에 출력합니다.
	if (MyData != nullptr && GEngine)
	{
		FString Message = FString::Printf(TEXT("캐릭터 데이터 로드 성공! 체력: %d, 마나: %d"), MyData->MaxHP, MyData->MaxMP);
		
		// 화면 좌상단에 청록색(Cyan)으로 10초 동안 띄웁니다.
		GEngine->AddOnScreenDebugMessage(-1, 10.0f, FColor::Cyan, Message);
	}
}
```

모두 완료 후 **Rider에서 빌드**하고 언리얼 에디터에서 플레이(Play)를 클릭하면, 좌측 상단에 푸른 글씨로 체력과 마나 정보가 뜨는 것을 확인할 수 있습니다.
