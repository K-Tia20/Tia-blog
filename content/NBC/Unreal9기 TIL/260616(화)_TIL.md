- 몬스터가 죽지도 않았는데 4~5초 뒤에 사라지는 현상 발생
- Behavior Tree와 BlackBoard 설정 과정에서 bIsDead 키가 보이지 않음

### 원인

문제의 원인은 BlackBoard에 bIsDead 키를 추가하지 않았기 때문이었다.
1. BlackBoard 에셋을 열어 Key 추가
2. Key 이름을 bIsDead로 설정
3. 타입을 Bool로 지정
![[Pasted image 20260616205040.png|330]]
이후 Behavior Tree의 Decorator에서 정상적으로 bIsDead를 선택할 수 있었다.

![[Pasted image 20260616210630.png]]

---
1. Behavior Tree에서 사용하는 모든 Key는 반드시 BlackBoard에 먼저 등록되어 있어야 한다.
2. AI 문제는 "Behavior Tree 실행 → BlackBoard 값 → Task 실행" 순서로 확인하면 원인 찾기가 쉽다.
3. 언리얼 AI는 설정이 연결되지 않으면 에러 메시지 없이 동작하지 않는 경우가 많아, 디버깅과 로그 확인이 중요하다.
### 해결

###### 1. 몬스터가 멋대로 사라지는 문제 해결
BlackBoard와 Behavior Tree 설정을 올바르게 하니, 몬스터가 죽었을 때만 사망 시퀀스가 실행되도록 수정되었다.
##### 2. 추가로 발견한 문제
몬스터가 이제는 사라지지 않지만 공격을 하지 않는 문제가 남아 있다.
