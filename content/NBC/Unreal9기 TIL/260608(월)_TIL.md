### 문제

pawn은 정상적으로 생성되지만
Move, Look 입력이 동작하지 않음
### 오류

게임 실행 시 캐릭터 이동 및 시점 회전이 동작하지 않았다.
코드에는 문제가 없어 보였지만 입력이 바인딩되지 않은 상태였다.
### 원인
C++ 클래스 `BasePawn`을 기반으로 생성한 블루프린트 `MyBasePawn`의 Input 관련 변수들이 비어 있었다.

### 해결
![[Pasted image 20260608195302.png]]
`MyBasePawn` 블루프린트의 Self(Input) 항목에 다음 에셋들을 연결했다.

- IMC_Default
- IA_Move
- IA_Look
- IA_UpDown

설정 후 Enhanced Input Mapping Context와 Input Action이 정상적으로 등록되어 입력이 동작.
- C++ 코드만 작성했다고 입력이 자동으로 연결되는 것은 아니다.
- `UPROPERTY(EditAnywhere)`로 노출한 Input 관련 변수는 블루프린트에서 직접 설정해야 한다.
- 입력이 동작하지 않을 때는 코드뿐 아니라 블루프린트 에셋 연결 여부도 확인해야 한다.
