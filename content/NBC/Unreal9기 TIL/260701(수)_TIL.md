- 파일 구조 정리 중
```
Source/YourProject/  
├── UI/ # UI 핵심 로직 (C++ 클래스)  
│ ├── Base/ # UI 관리 및 공통 기반 클래스  
│ │ ├── MyHUD.h / .cpp # 게임 시작 시 최상위 HUD를 띄우고 관리하는 총괄 클래스  
│ │ ├── GameUserSetting.h / .cpp # (선택) 사운드 및 UI 크기 설정을 디스크에 세이브/로드하는  
│ │ └── DamageTextActor.h / .cpp # 데미지 숫자를 3D 월드에 배치하기 위한 액터 그릇  
│ │  
│ ├── InGame/ # 실제 인게임 전투 중에 사용되는 UI  
│ │ ├── HUDWidget.h / .cpp # 인게임 UI의 최상위 도화지 (아래 자식들을 포함)  
│ │ ├── CrosshairWidget.h / .cpp # 조준점, 히트마커, 킬 확정 연출  
│ │ ├── WaveWidget.h / .cpp # 현재 레벨/웨이브 정보, 제한 시간 타이머  
│ │ ├── KillLogWidget.h / .cpp # 피해 및 적 처치 로그 시스템  
│ │ ├── BossHPWidget.h / .cpp # 보스전 돌입 시 상단에 나타날 체력바  
│ │ └── DamageTextWidget.h / .cpp# 몬스터 머리 위? 에 뜰 데미지 수치 텍스트

│ │ └── EnemyHPWidget.h / .cpp # 쫄몹 머리 위에 '둥둥 떠다니는' 월드 공간 체력바  
│ │  
│ └── Menus/ # 마우스 커서가 활성화되는 팝업 및 메뉴 UI  
│ ├── MainMenuWidget.h / .cpp # 게임 오프닝 이후 진입하는 메인 메뉴  
│ ├── SettingWidget.h / .cpp # 소리 조절(BGM/SFX), UI 크기 조절 옵션창  
│ ├── PauseWidget.h / .cpp # 게임 중 ESC 누르면 나오는 일시정지 창  
│ ├── LoadingWidget.h / .cpp # 레벨 넘어갈 때 띄울 로딩 화면  
│ ├── OpeningWidget.h / .cpp # 게임 인트로 시네마틱 연출용 위젯  
│ ├── GameOverWidget.h / .cpp # 시간 초과 및 플레이어 사망 시 화면  
│ ├── GameClearWidget.h / .cpp # 4레벨 보스 처치 후 클리어 화면  
│ └── CreditWidget.h / .cpp # 개발자 이름 및 에셋 라이센스 화면  
│  
└── Sound/ # 사운드 시스템 제어 (C++ 클래스)  
├── SoundManager.h / .cpp # BGM 변경, 볼륨 조절(Sound Mix 연동)을 총괄하는 싱글톤  
└── UIPlaySoundComponent.h / .cpp# UI 버튼 클릭 시 효과음을 공통으로 터트려주는 컴포넌트  
  
```
