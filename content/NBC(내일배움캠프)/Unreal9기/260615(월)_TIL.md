### 오늘 배운 것

#### 1. 애니메이션 몽타주(Animation Montage)

애니메이션 몽타주는 특정 상황에서 원하는 애니메이션을 재생하기 위한 기능이다.

- 공격 애니메이션
- 피격 애니메이션
- 사망 애니메이션

상태 머신(State Machine)으로 관리하기 어려운 일회성 동작들을 재생할 때 사용한다.

---
#### 2. 슬롯(Slot)

슬롯은 몽타주가 재생될 위치를 의미한다.

예시

- DefaultSlot
- Damage
- Death

Anim Blueprint의 Anim Graph에서 Slot 노드를 추가하고, 몽타주에서도 동일한 Slot을 지정해야 정상적으로 재생된다.

##### 슬롯 생성 방법

1. Window → Anim Slot Manager
2. 원하는 Slot 추가
3. 저장
4. Anim Graph에 Slot 노드 추가
5. 몽타주에서 해당 Slot 선택

---
#### 3. 노티파이(Notify)

노티파이는 특정 시점에 이벤트를 발생시키는 기능이다.

예시

- 발소리 재생
- 공격 시작
- 이펙트 생성

##### 생성 방법

1. Notify 트랙 우클릭
2. Add Notify
3. New Notify

생성 시 노란색 마커 형태로 표시된다.

---
#### 4. 노티파이 스테이트(Notify State)

노티파이 스테이트는 시작과 종료 구간을 가지는 이벤트이다.

예시

- 무기 충돌 활성화
- 무적 상태
- 트레일 이펙트
- 
##### 생성 방법

1. Notify 트랙 우클릭
2. Add Notify State
3. New Notify State

생성 시 보라색 막대 형태로 표시된다.

### 원인

처음에는 Notify를 생성하였다.

Notify는 노란색 마커 형태로 생성되기 때문에 강의 자료의 보라색 블록과 달랐다.

즉, 강의 자료의 보라색 블록은 일반 Notify가 아니라 Notify State였다.

### 해결

Notify 트랙에서 Add Notify → New Notify가 아닌

Add Notify State → New Notify State 를 선택해야 한다.

Notify State는 일정 시간 동안 유지되는 이벤트를 처리할 수 있으며, 생성 시 보라색 막대 형태로 표시된다.
