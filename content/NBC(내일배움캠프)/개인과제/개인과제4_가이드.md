# Enhanced Input 에셋 설정 가이드

입력 액션(IA)과 IMC는 C++ 클래스가 아니라 **언리얼 에디터에서 만드는 데이터 에셋**입니다. 아래 순서대로 생성하면 됩니다.

---

## 1. 입력 액션(Input Action) 생성

콘텐츠 브라우저에서 우클릭 →  
**Input > Input Action** 선택

|에셋 이름|Value Type|비고|
|---|---|---|
|`IA_Move`|`Vector 2D`|WASD 이동용|
|`IA_Look`|`Vector 2D`|마우스 시점 회전용|

> **Value Type**은 에셋을 더블클릭 → 디테일 패널 → **Value Type** 항목에서 `Axis2D (Vector2D)` 선택

---

## 2. Input Mapping Context(IMC) 생성

콘텐츠 브라우저에서 우클릭 →  
**Input > Input Mapping Context** 선택 → 이름: `IMC_Default`

### IMC 내부 매핑 설정

에셋 더블클릭 후 `+` 버튼으로 아래처럼 매핑을 추가합니다.

#### IA_Move 매핑 (WASD)

|키|Modifier|X/Y|
|---|---|---|
|`W`|없음|Y = +1|
|`S`|**Negate** (Y만)|Y = -1|
|`D`|없음|X = +1|
|`A`|**Negate** (X만)|X = -1|

> Modifier 추가 방법: 키 항목 좌측 화살표 펼치기 → **Modifiers** 배열에 `+`
> 
> - `W` / `D` : Modifiers 없음 (기본값이 양수)
> - `S` : `Negate` 추가 (Axis: `Y`만 체크)
> - `A` : `Negate` 추가 (Axis: `X`만 체크)
> 
> **Swizzle Input Axis Values** Modifier를 함께 사용하면 1D 키로 2D 값 매핑이 편합니다.  
> 구체적으로는 `W/S`에는 `Swizzle(YXZ)` + `Negate(S만)`, `A/D`는 그대로 두는 방식도 일반적입니다.

#### IA_Look 매핑 (마우스)

|키|Modifier|비고|
|---|---|---|
|`Mouse XY 2D-Axis`|없음|에디터 기본 제공|

> `Mouse XY 2D-Axis`는 마우스 수평(X)·수직(Y) 이동을 Vector2D로 한 번에 줍니다.

---

## 3. Blueprint로 GameMode 설정

1. 콘텐츠 브라우저에서 **BP_MyGameMode** 생성 (GameModeBase 상속)
2. **Default Pawn Class** → `AMyPawn` (또는 파생 BP)
3. 프로젝트 세팅 → Maps & Modes → **Default GameMode** → `BP_MyGameMode`

---

## 4. Pawn Blueprint에서 에셋 연결

`AMyPawn`을 상속한 Blueprint를 생성하거나 C++ 디폴트 값에서 직접 지정합니다.

|프로퍼티|연결할 에셋|
|---|---|
|`Default Mapping Context`|`IMC_Default`|
|`Move Action`|`IA_Move`|
|`Look Action`|`IA_Look`|

> C++ 생성자에서 `ConstructorHelpers::FObjectFinder`로 하드코딩도 가능하지만, Blueprint에서 지정하는 방식이 유지보수에 유리합니다.

---

## 5. 빌드 설정 확인 (`Build.cs`)

`EnhancedInput` 모듈이 없으면 컴파일 에러가 납니다.

```csharp
// MyProject.Build.cs
PublicDependencyModuleNames.AddRange(new string[]
{
    "Core", "CoreUObject", "Engine", "InputCore",
    "EnhancedInput"   // ← 반드시 추가
});
```

## Claude 응답: 언리얼 엔진 진행 순서

## 언리얼 엔진 진행 순서

### 1. C++ 클래스 생성

- 언리얼 에디터 상단 메뉴 → Tools → New C++ Class
- 부모 클래스로 **Pawn** 선택
- 클래스 이름 지정 후 생성

---

### 2. GameMode C++ 클래스 생성

- 동일하게 New C++ Class
- 부모 클래스로 **GameModeBase** 선택
- 클래스 이름 지정 후 생성

---

### 3. GameMode 설정

- 프로젝트 세팅 → Maps & Modes → Default GameMode를 방금 만든 GameMode로 변경
- 또는 현재 레벨의 World Settings에서 변경

---

### 4. 입력 에셋 생성

- Content Browser 빈 공간 우클릭 → Input → **Input Action** 두 개 생성
    - IA_Move, IA_Look 각각 생성, Value Type을 **Axis2D (Vector2D)** 로 설정
- 동일하게 우클릭 → Input → **Input Mapping Context** 하나 생성
    - IMC 열어서 + 버튼으로 두 액션 추가하고 각각 키 할당
    - IA_Move → W/A/S/D 키 등록 (Swizzle, Negate 모디파이어 활용)
    - IA_Look → Mouse XY 2D Axis 등록

---

### 5. Visual Studio에서 Pawn 헤더/소스 작업

- 솔루션 탐색기에서 만든 Pawn 클래스의 **.h / .cpp** 파일 열기
- 헤더에 컴포넌트 변수 선언 (Capsule, SkeletalMesh, SpringArm, Camera)
- 소스에서
    - 생성자: 컴포넌트 생성 및 계층 구조 연결, Physics false 설정
    - BeginPlay: IMC 등록
    - SetupPlayerInputComponent: IA_Move, IA_Look 바인딩
    - Move/Look 처리 함수 각각 작성

---

### 6. GameMode 소스에서 DefaultPawnClass 지정

- GameMode .cpp 생성자 안에서 DefaultPawnClass를 만든 Pawn 클래스로 지정

---

### 7. 컴파일 및 에디터 확인

- Visual Studio에서 빌드 (Ctrl+Shift+B) 또는 에디터 내 Compile 버튼
- 에디터로 돌아와서 레벨에 플레이어 스타트 배치 확인
- 플레이 버튼 눌러서 이동/회전 동작 확인
