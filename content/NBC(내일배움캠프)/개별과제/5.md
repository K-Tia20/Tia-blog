# 3. 전체 게임 제작 및 연동 과정 (Step-by-Step)

## 1단계: C++ 프로젝트 컴파일 및 빌드

1. 언리얼 에디터를 닫고 프로젝트의 `Source/P5/` 내에 위의 모든 파일명과 전체 코드를 복사 및 생성합니다.
    
2. `.uproject` 파일을 우클릭하고 `Generate Visual Studio project files`를 실행합니다.
    
3. IDE(Visual Studio 또는 Rider)를 열어 `Ctrl + Shift + B`를 눌러 컴파일을 완수합니다.
    

## 2단계: 에디터 셋업 및 BP 자식 클래스 분화

1. 컴파일 완료 후 언리얼 에디터를 실행합니다.
    
2. `OkItemBase`를 상속받아 `BP_Item_Base`를 만들고 스태틱 메시(장애물용 박스)를 지정합니다.
    
3. `OkPointItem`을 상속받아 `BP_PointItem`을 만들고 금색 코인 모양 메시를 할당한 뒤, `Score Value`에 **10**을 입력합니다.
    
4. 콘텐츠 브라우저 빈 곳 우클릭 $\rightarrow$ `입력` $\rightarrow$ `Input Mapping Context` 및 `Input Action` 6종을 만들어 기본 캐릭터 조작(WASD, 마우스 룩 등)을 할당한 뒤, 에디터용 플레이어 컨트롤러 블루프린트를 만들어 이를 바인딩합니다.
    

## 3단계: 맵(Map) 설계 및 데이터 할당

1. 파일 메뉴에서 새 레벨을 총 3개 만듭니다. 이름은 각각 **`Map1`**, **`Map2`**, `Map3`로 지정합니다.
    
2. `Map1`은 바닥 평면, `Map2`는 움직이는 벽 장애물들 배치, `Map3`은 추락 위험이 있는 공중 발판들로 월드를 구성합니다.
    
3. `프로젝트 세팅 -> 맵 및 모드`에서 기본 게임모드를 `OkGameMode` 기반 블루프린트로 변경하고, 최하단의 Game Instance를 `OkGameInstance`로 교체합니다.
    
4. 각 맵의 `월드 세팅(World Settings)` 탭에서 게임모드가 잘 박혀있는지 확인합니다.
    
5. `Map1` 월드 아웃라이너에서 `OkGameState`를 클릭한 뒤, 디테일 패널의 **`Spawn Locations` 배열 엘리먼트를 여러 개 추가하고 아이템들이 생성될 월드의 좌표(X, Y, Z) 값들을 직접 타이핑하여 입력**해 줍니다.
    
6. `Item Class Base` 항목에는 `BP_Item_Base`를, `Point Item Class` 항목에는 `BP_PointItem`을 각각 할당해 줍니다.
    

## 4단계: UMG UI 디자이너 및 캔버스 정렬

1. 콘텐츠 브라우저에서 우클릭 $\rightarrow$ `유저 인터페이스` $\rightarrow$ `위젯 블루프린트`를 생성하여 **`WBP_HUD`**, **`WBP_MainMenu`**, **`WBP_GameOver`** 3개를 만듭니다.
    

### 🎨 UI 일관성 디자인 정렬 배정표 (Canvas 구조)

- **`WBP_MainMenu` & `WBP_GameOver`**:
    
    - 최상위에 `CanvasPanel`을 배치합니다.
        
    - 하위에 `VerticalBox`를 화면 정중앙에 앵커(Anchor Center) 정렬 처리합니다.
        
    - 버티컬 박스 내부에 **`Button`** 컴포넌트들을 쌓고, 자식으로 `TextBlock`을 넣습니다.폰트는 `Arial` 혹은 기본 폰트, 크기는 `32pt` 통일, 색상은 고급스러운 다크 그레이로 맞춥니다.
        
    - 각 버튼의 블루프린트 그래프 `OnClicked` 이벤트에서 시작(`Open Level: Map1`), 종료(`Quit Game`), 재시작(`Open Level: 현재맵`) 노드를 링크합니다.
        
- **`WBP_HUD`**:
    
    - **`CanvasPanel`** 우측 상단에 `VerticalBox`를 배치합니다.
        
    - 제한 시간, 점수, 현재 단계 표시용 `TextBlock`들을 생성합니다.
        
    - 각 텍스트 항목 우측의 `바인딩 생성(Create Binding)`을 클릭하고 함수 내부에서 `Get Game State` $\rightarrow$ `Cast to OkGameState` 노드를 호출하여 C++ public 변수인 **`CurrentLevel`, `CurrentWave`, `CurrentScore`, `TimeRemaining`** 값을 실시간 포맷 텍스트(Format Text) 처리하여 화면에 투사 연동되게 마무리합니다.
        
- **`머리 위 HP 체력바 위젯`**:
    
    - `OkPawn`을 상속받은 블루프린트 캐릭터 창을 켜고, 좌측 상단 컴포넌트 추가를 눌러 **`Widget` 컴포넌트**를 생성합니다. 머리 위로 위치를 올린 뒤 디테일 패널에서 `Space` 타입을 `Screen`으로 변경하고 생성해 둔 체력 위젯을 연결해 주면 모든 기획 조건이 기동되기 시작합니다.
