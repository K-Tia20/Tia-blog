### 과제 조건
- [ ] 한 레벨 안에서 레벨 전환 없이 1~3단계의 웨이브 (게임 진행)을 진행
- [ ] 각 웨이브마다 제한 시간, 아이템 스폰 횟수의 베리에이션을 설정
- [ ] 전체 게임 진행: 3번의 레벨이 전환
- [ ] 각 레벨 안에서 최소 3단계 이상의 웨이브
- [ ] 각 웨이브는 난이도 조정을 위해, 시간과 아이템의 갯수가 달라짐
- [ ] 웨이브 시작시 GEngine->AddOnScreenDebugMessage 등의 방법으로 “Wave 1 시작!” 알림을 출력
- [ ] HUD에 표시할 정보를 표시
- [ ] 점수, 시간, 체력
- [ ] 전부 한 화면에서 볼 수 있도록 배치
- [ ] 메인 메뉴 (시작, 종료) UI를 재설계
- [ ] 게임 오버 메뉴 (재시작, 메인 메뉴로 돌아가기) UI를 재설계
- [ ] 폰트, 색상, 배경 등을 적절히 조정하여 일관된 디자인을 적용
- [ ] 레벨 이동 또는 게임 종료 기능 구현
- [ ] 각 버튼 클릭 시 C++ / 블루프린트 함수를 호출
- [ ] 부정적 아이템 효과 추가 : SlowingItem: 플레이어가 일정 시간 동안 이동 속도 50% 감소
- [ ] 부정적 아이템 효과 추가 : ReverseControlItem: 일정 시간 동안 W키가 뒤로, A키가 오른쪽 등 컨트롤 반전
- [ ] 부정적 아이템 효과 추가 : BlindItem: 일정 시간 화면 시야가 제한되거나, 카메라 회전이 제한
- [ ] 단순 점수 감소 외에 색다른 디버프 효과여야 합니다.
- [ ] 아이템 효과는 중첩될 수 있습니다
- [ ] UI를 통해 각 디버프의 정보를 확인할 수 있어야 합니다.ex) 효과의 시작/끝, 중첩 상황 등
- [ ] 웨이브가 올라갈수록 맵 환경이나 플레이 상황 자체가 달라지게 설계
- [ ] Wave 1: 기존 로직 그대로
- [ ] Wave 2: 맵에 새로운 장애물이 추가
- [ ] Wave 3: 맵에 파도 함정 추가
- [ ] 이벤트 발생을 플레이어가 인지할 수있게 UI로 알려주세요.
- [ ] ex) “파도 함정이 발동되었습니다…!”
- [ ] UI 애니메이션 1개 이상 구현
- [ ] Widget Animation을 이용해 기존 위젯에 Fade In/Out, 슬라이드 애니메이션 등을 적용
- [ ] 버튼 hover 상태에 Tween 또는 강조 효과를 주어, 사용자 클릭 욕구를 높이는 연출
- [ ] 캐릭터 머리 위 체력바, 아이템 상호작용 안내 문구 등, 3D 공간에 위젯을 표시
- [ ] World Space 모드나 Screen Space 모드 중 선택, 적절한 마스크·배경 처리
- [ ] 마우스로 3D 위젯을 직접 클릭하여 상호작용할 수 있게 만들어봅시다. 상호작용 아이템 “Press E to pick up” 등
- [ ] WBP_HUD, WBP_MainMenu, HP 위젯을 기능과 디자인 관점에서 요약/분석
- [ ] 캔버스 구조 (CanvasPanel, VerticalBox 등)를 적절히 배치
- [ ] 점수, 타이머, 레벨 등 정보를 보기 좋게 표시
- [ ] 텍스트 스타일 (폰트, 색상, 테두리 등)과 아이콘, 게이지 바 등을 활용해 디자인 완성도를 높임
- [ ] 게임 시작, 재시작, 종료 버튼을 재배치하고, 배경 이미지·반투명 블러 등 시각적 요소를 개선
- [ ] 버튼 hover, clicked 등 인터랙션 효과 (색/이미지 변화)를 적용
