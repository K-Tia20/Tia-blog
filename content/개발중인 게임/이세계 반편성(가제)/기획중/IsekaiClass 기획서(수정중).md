
1. 개요
게임명 : 이세계클래스
장르 : 싱글 플레이 오픈월드 RPG
시점 : 3인칭 액션
핵심 재미 : 필드 전투 중심, 생활 콘텐츠 보조, NPC 영입과 파티 조합
성장 방식 : 경험의 서와 장비. 캐릭터 레벨·경험치·스킬 포인트 없음
생활 콘텐츠 : 제작·요리·농사·낚시·벌목·채광·채집
플랫폼 : PC, 컨트롤러
언어 : 한국어 우선. 영어·일본어는 기능 동결 후 여력이 있을 때 검토. 모든 대사는 처음부터 String Table로 관리
그래픽 : VRoid 기반 플레이어·NPC, Stylized 레벨
월드 : World Partition 기반 하나의 오픈월드, 자유 이동, 8지역 자유 이동, 지역별 몬스터 난이도 차이
시간 : 현실 48분 = 게임 24시간(현실 2분 = 1시간, 현실 2초 = 1분)
세이브 : 수동 4슬롯, 오토세이브 1개. 전투·대화·이벤트 중 저장 불가
사망 : 세이브 목록에서 수동 또는 오토세이브를 골라 불러오기
플레이어 : 이름 입력, 인간형 남성·여성 프리셋, 최초 전투 직업 선택(변경 불가)
종족 : 인간, 엘프, 드워프, 수인. 플레이어는 인간만 선택
엔딩 : 일반 엔딩은 월드 복귀, 히든 엔딩은 클리어 기록 후 타이틀

2. 핵심 콘셉트와 플레이 루프
2.1 핵심 콘셉트
- 레벨과 경험치 없이 경험의 서를 사용해 원하는 주 스탯을 직접 성장시킨다.
- 필드 전투가 핵심이며, 요리·제작과 생활 활동이 전투와 NPC 관계를 지원한다.
- NPC는 시간표에 따라 생활한다(상점 주인 6시 출근, 20시 퇴근 등).
- 호감도 100을 달성한 영입형 NPC를 동료로 영입해 최대 4명까지 함께 전투한다.
- 플레이어와 영입형 NPC는 같은 스탯·성장·장비 규칙을 공유한다.
- 지정 NPC 10명과의 관계를 모두 완성하면 히든 엔딩을 볼 수 있다.

2.2 핵심 루프
탐색 : 오픈월드 이동, NPC·자원·몬스터·워프 발견, 새 전투·생활·관계 기회 확보
전투 : 일반 공격과 스킬로 몬스터 처치, 아이템·골드·경험의 서 자동 획득. 동료는 일반 공격 자동, 스킬 수동(동료 창에서 자동 전환 가능)
성장 : 경험의 서 사용, 장비 교체·강화, 스킬 해금 조건 달성
생활 : 음식·포션·장비 제작, 채집과 수면, SP 회복, 전투 준비, 경제 자원 확보
관계 : 대화·선물·퀘스트로 호감도 증가, 영입형 NPC 영입, 집·소지품 접근, 동료 전투 강화, 히든 엔딩 조건 달성

3. 월드·지역·시간
3.1 월드 구조
- World Partition을 사용하는 하나의 통짜 오픈월드.
- 지역은 8개이다.
- 다른 지역도 처음부터 기술적으로 접근 가능하지만 지역별 몬스터 난이도가 자연스러운 진행 장벽이 된다.
- 주요 집·상점·식당은 오픈월드 안에 내부 공간을 제작한다. 
- 카메라 충돌, 실내 라이팅(낮밤), 미니맵 층 처리가 기술 리스크이므로 한 건물로 먼저 테스트한다.
- 상점·대장간 등 상주형 NPC는 집과 작업장이 한 공간이거나 가까이에 있고, 출퇴근을 해도 지도·미니맵의 상점 아이콘은 고정한다. 
- NPC가 부재(퇴근)할 때는 거래를 이용할 수 없다.

3.2 시간과 일시정지
하루 길이 : 현실 48분 = 게임 24시간(2분 = 1시간)
메뉴 : 인벤토리·스킬·퀘스트·지도·상점 등 모든 메뉴에서 시간 정지(게임 일시정지)
플레이어 수면 : 침대 사용 시 플레이어의 부족한 SP로 취침 시간을 계산해 그만큼 GameClock을 점프
수면 회복 : 플레이어 HP·MP·SP 완전 회복, 동행 동료 HP·MP 완전 회복. 쓰러진(사망) 동료는 회복 대상이 아니며 부활 아이템·스킬로만 복귀
사용 가능한 침대 : 플레이어 집 침대, 여관, 영입형·상주형 NPC 침대. NPC가 점유 중이면 사용 불가. 여관은 숙박 비용을 받을 수 있음
NPC 수면 : 개별 시간표에 따라 취침·기상, 동료는 플레이어와 같이 수면 진행
게임 종료 : 종료한 실제 시간 동안 NPC와 월드는 변하지 않음

3.3 빠른 이동
- 지역별 워프 마법사(상주형 NPC)에게 골드를 지급해 이동한다.
- 직접 방문한 워프만 해금되며, 호감도가 높아지면 비용이 감소한다.
- 기본 비용과 최대 할인율은 밸런스 시트에서 결정한다.

3.4 시간 기준
GameClock(게임 분) :  NPC 일과·수면, 낮밤, SP 시간 감소(플레이어), 농사 성장(게임 일 단위)
- 메뉴·일시정지·종료 중 정지. 수면 때만 점프
PlayClock(플레이 초) : 쿨타임, 디버프 남은 시간, 몬스터·자원 리스폰, 드롭 아이템 소멸, 오토세이브 간격, 최종 보스 리스폰
- 메뉴·일시정지·종료·수면 점프 중 모두 진행하지 않음
수면은 GameClock만 점프하므로 자는 것만으로 리스폰·재생이 갱신되는 어뷰징이 없다. 
농사는 의도적으로 수면의 영향을 받는다.
기본값 후보(밸런스 시트에서 확정): 일반 몬스터 리스폰 90초, 자원 재생 300초, 드롭 아이템 소멸 1,800초(30분), 오토세이브 간격 300초, 최종 보스 리스폰 1,800초.
리스폰은 처치 시점의 PlayClock 값을 저장하고, 지역 진입 시 현재 값과 비교해 처리한다.

3.5 수면 시간 계산
취침 시간은 플레이어 기준 부족 SP로 정해진다. 고정 기상 시각(오전 6시)은 없다.
취침 시간(게임 분) = ⌈ (최대 SP − 현재 SP) ÷ 수면 중 분당 SP 회복량 ⌉
- SP가 가득 차 있으면 수면 시간은 0이며, 최소 수면 시간 여부는 밸런스 시트에서 정한다.
- 수면이 끝나면 GameClock을 계산된 시간만큼 점프하고 OnTimeJumped(from, to)를 방송한다.
- 영입형 NPC(동행 동료 포함)의 SP는 같은 취침 시간만큼 회복량을 적용한다. 따라서 플레이어보다 SP가 더 부족한 동료는 완전 회복되지 않을 수 있다.


4. 플레이어·직업·무기
4.1 캐릭터 생성
- 이름 입력 → 인간형 남성·여성 프리셋 선택 → 최초 전투 직업 선택.
- 머리·얼굴·의상 세부 커스터마이징은 현재 범위에 포함하지 않는다.
- 시작 시 플레이어 집을 지급한다.

4.2 전투 직업
직업 : 역할 : 무기 계열 : 시작 구성
1) 전사 : 근접 물리·탱커 : 검 : 초보자 검, 전사 1번 스킬
2) 궁사 : 원거리 물리 : 활 : 초보자 활, 궁사 1번 스킬
3) 마법사 : 마법 공격 : 마법스태프 : 초보자 마법스태프, 마법사 1번 스킬
4) 치료사 : 치유·지원 : 치유완드 : 초보자 치유완드, 치료사 1번 스킬
- 직업은 선택 후 변경할 수 없고, 다른 직업의 스킬은 습득할 수 없다.

4.3 무기
- 무기 계열은 검·활·마법스태프·치유완드 4종이며 직업별로 장착 계열이 고정된다. 영입형 NPC도 DT에 무기 계열 1개를 고정한다
- 무기는 검의 물리 공격력, 마법스태프의 마법 공격력, 치유완드의 치유량처럼 능력치 성향을 제공한다.
- 무기 외형은 소켓 장착이며 아이템마다 다르게 보인다. 장비 DT의 메시·소켓 컬럼으로 관리한다(소켓 규격은 8번).

5. 성장과 스탯
5.1 성장 원칙
- 스탯을 가지는 대상은 플레이어와 영입형 NPC 24명뿐이다. 상주형·배경형 NPC는 스탯과 장비가 없다.
- 캐릭터 레벨·경험치·스킬 포인트를 사용하지 않는다. 성장은 경험의 서 사용으로만 진행한다.
- 주 스탯 상한은 플레이어와 영입형 NPC 모두 10,000이며 리셋할 수 없다. 상한은 안전장치이고, 밸런스 곡선은 1~300 범위 기준으로 설계한다.
- 주·파생 스탯은 정수로 표시하고 파생 값은 반올림한다.
- 엔딩 권장 성장치는 주 스탯 6개의 평균 100이다(총 600포인트, 고급 서 약 120권 상당).

5.2 주 스탯 6개
1) 근력 STR : 물리 공격력
2) 민첩 DEX : 이동·공격 속도, 자동 회피 확률, 치명타
3) 지력 INT : 마법 공격력, 치유량, 최대 MP 기여
4) 체력 CON : 최대 HP, 방어력, 최대 SP
5) 매력 CHA : 동료 전체 능력치와 고유 스킬 효율 소폭 상승
6) 운 LUK : 치명타, 높은 등급 장비, 추가 아이템, 골드 획득량·드롭 확률
- 주 스탯 기본값은 모두 1이다. 직업별 초기 수치 보정이 필요하면 밸런스 시트에서만 추가한다.
- 영입형 NPC의 초기 스탯은 NPC DT에서 지정한다.

5.3 파생 스탯
- 최대 HP: 체력 중심. 최대 MP: 지력 중심. 최대 SP(플레이어): 체력 중심.
- 물리 공격력: 근력·무기·장비 옵션. 마법 공격력: 지력·무기·장비 옵션.
- 치유량: 마법 공격력과 동일 값(지력 기반, 무기·장비 옵션 포함)으로 계산.
- 방어력: 체력·장비.
- 공격력: 물리·마법 피해 계산 이후 적용되는 최종 퍼센트 보정값(정수). 탈진 페널티도 이 값으로 처리한다.

5.4 경험의 서
등급 : 상승량 : 획득처
1) 초급 : +1 : 몬스터 드롭·퀘스트 보상
2) 중급 : +3 : 강한 몬스터·퀘스트·보스 보상
3) 고급 : +5 : 보스·고난도 퀘스트 보상
- 사용 횟수 제한은 없다. 플레이어와 동료는 포션처럼 대상에게 사용한다.
- 영입형 NPC에게는 동료 여부와 관계없이 선물·사용 시 즉시 스탯이 오른다.
- 영입형이 아닌 NPC(호감도가 있는 상점형 상주형 NPC 포함)는 경험의 서를 선물로 받아도 스탯이 오르지 않는다. 호감도는 선호 테이블을 따른다.
- 사용 시 대상(플레이어·영입형NPC) 머리 위에 증가 VFX를 재생한다. 성장 텍스트 알림은 없고, 연속 사용 시 VFX는 겹쳐 재생하지 않는다.

6. 전투 시스템
6.1 기본 전투
시점 : 3인칭 액션
타게팅 : 카메라 중앙 우선 선택, TAB으로 다음 적 전환. 세부 조작은 전투 담당자가 테스트 후 조정
일반 공격 : 마우스 왼쪽 버튼
방어 : 마우스 오른쪽 버튼을 누르는 동안 방어. 피해 감소율은 전투 밸런스에서 확정. SP 소모 없음
회피 : Shift. 무적 시간·거리·쿨타임은 전투 담당이 테스트 후 확정. SP 소모 없음
점프 : Space
상호작용 : F
드롭 : 몬스터 사망 즉시 아이템·골드 자동 획득. UI에 아이콘·수량 표시
인벤토리 넘침 : 스택 합산 후 남는 수량은 레벨에 드롭 아이템(외형 통일)으로 생성하고 F로 습득. 30분 후 레벨에서 삭제. 골드는 항상 획득
전투 상태 정의 : 어그로된 적이 있거나 최근 N초 안에 피격·공격했을 때. 저장 불가와 오토세이브 보류 판정에 사용

6.2 플레이어 스킬
모든 스킬은 액티브 스킬이며 직업별 4개가 고정이다. 스탯 조건을 만족하면 순차 해금하고 Q/E/R/T에 고정 매핑한다. 미해금 슬롯은 HUD에서 안보이게 한다.
스킬 교체는 없다. 스킬 창은 해금 조건을 읽기 전용으로 보여 준다.
스킬 사용 시 MP를 소모한다. 공격 스킬은 현재 타게팅된 적을 대상으로 한다.
회복·버프 스킬은 대상 지정 모드로 사용한다.

6.3 몬스터와 보스
- 몬스터는 행동 반경 안에서 이동하고, 플레이어 유무와 관계없이 PlayClock 기준 리스폰 규칙을 적용한다.
- 지역이 바뀔수록 몬스터가 크게 강해진다. 일반 몬스터와 보스의 수량은 전투 담당자 제안 후 팀장이 승인한다.
- 지역 보스는 최종 보스 1명을 포함해 총 5명을 목표로 한다.
- 보스도 기본 전투 규칙을 공유하되 보스전 동안 화면 전체 UI 구성이 변경된다.
- 최종 보스는 엔딩 후에도 리스폰하며 반복 보상을 획득할 수 있다.

7. SP·상태이상
7.1 SP (플레이어)
- 감소 요인 : 게임 시간, 생산작업(제작·요리·채집·농사·냚시·벌목·채광)
- 회복 : 음식, 수면
NPC는 SP가 없다.
공격·회피·방어·스킬은 SP를 소모하지 않는다.
SP 0(탈진): 공격력·공격속도·이동속도가 저하된다. 행동은 막지 않는다. SP가 0일 때 걸리는 지속 GAS Effect(State.Exhausted)로 구현한다.
감소량과 탈진 수치는 밸런스 시트에서 확정한다.

7.2 디버프
독·출혈·골절·질병,저주 등 다양한 디버프가 있다.
주로 몬스터 스킬로 발생한다.
각 디버프는 HUD에 아이콘으로 표시되며 아이콘에 커서를 가져가면 남은 시간 타이머를 표시한다(PlayClock 기준)
디버프의 효과가 끝나는 5초동안 흐리게 없어졌다 사라졌다를 반복하여 디버프 끝나는 타이밍을 알려준다.
화면 어두워짐, 출혈 표현 등 상태별 전체 화면 연출(VFX, 화면 전체 애니메이션 루프)을 사용할 수 있다.
효과 수치와 중첩 규칙은 밸런스 시트에서 확정한다.

8. NPC 생활 시스템
8.1 NPC 규모
NPC는 총 52명이며, 스탯·장비·SP를 가지는 것은 영입형 24명뿐이다.
분류 : 수 : 내용 : 호감도 : 스탯·장비 : 영입
9) 영입형 : 24 : 고유 이름·외형·직업·선호·퀘스트·고유 스킬 : 있음 : 있음 : 호감도 100
10) 상주형(서비스) : 16 : 상인·대장장이·워프 마법사·여관 주인 등. 출퇴근과 호감도(할인) : 있음 : 없음 : 불가
11) 배경형 : 12 : 공용 템플릿 기반, 간단한 이동과 대화
- DT의 bRecruitable 플래그가 기준이며, 대화 메뉴의 영입 항목은 이 플래그가 true이고 호감도가 100일 때만 표시한다.
- 히든 엔딩 대상인 지정 NPC 10명은 DT의 bEndingTarget 플래그로 지정한다

8.2 NPC 데이터 원칙
- 모든 NPC는 재고·골드·생산량이 없다. 영입형도 마찬가지다.
- NPC는 시간표대로만 움직인다. 직업 행동은 연출이며 아이템을 만들거나 소모하지 않는다.
- 영입형 NPC만 DT에 장비 아이템이 맞춰져 있고 스탯을 가진다.

8.3 상호작용과 생활
- NPC가 먼저 플레이어에게 말을 걸지 않는다. 플레이어가 찾아가 상호작용한다
- 영입형·상주형 NPC는 개인 집과 침대를 가진다.
- 직업 행동은 밭·나무·작업대 같은 실제 Smart Object와 상호작용하는 것처럼 보이게 한다.
- 도둑질과 마을 습격은 구현하지 않는다. NPC가 몬스터와 만나지 않도록 배치한다.
- NPC는 레벨에 직접 배치하지 않는다. 레벨에는 Smart Object와 일과 지점(앵커)만 두고, 스포너가 상태를 보고 스폰한다

8.4 상점과 거래
- 상점형(상주형) NPC 대화 메뉴에서 구매·판매를 모두 지원한다. 구매가는 높고 판매가는 낮게 설정해 되팔이를 방지한다.
- 판매 목록은 상점 DT에 고정하며 NPC 재고·골드가 없으므로 구매·판매 수량 제한을 두지 않는다.
- NPC 간 거래는 없다.
- 호감도에 따라 가격을 할인한다. 권장 규칙: 할인 후 구매가는 판매가 이상으로 유지한다.
- 가격 비율과 할인율은 밸런스 시트에서 관리한다.

8.5 먼 지역 일과 계산
- 일과는 시뮬레이션이 아니라 계산이다. ResolveSchedule(NpcId, GameMinute)가 현재 활동, 목표 앵커, 이동 진행도를 반환한다.
- 플레이어가 지역에 진입하면 계산된 위치에 NPC를 스폰한다. 이동 구간이면 출발 앵커에서 스폰하고 State Tree가 이어서 걷게 한다.
- 현재 지역에 스폰된 NPC만 State Tree를 실시간 실행한다.

9. 호감도와 동료
9.1 호감도
- 대상: 영입형·상주형 NPC. 범위 0~100.
- 상승: 퀘스트와 선호 선물(일일 한도 없음). 하락: 비선호 아이템 선물만.
- 호감도만 기억하고 행동 이력은 기억하지 않는다.
- 영입 조건은 영입형 NPC의 호감도 100이 유일하다. 상주형 NPC의 호감도는 할인 등 혜택에만 쓰이며 스탯에는 영향이 없다.
- 지정 NPC 10명의 호감도는 엔딩 분기 조건이 된다.

9.2 동료 편성·영입·해고
영입 : 호감도 100, 빈 파티 슬롯 + 해당 NPC를 직접 찾아가 대화
해고 : 쓰러진 상태가 아닐 것 + 어디서든(편성 창)
재영입 : 호감도 100 유지, 빈 슬롯 + 해당 NPC를 다시 찾아가 대화
- 플레이어를 제외하고 최대 4명이 동행하며 최대 전투 인원은 5명이다.
- 해고하면 NPC의 모드가 Scheduled로 바뀌고, 현재 시간표 위치를 계산해 그 위치에 재배치한다. 플레이어 시야에서 갑자기 나타나지 않도록 걸어서 퇴장한 뒤 앵커가 로드돼 있을 때 재스폰한다.
- 해고된 NPC의 호감도·스탯·HP·MP,장비 상태는 유지된다. 플레이어 장비를 가진 채 해고되면 그대로 가져간다.
- 쓰러진 동료는 부활 전에 해고할 수 없다.

9.3 이동과 전투
- 동료는 플레이어 주변 포메이션을 유지하며 서로 충돌하지 않는다. 일정 거리 이상 멀어지면 플레이어 뒤로 순간이동한다.
- 기본 명령은 플레이어가 타게팅한 적 또는 주변의 적 공격이다. 동료 창에서 공격 성향, 후퇴 HP 기준, 전투 지속 여부를 설정한다.
- 동료 스킬은 NPC별 고유 액티브 스킬 1개이며 성장·교체하지 않는다. Z/X/C/V 수동 발동이 기본이고 동료 창에서 자동 사용을 켜고 끌 수 있다.
- 자동 사용 조건은 유형별 기본값(공격형은 적 존재, 회복형은 HP 기준 이하)을 사용한다. 동료마다 별도 MP와 쿨타임을 사용한다.
- 동료 AI는 모드에 따라 State Tree를 교체하는 방식이다.

9.4 쓰러짐과 부활
동료가 쓰러지면 쓰러짐 모션 후 월드에서 사라지고 HUD의 해당 NPC 상태창을 회색 처리한다(Mode = Downed).
쓰러진 동료도 파티 4명 제한에 포함한다. 수면으로는 회복되지 않으며 부활 물약(상점에서 항상 구매 가능)·부활 스킬로만 복귀한다. 부활 직후 HP/MP 비율은 밸런스 시트에서 확정한다.
쓰러진 동료 칸은 부활 아이템·스킬 대상 지정 때만 선택할 수 있다.
플레이어가 쓰러졌을 때 동료가 자동으로 살리는 기능은 없다.
플레이어는 죽으면 바로 게임 오버 된다.

9.5 소유권과 매력
- 호감도 100이된 NPC(영입형·상주형)의 집 창고·옷장·책장 등 을 사용할 수 있다. 침대는 영입형·상주형 모두 사용 가능하다
- 컨테이너에는 초기 배치분만 있고, NPC 생산량이 없으므로 가져간 물건은 재생산되지 않는다.
- 매력이 높을수록 동료 전체 능력치와 고유 스킬 효율이 소폭 상승한다. 동행 인원은 항상 최대 4명이다.

10. 아이템·장비·경제
10.1 인벤토리
탭 : 일반 / 퀘스트 2개 탭. 퀘스트 아이템은 퀘스트 탭에만 들어간다
기본 칸 수(일반 탭) : 20칸
확장 : 인벤토리 확장권 1장당(상점이나 퀘스트 등) +10칸, 최대 100칸(확장권 8장)
스택 : 소비·재료 한 칸에 99개, 장비 1개
넘침 : 스택 합산 후 남는 수량을 레벨에 드롭 아이템(외형 통일)으로 생성. F로 습득
버리기 : 버릴 아이템을 (인벤토리 창 밖으로 끌어내면 또는 버리기 휴지통에 넣으면) 플레이어 발밑에 드롭 아이템(외형 통일) 생성
드롭 아이템 소멸 : 생성 30분 후 레벨에서 삭제(PlayClock 1,800초) 
- 드롭 아이템은 모든 품목이 같은 외형(공용 메시 1종)을 쓴다. 습득 시 내용물은 인벤토리 규칙을 다시 따른다.
- 퀘스트 보상·제작·구매로 들어오는 아이템이 넘치면 드롭 대신 거부하고 안내한다. TryAddItem이 남은 수량을 반환하고 호출한 쪽이 정책을 결정한다.
- 퀘스트 아이템은 버리기·드롭·소멸 대상이 아니다.

10.2 창고
- 기본 창고 1개(40칸)는 플레이어 집에 있고 집 창고만 공유한다.
- 추가 창고는 집 내부에 미리 배치된 슬롯을 제작·구매 시 활성화한다. 월드 자유 배치는 범위에서 제외하며 프로토타입에서도 제외한다.

10.3 장비
- 장비는 플레이어와 영입형 NPC만 착용한다. 공용 슬롯: 무기·옷·반지·목걸이.
- 등급: 일반·고급·희귀·영웅·전설. 랜덤 옵션의 종류와 최대 개수는 밸런스 시트에서 확정.
- 강화는 대장장이 NPC(상주형)에게 맡기며 장비를 해제한 뒤 강화한다. 실패 시 골드만 소모하고 단계 하락·파괴는 없다. 최대 단계와 성공 확률은 밸런스 시트에서 확정.
- 옷·반지·목걸이 외형은 VRoid 캐릭터에 반영하지 않는다. 무기만 소켓으로 표시한다.

10.4 아이템 종류
일반 : 포션, 음식, 경험의 서, 장비, 생산품, 채집품, 어종, 인벤토리 확장권, 부활 물약 등
퀘스트 : 퀘스트 아이템
- ID 기반 데이터로 관리하며 아이템 DT에 탭 구분 컬럼을 둔다. 화폐는 골드만 사용한다.

11. 생활 콘텐츠
11.1 우선순위
요리·제작: 핵심 시스템으로 우선 완성.
농사·낚시·벌목·채광·채집: 최종 구현 목표, 일정 부족 시 콘텐츠 수량 축소.
건축·목축·결혼: 구현 추가, 없어도 되는 목록

11.2 도감 콘텐츠
각 아이템, NPC 호감도, 지역 명소 사진(특정 장소 액터 상호작용)

11.3 세부 규칙
- 제작대와 주방은 초기에 사용할 수 있다. 기본 레시피를 제공하고 퀘스트와 NPC 호감도로 추가 레시피를 해금한다
- 낚시는 기본 액션 또는 타이밍 입력 미니게임이며 최종 목표 20종을 지역별로 배분한다(지역당 5종).
- 벌목·채광 자원은 채집 후 PlayClock 약 5분 뒤 재생한다. 농사 성장은 작물에 따라 다르다.
- 생산작업은 플레이어 SP를 소모한다
- 품목 수량은 일정에 따라 조정한다.

12. 퀘스트·대화·엔딩
12.1 퀘스트
일반 퀘스트와 연계 퀘스트를 사용한다. 
유형: 대화·아이템 전달·몬스터 처치·보스 처치·채집·제작·호감도 달성·장소 도달·호위.
스탯과 호감도 조건을 설정할 수 있다. 보상은 경험의 서·골드·아이템·호감도 등이다. 수락 개수·시간 제한은 없다.
전체 목록은 퀘스트 창에서 확인하고, HUD에는 선택한 퀘스트 하나만 표시한다. 완료 후 다음 퀘스트 자동 추적 여부는 DT 우선순위와 담당자 설정을 따른다.

12.1-1 퀘스트 대상이 동료일 때
퀘스트 창·HUD에 "동행 중" 배지와 안내 문구("OO은(는) 현재 동료입니다. 해고 후 대화하면 진행할 수 있어요.")를 표시한다. 큰 지도의 대상 마커는 파티 아이콘으로 바꾼다.
동료인 상대는 상호작용이 불가능하기 때문에 무조건 해고후 진행해야한다.

12.2 대화
- 텍스트 창과 선택지를 사용한다. 선택지는 연출용이며 엔딩 분기·호감도·퀘스트 결과에 영향을 주지 않는다.
- 상점형 NPC 대화 메뉴에는 구매·판매, 선물하기를 표시하고, 영입형 NPC는 호감도 100일 때 동료 영입을 표시한다. NPC 풀보이스는 범위에서 제외한다.

12.3 엔딩 분기
엔딩은 2종이며, 지정 NPC 10명의 호감도가 모두 100인지로 갈린다.
1) 지정 NPC 10명 중 호감도 100 미달성자 1명 이상 -> 엔딩 퀘스트 -> 일반 엔딩
2) 지정 NPC 10명 모두 호감도 100 -> 엔딩 퀘스트 -> 히든 엔딩
- 메인 퀘스트를 따라가 엔딩 퀘스트(QST_FIN_001)를 수락하면 최종 보스전이 열린다.
- 분기 판정은 엔딩 퀘스트 완료(최종 보스 처치) 시점에 한다. 판정 함수는 DT의 bEndingTarget NPC 10명을 WorldState에서 조회한다.
- 일반 엔딩의 경우 엔딩 UI와 크레딧을 표시하고, 보스를 처치한 상태의 기존 월드로 돌아가 계속 플레이한다.
- 히든 엔딩의 경우 히든엔딩 UI와 크레딧을 표시하고 게임 클리어가 되고 종료된다.

13. UI·입력·지도·사운드
13.1 HUD
플레이어와 동료의 이미지, 각자의 HP·MP를 표시한다. SP 게이지는 플레이어만 표시한다
상태이상 아이콘에 커서를 올리면 설명과 남은 시간을 확인한다.
퀵슬롯 4개, 플레이어 스킬 4개, 동료 스킬 0~4개를 표시한다.
아이템 자동 획득 시 아이콘과 수량을 표시하고 골드는 +100 형태로 표시한다.

13.2 입력
동작 : 입력
1) 일반 공격 : 마우스 왼쪽
2) 방어 : 마우스 오른쪽(누르는 동안 유지)
3) 회피 : Shift
4) 대상 선택 : TAB(카메라 중앙 우선, 다음 적 전환)
5) 플레이어 스킬 : Q / E / R / T(직업 스킬 4개 고정)
6) 동료 스킬 : Z / X / C / V(편성 순서에 대응)
7) 퀵슬롯 : 1 / 2 / 3 / 4
8) 점프 : Space(플레이어만)
9) 상호작용·드롭 아이템 습득 : F
10) 인벤토리·퀘스트·지도·동료 : I / O / M / P(조작 테스트 후 변경 가능)
11) 일시정지 : ESC(모든 메뉴에서 게임 시간 정지)
12) 대상 지정 모드 취소 : ESC
13) 타겟 해제, 스킬·스탯·장비 창, 컨트롤러 : 키 미정, 후순위

대상 지정 모드
진입: 퀵슬롯에서 대상형 아이템(포션·음식·경험의 서 등)을 고르거나 회복·버프 스킬 키(Q/E/R/T)를 누르면 진입한다. 
모드 중: Z/X/C/V는 편성 순서 1~4번 동료를 지정하고, 같은 키를 다시 누르면 플레이어 자신이다. 빈 칸은 무시한다.
쓰러진 동료 칸은 부활 아이템·스킬일 때만 선택 가능하고 그 외에는 비활성 표시한다.
종료: 사용 완료 또는 ESC로 취소. 모드가 아닐 때 Z/X/C/V는 해당 동료의 고유 스킬 수동 발동이다.
모드 중에는 HUD 파티 슬롯을 강조한다. 모드 중에 동료 스킬을 쓰려면 먼저 취소해야 한다.

13.3 지도와 마커
표시 항목  : 큰 지도 : 마을 지도 : 미니맵
1)플레이어 : X : O : O
2)동료 NPC : X : X : O
3)적(몬스터·보스) : X : X : O
4)상점형 NPC 아이콘(고정) : X : O : O
5)해금한 워프 : O : O : O
6)선택한 퀘스트 마크 : O : O : O
- 미니맵에는 상점형 아이콘, 플레이어, 동료 NPC, 적만 표시한다.
- 마을 지도에서 퀘스트가 있는 NPC는 상점 아이콘보다 퀘스트 아이콘을 우선한다.
- NPC 머리 위에는 퀘스트 마크만 표시하며 퀘스트가 없으면 아무 마크도 없다.

13.4 사운드·설정
지역별 비전투·전투 BGM과 최종 보스, 환경음·UI 효과음·발소리·무기 타격음·스킬 효과음·몬스터 음성을 포함한다.
설정 메뉴(그래픽 품질, 키 설정·리바인드, 언어, 볼륨, 접근성 기본 항목)와 Common UI·폰트(한/영/일 Composite Font 폴백)

14. 저장·사망·지속 상태
14.1 저장 방식
- 수동 세이브: 4개 슬롯. 전투·대화·이벤트 중이 아닐 때 메뉴의 저장 기능으로 필드 어디서든 저장한다.
- 초기 저장: 새 게임 시작 직후 기본 오토세이브를 생성한다.
- 사망: 수동·오토세이브를 포함한 목록에서 선택해 불러온다.

14.2 오토세이브
트리거: 수면 직후, 지역 경계 통과·워프 이동 후, 퀘스트 수락·완료 후, 보스 처치 후, 마지막 저장 후 PlayClock 5분.
전투·대화·이벤트 중이면 보류했다가 끝난 직후 실행한다. HP가 매우 낮거나 활성 디버프가 있으면 보류한다.
목록에는 1개만 보이되 내부에 직전 오토세이브 1개를 백업한다. 저장은 비동기로 하고 임시 파일에 쓴 뒤 교체한다. HUD에 저장 아이콘을 표시한다.

14.3 필수 저장 범위
캐릭터 상태(플레이어와 영입형 NPC 공통): 주 스탯, HP/MP/SP(플레이어만), 장비 인스턴스, 모드, 파티 슬롯, 호감도
플레이어 인벤토리(일반·퀘스트 탭), 확장 칸 수
상주형 NPC 호감도
활성 디버프(ID, 남은 시간), 창고·NPC 컨테이너 내용물
퀘스트 진행, GameClock·PlayClock, 해금 워프, 파티 편성
몬스터 처치 시각(PlayClock)과 보스 처치 플래그, 엔딩 퀘스트 진행도·엔딩 클리어 플래그·엔딩 종류
자원 재생 남은 시간, 드롭 아이템(내용물, 위치, 생성 PlayClock)
스폰된 NPC의 현재 위치는 저장하지 않는다(시간표로 재계산). 동료는 로드 시 플레이어 주변에 스폰한다
세이브에 SaveVersion을 두고 DT 변경에 대한 마이그레이션 규칙을 둔다. 저장 직전에 살아 있는 액터의 GAS 값을 서브시스템에 기록(Flush)한다

15. 콘텐츠 목표와 1차 프로토타입
구현 기준
저장 기능, 시간·WorldState 뼈대, 치트 콘솔, 기획과 프로토타입 실제 확인
영입형 NPC 1명, 상인(상주형) NPC 1명이 실제 일과대로 움직이는지 확인
일반 몬스터 1종
기본 이동, 검사 일반 전투·스킬, 제작 애니메이션
게임 시작, 이름, 직업 선택, 전체 UI 입력만 가능한 수준
프로토 우선순위는 낮으나 일과·수면을 위한 Smart Object·앵커·침대 최소 배치 필요
요리(빵 1종: 섭취·선물), 제작(무기 1종, 재료는 상점 NPC 판매)
직업 1개(전사), 스킬 1개 사용
호감도 시스템(빵 선물 → 호감도 증가 → 영입), 몬스터 사냥 시 호감도가 오르는 퀘스트 1개

15.2 1차 프로토타입 완료 기준
이름·남녀 프리셋·최초 직업을 선택할 수 있다
몬스터 1종이 스폰·전투·사망·리스폰하고 보상을 자동 지급한다.
상인 NPC 1명이 일과를 수행하고 거래가 가능하다.
영입형 NPC 1명을 대화·선물·호감도 100을 거쳐 영입하고, 플레이어를 따라가며 수동 동료 스킬을 사용한다
경험의 서로 주 스탯이 오르고 파생 스탯에 반영된다.
최소 인벤토리(일반/퀘스트 탭)·퀵슬롯·음식·수면·퀘스트·HUD·세이브가 작동한다.

17. 데이터 테이블·ID 규칙
17.1 공통 규칙 
영문 대문자·숫자·밑줄만 사용(한글·공백·하이픈 금지), 길이 40자 이하, 시리얼은 3자리 0패딩(001~999)
DT의 Row Name은 ID와 같다. 코드·세이브·DT 간 참조는 모두 ID(FName) 또는 Gameplay Tag이며, 표시 문자열은 String Table에만 둔다.
한 번 쓴 ID는 변경·재사용·번호 당기기 금지. 삭제 대신 bDeprecated=true로 둔다.
지역 코드: R00 공용, R01~R04 각 지역(소속 지역은 주 거주·등장 지역).
번호 대역은 1번이 ID_Registry 시트에서 배정하고 담당자는 대역 안에서만 신규 ID를 만든다.
