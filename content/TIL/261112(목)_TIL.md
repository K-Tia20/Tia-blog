# 새 PC에 개발 환경과 제작 기록 체계 만들기

NVIDIA 드라이버만 설치된 PC에서 Epic AI MegaJam을 시작했다. 게임을 만들기 전에 엔진·빌드 도구·버전 관리를 준비하고, 작업 화면을 남길 수 있는 기록 환경부터 정리했다.

## 1. 언리얼과 제작 도구 설치

**Unreal Engine 5.9, Blender 5.3, Python, Visual Studio Community 2026**을 설치했다. 언리얼 C++ 프로젝트를 빌드할 수 있도록 C++ 도구와 Windows SDK도 함께 준비했다.

| 도구 | 사용할 작업 |
| --- | --- |
| Unreal Engine | 게임 기능·UI·월드 제작과 Windows 빌드 |
| Blender | 모델 수정과 소품 보정 |
| Visual Studio·C++ 빌드 도구 | 프로젝트 코드 컴파일 |
| Python·MCP | 반복 작업과 도구 연결 |

설치 후에는 엔진을 실제로 열어 기본 맵이 표시되는 것부터 확인했다. 아래는 게임 제작 전, 엔진 실행을 점검하던 화면이다.

![[TIL/첨부파일모음/20261112-sinbi-first-editor.jpg|700]]

## 2. GitHub에 프로젝트 연결

**Git·Git LFS·SourceTree**를 설치하고 GitHub와 연결했다. 코드와 설정은 Git으로 관리하고, 큰 바이너리 파일은 Git LFS로 구분하는 방향으로 잡았다.

프로젝트를 수정한 뒤에는 변경 파일을 확인하고 **커밋 → 푸시** 순서로 기록을 남기기로 했다. 원본 영상이나 설치 파일처럼 큰 자료는 프로젝트 소스와 별도로 관리한다.

## 3. 캡처와 원본 영상 보관 방식 정하기

작업 폴더에 날짜별 기록을 만들고 **로그·스크린샷·원본 영상·GIF**를 나눠 보관했다. 중요한 변화는 결과만 남기지 않고, 문제가 생긴 화면과 수정한 화면도 함께 모으기로 했다.

10초 시험 녹화와 GIF를 실제로 만들고 재생했다. 파일이 생성되는 것뿐 아니라 영상과 이미지가 정상적으로 열리는지까지 살펴봤다.

## 4. 디렉터스 컷에서 게임 아이디어 시작

잼 주제인 **디렉터스 컷**을 감독의 입장에서 게임을 다시 편집하는 의미로 받아들였다. 화면으로 보고 생각을 전달하면서 AI와 제작하는 과정을 기록하고, 이후 콘서트 여행 게임의 기획으로 이어갈 준비를 했다.
