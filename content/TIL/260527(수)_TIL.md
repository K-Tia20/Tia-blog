**1)델리게이트**

> **델리게이트**“특정 상황이 발생했을 때 연결된 함수를 대신 실행해주는 기능”

- 어떤 이벤트(공격, 버튼 클릭, 체력 감소 등)가 발생하면
- 미리 등록된 함수를 자동으로 호출하는 방식

```cpp
#include <iostream>
using namespace std;

// 함수 포인터 선언
void (*Delegate)();

// 실행될 함수
void Attack()
{
    cout << "공격 실행!\n";
}

void Heal()
{
    cout << "회복 실행!\n";
}

int main()
{
    // 공격 함수 연결
    Delegate = Attack;
    Delegate();

    // 회복 함수 연결
    Delegate = Heal;
    Delegate();

    return 0;
}
```

언리얼 엔진에서도 UI 버튼 클릭, 충돌 이벤트 등에서 많이 사용된다.

**2)콘솔 오디오 기능 구현**

```cpp
#include <windows.h>   // Windows 기능 사용
// - 창 생성
// - 키보드 입력 감지
// - 마우스 입력
// - 시간 제어
// - 프로세스 제어
// - 사운드 재생
#include <mmsystem.h>  // PlaySound 함수 사용
// - PlaySound()
// - waveOut()
// - MIDI 기능
// PlaySound() 함수 사용

#pragma comment(lib, "winmm.lib") // 사운드 라이브러리 연결

int main()
{
    // PlaySound 기본 구조
    // PlaySound(사운드파일, 모듈정보, 재생옵션);

    PlaySound(
        // 1번째 자리
        // 재생할 wav 파일 이름
        // L은 유니코드 문자열 의미
        // 현재 프로젝트 폴더 안의 bgm.wav 파일 재생
        L"bgm.wav",

        // 2번째 자리
        // 사운드를 어디서 가져올지 설정
        // NULL은 외부 wav 파일에서 직접 읽겠다는 의미
        // 콘솔 프로젝트에서는 대부분 NULL 사용
        NULL,

        // 3번째 자리 : 재생 옵션 -> "|" 는 옵션 여러 개를 동시에 사용하는 의미다.
        // 사운드를 어떤 방식으로 재생할지 설정

        // SND_FILENAME
        // 파일 이름으로 사운드를 재생

        // SND_ASYNC
        // 프로그램을 멈추지 않고
        // 백그라운드에서 재생

        // SND_LOOP
        // 음악이 끝나면 계속 반복 재생

        SND_FILENAME | SND_ASYNC | SND_LOOP
    );

    // 프로그램을 3초 동안 멈춤
    // 단위는 밀리초(ms)
    // 1000 = 1초
    // 음악 재생 시간 확보용
    Sleep(3000);

    // 현재 재생 중인 사운드 종료
    // NULL을 넣으면 모든 사운드 정지
    PlaySound(NULL, 0, 0);

    // 프로그램 종료
    return 0;
}
```

**3. 문제/오류/해결**

**문제 :**

콘솔 BGM 테스트 코드에서

마지막 전투 효과음(SE)이 출력되지 않는 문제가 발생했다.

**오류 :**

효과음 재생 직후 프로그램이 바로 종료되면서

사운드가 끝까지 재생되지 못한 것으로 확인되었다.

**해결 :**

효과음 재생 이후 잠시 대기 시간을 추가했다.

```cpp
Sleep(1000);
//프로그램을 1초 동안 멈춘다

// Sleep(1000); 은 프로그램을 잠시 멈추는 함수
// Windows 환경에서는 보통 #include <windows.h> 헤더를 사용한다.
// 단위는 밀리초(ms) 이다. 1000ms = 1초
```

이를 통해 효과음이 재생될 시간을 확보하여 문제를 해결했다.
