## \[내일배움캠프 사전캠프 1일차\] Unreal이란 무엇인가요?

[네이버 원본](<https://blog.naver.com/greentea_icecream/224234539270>) · 16:30

**1. Unreal Engine의 기본 개념과 역할에 대해 이해합니다.**

**1-1. Unreal Engine의 기본 개념 :**

세계에서 가장 개방적이고 진보된 리얼타임 제작 툴

**1-2. Unreal Engine의 역할 :**

AAA게임, 인디 게임, 모바일 게임, 포트나이트 언리얼 에디터, 영화&TV, 방송&라이브 이벤트, 애니메이션, 건축, 자동차, 시뮬레이션, HMI, 디지털 트윈

**1-3. Unreal Engine**의 주요 기능 **:**

**① 그래픽 렌더링 (Rendering):**

빛, 그림자, 반사 등을 계산하여 3D 데이터를 실시간 이미지로 변환하는 기술

② **물리 엔진 (Physics):**

충돌, 힘, 중력 등을 계산하여 현실과 유사한 움직임을 구현하는 시스템

**③ 비주얼 스크립팅 (Blueprint):**

노드 기반으로 코드를 시각화하여 프로그램 로직을 구성하는 도구

**④ C++ 프로그래밍:**

엔진과 게임 기능을 직접 구현하는 기반 프로그래밍 언어

**⑤ 애니메이션 시스템:**

캐릭터와 오브젝트의 움직임을 정의하고 자연스럽게 재생하는 시스템

**⑥ UI 시스템 (UMG):**

사용자 인터페이스를 구성하고 화면에 표시하는 시스템

**1-4. Unreal Engine**의 장점과 단점 **:**

**\[장점\]**

**①고품질 그래픽**

실시간으로 영화 수준의 사실적인 그래픽 구현 가능

②**Blueprint 지원**

코딩 없이도 로직 구현 가능 → 초보자 접근성 높음

**③강력한 C++ 기반**

성능 최적화와 세밀한 제어 가능

**④다양한 분야 활용**

게임뿐 아니라 영화, 건축, 시뮬레이션 등 확장성 높음

**⑤무료 사용 + 로열티 구조**

초기 비용 없이 시작 가능 (일정 수익 이상 시 로열티)

**\[단점\]**

**①높은 학습 난이도**

기능이 많아 구조 이해에 시간 필요

②**무거운 엔진**

사양 요구가 높고 빌드/실행이 느릴 수 있음

**③C++ 진입 장벽**

깊이 있는 개발을 위해서는 C++ 학습 필요

**④프로젝트 용량 큼**

기본 프로젝트도 용량이 큰 편

**⑤모바일 최적화 난이도**

경량화 작업이 필요하고 최적화가 까다로움

**2. 게임씬(Game Scene)의 개념과 게임개발에서의 중요한 부분에 대해 알아봅니다.**

**2-1. 게임씬(Game Scene)의 개념 :**

게임 개발에서 특정 상태나 공간을 구성하는 기본 단위(Unreal에서는 Level)

**2-2. 게임개발에서의 중요한 부분 :**

게임씬은 캐릭터, 배경, UI 등 모든 요소를 포함하며, 게임의 흐름을 구성하고 장면을 구분하는 중요한 역할을 한다.

**2-3. Unreal Engine의 게임 레벨(Level) 구성 요소 :**

레벨(Level)은 게임에서 하나의 공간(맵)이며, 게임이 진행되는 기본 단위이다.

**World**

레벨 전체를 관리하는 최상위 공간 (모든 요소를 포함)

**Actor**

레벨에 배치되는 모든 객체 (캐릭터, 오브젝트 등)

**Light**

장면의 밝기와 분위기를 결정하는 조명 요소

**Camera**

플레이어가 화면을 통해 보는 시점을 결정

**3. Unreal Engine이 게임 산업에서 사용되는 사례를 찾아보고 탐구합니다.**

**3-1. Unreal Engine이 게임 산업에서 사용되는 사례 :**

**\[아키에이지 크로니클\]**

대규모 오픈월드 구성

실시간 그래픽 및 물리 처리

멀티플레이 환경 지원

**\[PUBG: Battlegrounds\]**

대규모 맵과 전투를 위한 실시간 렌더링 처리

총기, 차량, 낙하 등 물리 시스템 구현

넓은 오픈월드에서 안정적인 프레임 유지

**\[옥토패스 시리즈\]**

2D 픽셀 + 3D 환경을 결합한 HD-2D 그래픽 구현

조명, 그림자 등을 활용한 입체적인 연출

Blueprint 등을 활용한 빠른 개발 및 반복 작업

**\[오딘: 발할라 라이징\]**

모바일 환경에서도 고품질 그래픽 구현

광활한 필드와 캐릭터를 처리하는 렌더링 성능 제공

MMORPG 특성에 맞는 대규모 환경 표현
