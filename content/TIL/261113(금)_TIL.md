### 오늘 한일

**실제 마이크 입력과 첫 게임 UI 연결**

기획을 문서로 정리하고, 월드와 분리한 **기능 시험 맵에서 첫 플레이 흐름**을 만들었다.

- 노래·타자 공연, 선물과 팬심, 동료, 영감 성장의 규칙을 정리했다.
- 12초 시험곡으로 마이크 음정·박자 채점과 Enter로 입력하는 박자 타자를 연결했다.
- 마이크 접근 권한과 첫 오디오 버퍼 처리 문제를 고치고, 직접 노래한 입력이 결과와 보상까지 이어지는 것을 확인했다.
- 메인 메뉴부터 저장 슬롯까지 PC용 UI 9개 화면을 정리하고 WBP에 반영했다.
- UI 문구는 이미지에 고정하지 않고 String Table로 관리하는 방향을 잡았다.

![[TIL/첨부파일모음/20261113-sinbi-mic.jpg|700]]

초기 공연 시험 화면이다. 이때는 짧은 시험곡으로 입력과 정산부터 연결했다.

**오늘 배운 점**  
버튼이 보이는 것과 기능이 작동하는 것은 다르다. ‘입력 → 판정 → 결과 → 보상’을 끝까지 이어서 실행해 봐야 빠진 부분이 드러났다.
