# 기능 1~33번을 실제 플레이 중심 영상으로 만들기

블로그의 기능 소개 1~33번을 한 편의 영상으로 묶었다. 먼저 1~2번 미리보기의 구성을 맞춘 뒤, 실제 플레이 장면에 핵심 설명을 얹는 방식으로 전체 구간을 편집했다.

## 1. 기능 번호와 제목을 같은 자리에 고정

제목과 설명이 배경에 묻히지 않도록 어두운 둥근 상자를 사용했다. 번호는 보라색 칸 중앙에 크게 놓고, 기능 제목은 화면 상단의 같은 자리에서 **7초씩** 보이게 했다.

![[TIL/첨부파일모음/20261118-sinbi-feature02.jpg|700]]

기능이 바뀔 때마다 제목을 읽을 시간을 주고, 아래 설명은 짧게 나눴다. 화면만 넘기는 구성보다 설명하는 순간에 해당 기능이 실행되는 장면을 보여 주도록 맞췄다.

## 2. 최신 게임 화면 추가 촬영

최신 패키지를 열어 메뉴·파티의 캐릭터 프리뷰·가방·일기·설정·사용 에셋 화면을 추가로 촬영했다. 이동과 전투처럼 움직임이 중요한 기능에는 기존 플레이 영상의 해당 장면을 활용했다.

삭제·보류한 기능은 현재 게임의 기능처럼 보이지 않도록 구분했다. 엔딩 소개에 사용한 바로 보기 장면도 전체 퀘스트를 새로 완료한 영상과는 구분했다.

## 3. 영상에서 제목이 사라진 문제 수정

서로 다른 녹화 영상이 이어지는 구간에서 일부 제목이 사라졌다. 영상별 색 정보와 범위가 섞인 부분을 정리하고, 같은 기준으로 변환한 뒤 다시 렌더링했다.

CapCut에서는 그래픽을 같은 트랙에 겹쳐 넣으면서 영상 길이가 늘어나는 문제도 생겼다. 제목·설명·상태 표시를 별도 트랙으로 나누고, 실제 편집기에서 길이와 표시 시점을 다시 맞췄다.

## 4. 13분 30초 기능 소개 영상 공개

완성본은 **1920×1080, 약 13분 30초**로 정리했다. 내레이션과 조용한 반주를 넣고 YouTube 설명에 기능 1~33번 타임스탬프를 작성했다.

Codex를 이용한 제작, Gemini의 여섯 곡과 반주, AI 내레이션, fal 오프닝 사용을 설명에 명시하고 공개 게시했다.

## 5. 옵시디언 커밋 버튼 동작 정리

TIL을 수정했는데도 체크 버튼이 눌리지 않았다. 커밋 메시지의 문제가 아니라, 변경 파일을 커밋 대상으로 올리는 **스테이징**이 비어 있고 자동 스테이징이 꺼져 있었기 때문이다.

스테이징이 비어 있을 때 체크 버튼으로 변경 파일을 올리고 커밋할 수 있도록 설정했다. 이때는 보관함의 다른 변경 파일도 함께 대상이 될 수 있으므로 목록을 먼저 살펴봐야 한다. GitHub에 올리는 푸시는 위 화살표로 별도로 실행하고, 자동 푸시는 계속 꺼 두었다.
