- **range-for문**

**for (const auto& x : container)**

**:컨테이너의 모든 요소를 처음부터 끝까지 자동으로 순회하는 반복문**

**ex)**

```
//range-for문 예시    
// 출력
    for (const auto& pair : myMap) {
        cout << "Key: " << pair.first << ", Value: " << pair.second << endl;
    }
```

- **함수 find**

**컨테이너 내부에서 특정 원소를 찾아 해당 원소의 반복자를 반환하는 함수**

**\*#include <algorithm> // find 함수 사용**

**ex)**

```
// 함수 find 사용
// 특정 값 30을 찾음
    auto it = find(vec.begin(), vec.end(), 30);

    if (it != vec.end()) 
    {
         출력~내용~~
    }
```

- **ignore();**

**입력 버퍼에 남아있는 값을 버리는 함수**

**주로 엔터(\\n) 같은 찌꺼기 입력을 제거할 때 사용**

**ex)**

```
//ignore(); 사용 이유

cin >> a;
getline(cin, str);
//이러면 cin >> a 뒤에 남은 \n 때문에 getline이 바로 끝나는 문제 발생

cin.ignore();
getline(cin, singredient);
//버퍼에 남아있는 \n을 삭제해서
//다음 입력이 정상적으로 들어오게 함
```
