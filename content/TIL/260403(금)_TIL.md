## \[내일배움캠프 사전캠프 5일차\]콜리전 (Collision,충돌) 설정

**콜리전** **:**

오브젝트가 서로 부딪히는 것을 감지하고 처리하는 기능

**1. 시뮬레이션 중 히트 이벤트 생성\[true/false\]**

물리 충돌 발생 시 Hit 이벤트 발생 여부

ex) 충돌 감지 (예: 총알 맞음, 부딪힘)

**2.피직스 머터리얼 오버라이드\[파일 업로드\]**

물체의 “미끄러움과 튕김”을 설정하는 옵션

오브젝트에 적용된 물리 재질(Physics Material)을

기존 설정 대신 강제로 덮어쓰는 옵션

**3. 오버랩 이벤트 생성\[true/false\]**

오브젝트가 겹칠 때 Overlap 이벤트 발생

트리거, 아이템 획득 등에 사용

**4.캐릭터가 밟고 올라갈 수 있는지 여부\[Yes, No, (Owner)\]**

캐릭터가 해당 오브젝트 위에 올라갈 수 있는지 설정

계단, 박스 등

**5.콜리전 프리셋**

미리 정의된 충돌 설정 선택

|  |  |  |
| --- | --- | --- |
| 프리셋 | 설명 | 용도 |
| Default | 프로젝트 기본 콜리전 설정 사용 | 일반 오브젝트 |
| Custom | 사용자가 직접 설정 | 세부 조정 필요 시 |
| NoCollision | 충돌 없음 | 완전 통과 |
| BlockAll | 모든 것과 충돌 | 벽, 바닥 |
| OverlapAll | 모든 것과 겹침 | 트리거 영역 |
| BlockAllDynamic | 동적 오브젝트 기준 충돌 | 움직이는 물체 |
| OverlapAllDynamic | 동적 오브젝트와 겹침 | 이벤트 영역 |
| IgnoreOnlyPawn | Pawn(캐릭터)만 무시 | 캐릭터만 통과 |
| OverlapOnlyPawn | Pawn만 오버랩 | 캐릭터 감지 |
| Pawn | 캐릭터용 충돌 설정 | 플레이어/NPC |
| Spectator | 모든 것 통과 | 자유 카메라 |
| CharacterMesh | 캐릭터 메쉬용 충돌 | 캐릭터 외형 |
| PhysicsActor | 물리 오브젝트 | 떨어지는 물체 |
| Destructible | 파괴 가능 오브젝트 | 부서지는 오브젝트 |
| InvisibleWall | 보이지 않는 벽 (정적) | 맵 경계 |
| InvisibleWallDynamic | 보이지 않는 벽 (동적) | 이동 경계 |
| Trigger | 오버랩 전용 | 감지 영역 |
| Ragdoll | 물리 캐릭터 | 시체 |
| Vehicle | 차량용 충돌 | 자동차 |
| UI | UI 전용 충돌 | UI 요소 |

**\*Custom :**

**콜리전 활성화됨 (Collision Enabled)**

|  |  |
| --- | --- |
| **옵션** | **설명** |
| No Collision | 충돌 없음 (완전히 무시) |
