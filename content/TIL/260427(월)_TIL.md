- 이후에도 타이머가 계속 감소

+

- 플레이어 HP가 0이 되어 사망(패배) 처리됨
- 하지만 타이머는 계속 진행되어 추가로 패배 로직이 다시 실행됨

**오류:**

- 승리 / 패배 로직이 각각 독립적으로 실행됨
- 게임 종료 이후에도:
- 타이머(Timer / Tick)가 계속 동작
- 패배 조건이 계속 검사됨
- 즉, 게임 종료 상태를 통제하는 공통 기준이 없음

**해결:**

1. 게임 종료 상태 변수 통합 : IsGameOver (Boolean)

2. 모든 승리 / 패배 로직에 공통 가드 추가

UpdateRemainingTime 이벤트 노드

: Branch (IsGameOver) true → 아무것도 실행 안함/ false → 아래 로직 실행

OnAntKilled, OnPlayerDeath 이벤트 노드 : set is game over 노드 추가
