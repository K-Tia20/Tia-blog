## \[내일배움캠프 사전캠프 7일차\]레벨 생성 및 기본 오브젝트 배치

**\[레벨 생성 및 기본 오브젝트 배치\]**

**1. 오늘 배운 개념 요약**

**레벨 (Level) :**

게임 내 하나의 맵(공간)이며, 프로젝트 안에 여러 개가 존재하고 각각 독립된 씬처럼 작동

**Static Mesh :**

움직이지 않는 3D 오브젝트이며, 레벨은 여러 Static Mesh를 조합해 구성됨

**2. 구현 과정**

**\[Step 1\] 새 레벨 만들기**

언리얼 에디터에서 File → New Level → Basic 선택

레벨 저장: MyFirstLevel이라는 이름으로 저장

![[첨부파일모음/naver-224243944157-44e10f6f5176.png]]

![[첨부파일모음/naver-224243944157-8fde0fe57caa.png]]

**\[Step 2\] 바닥 만들기**

Place Actors 패널에서 Cube 선택

바닥 역할로 사용할 큐브를 배치하고 Scale을 아래처럼 조정

X: 20, Y: 20, Z: 0.5

![[첨부파일모음/naver-224243944157-b9bc083321f8.png]]

![[첨부파일모음/naver-224243944157-9f56b2ac8199.png]]

![[첨부파일모음/naver-224243944157-6d104497b95e.png]]

**\[Step 3\] 벽 만들기**

Cube를 4개 더 추가해서 네 방향에 벽처럼 배치

각 벽은 높이(Z)를 3.0, 길이(X 또는 Y)는 20으로 설정

![[첨부파일모음/naver-224243944157-8dad35258bd4.png]]

![[첨부파일모음/naver-224243944157-338e0c2f5023.png]]

**\[Step 4\] 오브젝트 배치 연습**

테이블이나 의자처럼 보이도록 작은 큐브를 만들어 배치

다양한 Mesh(예: Cylinder, Sphere)로 오브젝트 감각 익히기

![[첨부파일모음/naver-224243944157-cee4daa9eab2.png]]

사각 테이블

![[첨부파일모음/naver-224243944157-674eebb58871.png]]

원형 의자

**\[Step 5\] 카메라 시점 바꾸기**

뷰포트 조작 (마우스 우클릭 + W/A/S/D)으로 공간 둘러보기

오브젝트 위치와 크기 확인, 어색하면 수정해보기

![[첨부파일모음/naver-224243944157-9f05297858e3.png]]

**3. 느낀 점 & 개선하고 싶은 점**

디테일 >트랜스폼>위치로 위치를 변경했으나 뭔가 어색함

실린더가 스케일만 변화 주고서는 길쭉만해졌다

## \[내일배움캠프 사전캠프 7일차\]조명과 머티리얼 기본 적용

**\[조명과 머티리얼 기본 적용\]**

**1.오늘 배운 개념 요약**

**조명(Light) 종류 :**

Directional Light: 태양빛처럼 전체 씬에 영향을 줌

Point Light: 전구처럼 특정 위치에서 빛을 방사함

Spot Light: 특정 방향으로 빛을 집중시킴

**머티리얼(Material) :**

오브젝트에 적용되는 재질로, 색상뿐 아니라 반사, 광택, 질감 등 표현 가능

Material Instance를 사용하면 기존 머티리얼을 빠르게 커스터마이징 가능

**1.구현 과정**

**\[Step 0\] 프로젝트 생성**

File → New Project → Games → Third Person(또는 Blank) 선택

❗️Starter Content 체크❗️

프로젝트 이름 지정 후 Create 클릭

![[첨부파일모음/naver-224243987317-9b584943da6d.png]]

![[첨부파일모음/naver-224243987317-0bf78f0bab95.png]]

**\[Step 1\] 조명 추가**

Directional Light 하나 배치 (태양 역할)

Place Actors → Lights → Directional Light 드래그 앤 드롭

Point Light 2개 이상 배치해 내부 조명 효과 확인

각 라이트의 밝기(Intensity)와 색상(Color) 조정해보기

![[첨부파일모음/naver-224243987317-04e3d8a00c3b.png]]

![[첨부파일모음/naver-224243987317-c2bc335a8da9.png]]

![[첨부파일모음/naver-224243987317-83a078129f7a.png]]

![[첨부파일모음/naver-224243987317-62c5f034f2fd.png]]

**\[Step 2\] 머티리얼 적용**

StarterContent > Materials 폴더에서 다양한 머티리얼 확인

바닥에는 M\_Metal\_Gold, 벽에는 M\_Concrete\_Poured 등 각각 다르게 적용

필요 시 Material Instance 만들어 색상만 바꿔보기

![[첨부파일모음/naver-224243987317-de882f6046a1.png]]

![[첨부파일모음/naver-224243987317-b48f45b9b47e.png]]

**\[Step 3\] 라이트의 그림자 확인**

다양한 위치에 오브젝트를 배치하고, 빛이 어떻게 반응하는지 확인

그림자 방향, 세기 등을 조정하며 결과 비교

![[첨부파일모음/naver-224243987317-8b75dbc30854.png]]

**3.느낀 점 & 개선하고 싶은 점**

빛의 밝기와 색상을 상황에 맞게 조절하는 것이 생각보다 까다롭게 느껴졌다. 앞으로 다양한 조명 연출을 연습해보고 싶다.
