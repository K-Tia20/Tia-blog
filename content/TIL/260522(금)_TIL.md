**2. 문제/오류/해결**

```
#include "player.h"
```

**문제 :**

코드에서 오류 표시가 발생함.

**오류 :**

현재 작업 중인 파일과 player.h 파일의 위치가 달라

상대 경로를 제대로 찾지 못한 문제였다.

```
#include "./player.h"
#include "../player/player.h"
```

**해결 :**

경로 개념을 다시 정리함.

- ./    (현재 파일 위치)
- ../   (상위 폴더로 이동)

또한 파일을 불러올 때는

파일 위치에 따라 상대 경로를 정확하게 작성해야

**3. 개선/목표**

단순히 코드를 작성하는 것보다

파일 구조와 경로를 이해하는 것이 협업에서 매우 중요하다는 것을 느꼈다.

특히 깃허브 협업에서는

폴더 구조와 파일 위치가 달라질 수 있기 때문에

경로를 제대로 이해하지 못하면 오류가 쉽게 발생한다는 점을 배웠다.

현재 팀에서 맡은 역할은 깃 관리와 로그 출력이다.

내일부터는 팀원들이 작성한 함수와 변수들을 하나씩 직접 읽어보며:

- 함수 역할 이해하기
- 변수 사용 이유 파악하기
- 코드 흐름 분석하기
- 상황과 컨셉에 맞는 로그 출력 추가하기

를 목표로 학습할 예정이다.

특히 단순히 사용하는 것이 아니라

“왜 이렇게 작성했는지”를 이해하는 방향으로 공부할 계획이다.
