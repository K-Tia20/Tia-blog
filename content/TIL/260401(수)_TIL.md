## \[내일배움캠프 사전캠프 3일차\]Unreal 엔진 블루프린트 프로그래밍 기초 용어 정리

![[첨부파일모음/naver-224237237058-602b34ef5924.png]]

사전캠프 3조^0^

**1. 기본 구성 요소**

**노드 (Node)** : 기능 하나를 수행하는 블록

**핀 (Pin)** : 노드 간 데이터를 연결하는 지점 (입력/출력)

**그래프 (Graph)** : 노드들이 연결된 작업 공간

**이벤트 그래프 (Event Graph)** : 이벤트 기반 로직을 작성하는 대표 그래프

**2. 핵심 개념**

**액터 (Actor)** : 레벨에 배치되는 모든 오브젝트

**레벨 (Level)** : 하나의 게임 맵/공간

**변수 (Variable)** : 데이터를 저장하는 공간

**함수 (Function)** : 특정 기능을 묶어 재사용하는 블록

**매크로 (Macro)** : 여러 노드를 묶은 재사용 로직 (함수보다 자유도 높음)

**이벤트 디스패처 (Event Dispatcher)** : 다른 블루프린트와 이벤트 연결

**3. 이벤트 관련**

**이벤트 (Event)** : 특정 상황에서 자동 실행되는 시작 지점

**Event BeginPlay** : 게임 시작 시 1번 실행

**Event Tick** : 매 프레임마다 반복 실행

**4. 변수 & 자료형**

**Int (Integer)** : 정수 (예: 1, 10)

**Float** : 소수 포함 숫자 (예: 1.5)

**Bool** : 참 / 거짓 (True / False)

**String** : 문자열 (텍스트)

**Vector** : 3D 위치/방향 값 (X, Y, Z)

**5. 자주 쓰는 노드**

**Print String** : 화면에 텍스트 출력 (디버깅용)

**In String** : Print String 노드 내에서 출력할 내용을 적는 곳

![[첨부파일모음/naver-224237237058-0aa9c2e70771.png]]

**6. 흐름 제어 노드**

**Branch** : 조건에 따라 실행 분기 (if문)

**Sequence** : 여러 실행을 순서대로 처리

![[첨부파일모음/naver-224237237058-b68b49bf1826.png]]

**For Loop** : 일정 횟수 반복

**For Loop with Break** : 조건 만족 시 반복 중단

**For Each Loop** : 배열 요소 하나씩 반복

**While Loop** : 조건이 참인 동안 반복

![[첨부파일모음/naver-224237237058-38312660c2dc.png]]

**7. 기타 중요 개념**

**컴파일 (Compile)** : 블루프린트 오류 체크 및 적용

![[첨부파일모음/naver-224237237058-6db27f45c4eb.png]]

**메인 툴바 (Main Toolbar)** : 실행, 컴파일 등 주요 버튼 영역

![[첨부파일모음/naver-224237237058-9413a6684a2d.png]]

**오버라이드 (Override)** : 부모 기능을 자식에서 재정의

![[첨부파일모음/naver-224237237058-0fb07141ae9f.png]]

자식에서 BeginPlay 만들면 부모 BeginPlay는 무시

**클래스(Class)**: 액터를 만들기 위한 설계도

![[첨부파일모음/naver-224237237058-1e7ee8158979.png]]

**컴포넌트(Component)**: 액터에 붙여서 기능을 더하는 부품

(예: 스태틱 메시, 라이트, 사운드 등)

![[첨부파일모음/naver-224237237058-2bcb4e01772a.png]]

클래스 구조 확인

**1. 프로젝트 생성 단계 주요 흐름**

**②**템플릿 선택 (유형 : 기본, 일인칭, 삼인칭, 내려보기, 비히클 등)

**뷰포트 (Viewport)**

**아웃라이너 (Outliner)**
