**기계어(Low-Level Language, Machine Language):**

**어셈블리어(Assembly Language):**

기계어를 사람이 읽기 쉽게 표현한 언어로, 기계어와 거의 1:1 대응

**고급 언어(High-Level Language):**

사람이 이해하기 쉽게 만든 언어

ex) C++, Java, Python

**소스코드(Source Code):**

프로그래머가 고급 언어로 작성한 코드

**빌드 프로세스(Build Process):**

소스코드를 실행 가능한 프로그램으로 바꾸는 과정

[이미지 원본](<https://img.notionusercontent.com/s3/prod-files-secure%2F83c75a39-3aba-4ba4-a792-7aefe4b07895%2F2349f50f-3311-4a1e-b022-4d5c1fd7a535%2Fimage.png/size/w=2000?exp=1776657293&sig=i-iUCu2mPJslYraDeBePHZElSBNYaT5d-kPlkorZVUE&id=3482dc3e-f514-8062-be09-f89fc67eb7fa&table=block&userId=32dd872b-594c-8198-9d40-0002b9c03646>)

**\[Compile\]**

**컴파일:**

**→ 소스코드를 기계어로 변환하는 과정**

1. 확장된 소스코드가 어셈블리 코드로 변환되는 과정.
2. 소스코드로부터 오브젝트 코드까지의 과정.

**빌드(Build):**

컴파일+링킹

링킹)여러 오브젝트 코드와 라이브러리를 하나로 합쳐 실행파일을 만드는 과정

[이미지 원본](<https://img.notionusercontent.com/s3/prod-files-secure%2F83c75a39-3aba-4ba4-a792-7aefe4b07895%2F9e79f991-b7c4-4b53-82fa-3a745f5d8a16%2Fimage.png/size/w=2000?exp=1776657625&sig=Y0vRtkneoy5dFTzbEAjNCAiJIlYamWQTGvlf7XPy2v8&id=3482dc3e-f514-80e4-a244-f89b4e0efa58&table=block&userId=32dd872b-594c-8198-9d40-0002b9c03646>)

**컴파일러:**

**→ 소스코드를 오브젝트 코드(기계어)로 변환하는 프로그램**

1. 확장된 소스코드를 어셈블리 코드로 변환해주는 프로그램.
2. 소스코드로 실행파일까지 만들어 주는 프로그램.

**솔루션 - 프로젝트 - 소스코드:**

**솔루션** : 여러 프로젝트를 묶는 최상위 단위

**프로젝트** : 하나의 실행 프로그램(또는 라이브러리)을 만드는 단위\[.exe 등\]

**소스코드** : 개발자가 작성한 코드 파일\[.cpp, .h, .c 등\]

**\[main() 함수와 printf() 함수\]**

**main() 함수:**

프로그램의 시작점(Entry Point)

```
// Main.c

int main(void)
{


	return 0;
}
```

**printf() 함수:**

print formatted의 약자(형식 지정 출력 함수)

```cpp
// Main.c

#include <stdio.h>

int main(void)   // stdio는 공구통 이름. #include는 공구통을 포함시키라는 명령어.
{
	printf("Hello, world!"); // stdio라는 공구통 안에 든 printf()라는 망치를 사용하는 예시.

	return 0;
}
```

**탈출 문자열(Escape Sequence):**

|  |  |
| --- | --- |
|  | 출력 |
| \\n | 개행(New line) |
| \\t | 탭(Tap) |
| \\’ | 따옴표 출력 |
| \\” | 쌍따옴표 출력 |
| \\\\ | 역슬래시 출력 |
| %% | % 출력 |

**두 가지 좋은 습관:**

1. 문 열고 닫기 →  {    }
2. 들여 쓰기

## \[내일배움캠프 1일차\]Day 1: UE5 에디터 기초 & FPS 캐릭터 생성

[네이버 원본](<https://blog.naver.com/greentea_icecream/224258870816>) · 16:21

**\[핵심 정리\]**

|  |  |
| --- | --- |
| **에디터** | 뷰포트(3D 화면), 아웃라이너(배치 목록), 디테일(속성 편집), 콘텐츠 브라우저(파일 관리) |
| **블루프린트** | 코드 대신 노드를 연결해서 로직을 만드는 비주얼 스크립팅 |
| **핀** | 실행 핀(흰색) = 순서, 데이터 핀(색상별) = 값 전달 |
| **액터 vs 캐릭터** | 액터 = 레벨에 놓을 수 있는 물체, 캐릭터 = 이동/입력이 가능한 액터 |
| **컴포넌트** | Camera, SkeletalMesh, SceneComponent 등을 조합해서 캐릭터를 구성 |
| **소켓** | 뼈(Skeleton)에 부착 지점을 만들어서 총 같은 오브젝트를 손에 고정 |
| **FAB** | 무료 에셋을 검색해서 프로젝트에 바로 추가 |
| **변수 타입** | Float = 소수점 있는 숫자, Integer = 정수, Boolean = true/false |
| **조작법** | 컴파일 = 변경사항 적용, PIE = 게임 실행, F8 = 빙의 해제 |

**\[과제 : 새로운 프로젝트 생성 후 오늘 배운 내용 다시 복습\]**

**In String** : 출력할 문자열, 변수 값도 연결 가능

**Print to Screen** : 화면에 텍스트 출력 여부, 체크 시 좌측 상단 등에 표시됨

**Print to Log** : 출력 로그에 기록할지 여부, Output Log 창에서 확인 가능

**Text Color** : 출력 텍스트 색상 설정

**Duration** : 화면에 표시되는 시간 (초 단위)

**Key** : 같은 Key를 사용하면 기존 메시지를 덮어씀, 워두면 계속 새 메시지 생성

**5. Scalability Group(스칼라빌리티 그룹)**

게임의 그래픽 품질(성능 ↔ 화질)을 조절하는 설정 묶음

- View Distance: 멀리 보이는 거리
- Anti-Aliasing: 계단현상(픽셀 깨짐) 완화
- Post Processing: 블룸, 색감 등 화면 후처리 효과
- Shadows: 그림자 품질
- Global Illumination: 간접광(빛 반사로 생기는 전체 밝기) 품질
- Reflections: 반사 표현 품질 (물, 거울 등)
- Textures: 텍스처 해상도
- Effects: 파티클, 폭발 등 이펙트 품질
- Foliage: 풀, 나무 등 식생 밀도
- Shading: 표면의 빛 표현(명암, 재질) 품질
- Landscape: 지형 디테일 및 품질
