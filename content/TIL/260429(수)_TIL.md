**2. 배운 내용**

**1) 헤더(.h) include 순서**

```
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "MyActor04080211.generated.h"
```

**\[기반\]**

- **CoreMinimal.h**

→ 언리얼의 기본 타입/매크로 (FString, FVector 등) 포함

→ 가장 먼저 와야 함

**\[확장\]**

- **Actor.h**

→ 내가 상속받을 클래스 (AActor) 정의

**\[자동생성\]**

- **generated.h (항상 마지막)**

→ 언리얼 빌드 툴(UHT)이 자동 생성하는 코드

→ UCLASS, GENERATED\_BODY() 같은 기능 연결됨

**2. 클래스 선언 구조**

```
class MYPROJECT_API AMyActor04080211 : public AActor
{
    GENERATED_BODY()
};
```

**\[구성 요소 설명\]**

- **MYPROJECT\_API**

→ DLL export/import 용

→ 다른 모듈에서도 이 클래스를 쓸 수 있게 함

→ (지금은 "붙어있는 것" 정도로 이해하면 충분)

- **AMyActor04080211**

→ 클래스 이름

→ A = Actor 계열 클래스라는 의미

- **: public AActor**

→ 상속 (Inheritance)

→ Actor 기능을 그대로 물려받음

- **GENERATED\_BODY()**

→ 언리얼 리플렉션 시스템 연결

→ 없으면 컴파일 에러

**3. .h / .cpp 역할 구분**

- **.h (헤더 파일) → 구조 정의**

“설계도”

변수, 함수 선언

- **.cpp (구현 파일) → 기능 구현**

“실제 동작”

함수 내용 작성

**4. FVector에서 F가 붙는 이유**

- **결론 : 구조체라서 + 언리얼 네이밍 규칙**
- **언리얼 네이밍 규칙\[접두어 의미\]**

|  |  |  |
| --- | --- | --- |
| **접두어** | **의미** | **예시** |
| **A** | Actor 클래스 (월드에 배치) | AMyCharacter |
| **U** | UObject 기반 클래스 | UMyComponent |
| **F** | Struct (구조체, 값 타입) | FHitResult |
| **E** | Enum | EWeaponType |
| **I** | Interface | IInteractable |
| **S** | Slate UI 클래스 | SButton |
| **T** | Template 타입 | TArray<int32>, TMap |
| **G** | 전역 변수(Global) | GEngine |
| **b** | bool 타입 | bIsDead, bCanAttack |
| **BP\_** | 일반 블루프린트 | BP\_Player |
| **WBP\_** | Widget Blueprint | WBP\_HUD |
| **ABP\_** | Animation Blueprint | ABP\_Enemy |

- **FVector는?**

**3D 좌표 구조체**(struct FVector) : **Struct라서 F**

내부 값:

float X;

float Y;

float Z;
