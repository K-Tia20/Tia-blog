7.팀장이 언리얼 엔진에서 프로젝트 생성

프로젝트 생성 시 선택 가능:(기본, 1인칭, 3인칭 등)

+ 기본 캐릭터등 미리 정해서 진행 가능

**\[Git 협업 작업 흐름 정리\]**

작업 시작 전 git pull origin : 팀 브랜치의 최신 변경 사항을 내 브랜치로 가져오기

**작업 순서**

1. git pull origin
2. 작업 진행
3. 커밋 후 Push
4. GitHub 사이트에서 Pull Request 생성 후 Merge

**협업 시 주의 사항**

**Merge 전 확인 필수**

- base 브랜치가 main인지 확인
- 반드시 팀 브랜치로 Merge 해야 함

예시:

- 잘못된 예: main
- 올바른 예: Team\_A, Develop 등 팀 브랜치

**오늘 배운 핵심**

- 협업 프로젝트는 엔진 버전 통일이 중요하다.
- 언리얼 프로젝트는 용량이 커서 Git LFS 사용이 필요하다.
- 작업 전 pull 습관이 중요하다.
- 바로 main에 머지하지 않고 팀 브랜치를 거쳐 관리한다.

**2. 개선/목표**

- 게임 기획 및 필요에셋 저장 및 구매
