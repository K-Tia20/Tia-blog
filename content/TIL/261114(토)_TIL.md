# 동료 전투와 영입, 캐릭터 동작 문제 다듬기

공연 중심의 시제품에 전투와 동료 행동을 붙였다. 
NPC가 따라오고 싸우는 흐름을 연결하면서, 캐릭터 복제·충돌·손 장식 변형처럼 실제 실행에서 나타난 문제도 함께 수정했다.

## 1. Rider와 MCP 연결

Rider에서 현재 언리얼 프로젝트를 열고 코드를 읽고 수정한 뒤 빌드하는 흐름을 연결했다. 프로젝트 모델 생성이 막혔을 때는 엔진에서 사용하는 .NET SDK 경로를 명시해 연결을 정리했다.

설치만 된 상태와 실제 프로젝트에서 사용할 수 있는 상태를 구분하고, MCP를 통한 코드 읽기·수정·빌드를 시험했다.

## 2. 공격 판정과 적의 추격

기본 공격이 애니메이션과 어긋나지 않도록 명중 시점과 사거리를 다듬었다. 
적은 감지 범위에 들어오면 추격하고, 대상이 멀어지면 원래 자리로 돌아가도록 했다.

이름과 HP바는 평소에는 숨기고, 적이 공격을 받거나 추격하는 동안 표시했다. 
동료가 HP 0이 되었을 때의 처리도 전투 상태와 함께 정리했다.

## 3. NPC를 복제하지 않고 동료로 전환

영입하면 같은 NPC가 하나 더 생기는 문제를 고치고, **현장에 있던 캐릭터가 바로 동료로 전환**되도록 했다. 적을 회유하는 R 입력도 연결했다. 이때는 적의 남은 HP 조건이 있는 방식으로 작업했다.

동료들의 몸집에 따라 따라오는 위치를 달리하고, 서로 길을 막는 충돌도 조정했다. 신비가 공격하지 않아도 동료가 적을 발견해 기본 공격하고 스킬을 사용하도록 행동과 쿨다운을 연결했다.

## 4. 자주색으로 뒤엉킨 손 장식 수정

신비의 손·팔 장식이 큰 자주색 면처럼 뒤엉키는 현상을 살펴봤다. 천 물리 상태를 초기화했을 때 형태가 돌아오는 것을 확인하고, 순간 이동이나 큰 자세 전환 뒤 상태를 다시 잡도록 보완했다.

HP가 0이 되면 짧게 노래하고 카메라가 신비 주위를 돈 뒤, 로딩 화면을 거쳐 마을로 돌아가도록 했다. 복귀 시 HP·MP는 각각 20이 되고 소지품과 골드는 유지한다.

## 5. 캐릭터 카탈로그와 소품 제작

캐릭터 외형·애니메이션·원본 팩을 살펴볼 수 있도록 카탈로그를 정리했다. 외부 에셋은 참조가 끊기지 않게 원래 경로를 유지하고, 게임에서 사용하는 설정과 블루프린트를 별도로 관리했다.

공연용 스탠딩 마이크는 Meshy로 생성한 뒤 Blender에서 보정했다. 생성 원본, 수정본, 적용 경로를 에셋 장부에 연결해 나중에 출처와 사용 위치를 찾을 수 있게 했다.
