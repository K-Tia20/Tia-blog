**\[1. 오늘 배운 개념\]**

**내비게이션(Navigation) :**

캐릭터가 씬 안에서 자연스럽게 이동할 수 있는 공간을

지나갈 수 없는 곳은 막고, 통과 가능한 구조를 명확히 해야 게임이 부드럽게 동작

오브젝트와 캐릭터가 실제로 닿는지 아닌지를 판별해주는 시스템

벽을 뚫고 지나가지 않도록 설정하는 데 사용

## \[내일배움캠프 사전캠프 13일차\]에셋 로딩/빌드 멈춤 문제 해결

**\[에셋 로딩/빌드 멈춤 문제  이유\]**

**1. 에셋 용량 과다**

- 폴리곤 수 많음
- 텍스처 해상도 큼 (4K, 8K)

**2. Shader 컴파일 걸림**

- 새 레벨 + 새 에셋 → 쉐이더 다시 생성

**3. HDD / 느린 디스크**

- SSD 아니면 로딩 오래 걸림

**4. DDC(캐시) 문제**

- Derived Data Cache 꼬임

**5. 에셋 자체 문제**

- 깨진 FBX
- 잘못된 메쉬 데이터

**\[에셋 로딩/빌드 멈춤 문제  해결\]**

**1. 조금 기다려보기**

- CPU 사용률 확인
- 높다 → 정상 작업 중
- 낮다 → 멈춘 상태

**2. 에셋 하나씩 넣기**

- 한 번에 여러 개 넣으면 멈춤

**3. 엔진 재시작 + 캐시 초기화**

- 경로 삭제
- 프로젝트 폴더 → DerivedDataCache 삭제
- 프로젝트 폴더 → Intermediate 삭제
- 프로젝트 폴더 → Saved 삭제

**4. 문제 에셋 확인**

- 특정 에셋만 넣을 때 멈추는지 체크
- 맞으면 그 에셋 버려야 함

**5. 에셋 가볍게 만들기 (Blender)**

- 폴리곤 줄이기 (Decimate)
- 텍스처 해상도 낮추기

**6. 엔진 설정 변경**

- Nanite 꺼보기 (무거운 경우)
- Virtual Texture 비활성화 테스트

**7. SSD 사용 여부 확인**

- HDD면 거의 무조건 느림
