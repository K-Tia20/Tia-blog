**오류:**

C++ Classes에 있는 액터는 코드로 만든 “**부모 클래스**”임

**콘텐츠 폴더**에 있는 액터는 **블루프린트(자식 클래스)**임

레벨에는 반드시 블루프린트 액터를 배치해야 정상 동작함

기본 콘텐츠에 있는 Actor는 내가 만든 클래스와 무관한 기본 액터라서 배치해도 아무 동작이 없음

![[첨부파일모음/naver-224268349442-95d735159d58.png]]

**해결 및 얻은 정보:**

C++ Classes의 액터를 직접 쓰는 것이 아니라

→ 해당 클래스를 기반으로 블루프린트 생성 (Create Blueprint based on …)

생성된 블루프린트를 레벨에 배치해야 C++ 로직이 정상 실행됨

![[첨부파일모음/naver-224268349442-70bd4a91bf14.png]]

이름이 같아도 구조가 다르므로

→ 내가 만든 C++ 기반 블루프린트인지 확인 후 사용

**이미 만든 블루프린트 액터 → 다른 C++ 클래스로 부모 변경 가능**
