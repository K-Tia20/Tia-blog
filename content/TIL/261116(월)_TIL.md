# 처음부터 엔딩까지 연결하고 Windows 배포본 만들기

기능을 더 늘리기보다 새 게임에서 엔딩까지 이어지는 흐름에 집중했다. 실제 맵에서 퀘스트와 이동을 진행하며 문제를 고치고, UI·효과음·탐험 보상을 정리한 뒤 Windows 배포본을 만들었다.

## 1. Q01부터 Q50 엔딩까지 진행

새 게임에서 네 세계를 오가며 Q01부터 Q50까지 진행했다. 곡 획득과 이야기 속 노래 장면을 포함해 엔딩까지 이어지는 과정을 영상으로 남겼다. 공연 입력은 게임의 타자 모드로 진행했다.

전체 흐름에서는 따로 시험할 때 놓쳤던 문제가 드러났다. 공연 비용이 부족한 상황, NPC와 카메라의 겹침, 무대를 가리는 나무 등을 살펴보며 진행을 이어 갔다.

## 2. 최종 플레이에 맞춰 UI 줄이기

상점, 플레이어 Q 스킬, 아이템 퀵슬롯, 지도·미니맵을 최종 범위에서 제거했다. HUD는 **HP·MP·영감·인기도와 현재 퀘스트 목표**를 중심으로 정리했다.

일기에서는 지난 퀘스트를 넘겨 볼 수 있게 하고, 대상 NPC의 머리 위에는 노란 느낌표를 표시했다. 문구 길이가 달라도 상호작용 안내가 잘 보이도록 크기도 조정했다.

## 3. 보물상자와 획득 알림 마감

처음 계획했던 200개에서 범위를 조정해 **행성마다 20개씩, 총 80개 상자**로 정리했다. 지면에 묻히거나 기울어진 배치를 보정하고, 획득한 상자는 사라지며 수집 상태가 저장되도록 했다.

아이템을 받으면 화면에 **+아이템명**이 나타나게 했다. 별도 상자 대신 검정 테두리가 있는 글자로 표시해 플레이 화면을 덜 가리도록 바꿨다.

## 4. 메인 메뉴·소리·시작과 끝 연결

메인 메뉴는 인물 없는 배경으로 바꾸고 별빛을 더했다. 언어를 고르면 버튼 문구도 바로 바뀌게 하고, 선택한 메뉴를 따라 아래 강조선이 움직이도록 했다.

![[TIL/첨부파일모음/20261116-sinbi-menu.jpg|700]]

메뉴 BGM은 〈IDOL SINBI〉의 반주를 조용히 재생하고 시작·종료 때 서서히 음량이 변하게 했다. 버튼 호버·클릭음, 발소리, 상자와 공연 종료 소리도 정리했다. 캐릭터의 대사·전투 발성은 제거하고 노래와 일반 효과음은 유지했다.

fal에서 만든 오프닝을 건너뛸 수 없는 시작 영상으로 연결했다. 엔딩은 눈 클로즈업과 암전 뒤 게임 클리어를 표시하고, 계속 지내기·메인 메뉴·끝내기를 선택하는 흐름으로 구성했다.

## 5. 사용 에셋 목록과 패키징

메인 메뉴에 사용 에셋 버튼을 넣어 자료의 출처를 볼 수 있게 했다. 이후 Windows 실행 파일과 필요한 게임 데이터를 묶어 패키징했다.
