### 오늘 한일

**Q01부터 엔딩까지 이어 보고 Windows 배포본 만들기**

기능을 더 늘리기보다 **처음 시작해서 엔딩까지 이어지는 흐름**에 집중했다.

- 새 게임에서 Q01~Q50, 네 세계 이동과 여섯 곡 공연을 이어서 진행하고 영상을 남겼다. 공연은 게임의 타자 입력 경로로 진행했다.
- 상점·플레이어 Q 스킬·퀵슬롯·지도 등 최종 범위에서 뺄 기능을 정리하고 HUD와 일기를 단순하게 다듬었다.
- 보물상자 획득 후 사라지기, 아이템명 표시, 이야기 속 노래 장면의 가사를 보완했다.
- 메인 화면의 언어 전환과 선택 바, 메뉴 BGM·버튼음·발소리·공연 종료 소리를 작업했다.
- 인물 없는 메인 배경과 별빛, fal 오프닝, 엔딩 화면을 연결했다.
- 캐릭터 대사 음성은 제거하고 노래·효과음은 유지했다.
- 사용 에셋 목록을 넣고 Windows 실행 파일로 패키징했다.

배포 형태로 정리한 메인 메뉴다.

**오늘 배운 점**  
각 기능이 따로 작동해도 전체 플레이에서는 공연 비용, 이동, 대화 카메라처럼 다른 문제가 나타났다. 빌드 성공과 실제 플레이 점검도 별개의 작업이었다.
