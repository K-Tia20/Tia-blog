## \[내일배움캠프 2일차\]Day 2: C언어

**\[서식지정자\]**

|  |  |  |
| --- | --- | --- |
| **서식 지정자** | **의미** | **설명** |
| **%d** | decimal | 10진수 |
| **%o** | octal | 8진수 |
| **%x** | hexadecimal | 16진수 |
| **%u** | unsigned | 양수(부호 없는 정수) |
| **%c** | character | 문자1개 |
| **%s** | string | 문자열 |
| **%f** | floating point | 실수(float) |
| **%lf** | double precision floating point | 실수(double) |
| **\[ ex \]** |  |  |
| printf("\[%-7d\]\\n", 65536);                --> \[65536  \]<br>printf("\[%07d\]\\n", 65536);               --> \[0065536\]<br>printf("\[%+7d\]\\n", 65536);               --> \[ +65536\]<br>printf("\[%5.10f\]\\n", 3.141592);       --> \[3.1415920000\]<br>printf("\[%+20.10f\]\\n", 3.141592);   --> \[       +3.1415920000\]<br>printf("\[%-20.10f\]\\n", 3.141592);    --> \[3.1415920000        \] |  |  |

**\[리터럴\]**

Literal : 소스코드에 적힌 값

**\[자료형\]**

|  |  |  |  |
| --- | --- | --- | --- |
| 자료형 | 크기 | 표현 가능 수 | 서식 지정자 |
| char | 1byte | -128 ~ 127 | %c 또는 %hhd |
| short int | 2byte | -32768 ~ 32767 | %hd |
| int<br>\[기본 정수 자료형\] | 4byte | -2147483648~<br>2147483647 | %d 또는 %i |
| long | 4byte 또는 8byte |  | %ld |
| long long | 8byte |  | %lld |
| float | 4byte | 유효 자리수 6~7자리 | %f |
| double<br>\[기본 실수 자료형\] | 8byte | 유효 자리수 15~16자리 | %lf |
| long double | 8byte |  | %Lf |

**\[변수\]**

선언 : 자료형 변수명 = 값;

**\[ASCII\]**

문자 형태의 데이터와 숫자 형태의 데이터 사이의 인코딩 규약 중 하나

[ASCII Chart - cppreference.com](<https://en.cppreference.com/cpp/language/ascii>)

char ch1 = 'A';

printf("ch1 = %c\\n", ch1);   →  A

printf("ch1 = %d\\n", ch1);   → 65

**\[복합 대입 연산자\]**

산술연산과 대입 연산이 함께 계산되는 연산자

ex) 같음

**\[값식문\]**

값: 데이터(리터럴)

식: 계산

문: 실행되는 명령

**\[증감 연산자\]**

전치 : ++num → 당장 1증가

후치 : num++ → 다음줄에 1증가

**\[논리 연산자\]**

|  |  |  |
| --- | --- | --- |
| 종류 | 기호 | 의미 |
| 곱 연산자 | && | 둘 다 참이면 참 |
| 합 연산자 | \|\| | 하나라도 참이면 참 |
| 반전 연산자 | ! | 참은 거짓, 거짓은 참 |

**\[관계 연산자 = 비교 연산자\]**

|  |  |  |
| --- | --- | --- |
| 종류 | 기호 | 의미 |
| 같다 | == | 두 값이 같으면 참 |
| 다르다 | != | 두 값이 다르면 참 |
| 크다 | > | 왼쪽 값이 더 크면 참 |
| 작다 | < | 왼쪽 값이 더 작으면 참 |
| 크거나 같다 | >= | 왼쪽 값이 크거나 같으면 참 |
| 작거나 같다 | <= | 왼쪽 값이 작거나 같으면 참 |

**\[형변환 연산자\]**

**\[삼항 연산자\]**

세개의 항을 갖는 연산자(if-else의 대용)

Num2 = 5;

**3.Num1과 Num2중 더 큰값 출력**

**\[sizeof\]**

자료형 크기를 바이트 단위로 변환

```
//[예시]

int Num1 = 1;
int Num2 = 7;

printf("%d", sizeof(int));          --> 4
printf("%d", sizeof(Num1));         --> 4
printf("%d", sizeof(Num1 + Num2));  --> 4
```

## \[내일배움캠프 2일차\]Day 2: 캐릭터 이동 & 입력 시스템 + 조준

**\[핵심 정리\]**

|  |  |
| --- | --- |
| **개념** | **배운 것** |
| **입력 매핑 (IMC/IA)** | IMC = 입력 묶음, IA = 개별 동작 정의. IMC에서 IA와 실제 키를 연결 |
| **이동 구현** | Add Movement Input으로 이동. 앞/뒤는 Forward Vector, 좌/우는 Right Vector 사용 |
| **시선 구현** | Add Controller Pitch Input = 위/아래, Yaw Input = 좌/우 회전. 카메라의 Use Pawn Control Rotation을 끄고 Pawn 자체를 돌려야 손·총이 함께 움직임 |
| **조준 (ADS)** | 우클릭마다 IsAiming을 NOT으로 토글. Timeline + Lerp로 FOV를 90↔60 부드럽게 전환 (Play from Start 필수) |
| **Animation Blueprint + State Machine** | 캐릭터 상황에 맞는 애니메이션을 자동 재생. Locomotion 상태머신에서 Idle↔Run 전환 규칙을 Speed로 판단 |
| **Speed** **변수** | Get Velocity → Vector Length XY로 Z축 제외한 속력을 구해 변수로 저장 → 전환 규칙에 사용 |
