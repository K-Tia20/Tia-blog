# 대사별 표정과 화자 전환, 입력 UI와 몬스터 표시 개선

어제 만든 VRoid 눈 깜빡임과 NPC 입 모양을 이어서, 오늘은 대사 한 줄마다 화자와 감정을 설정할 수 있게 했다. 첫 메인 퀘스트 세 줄에서 NPC와 플레이어가 번갈아 말하는 장면으로 확인했다. 입력 장치별 UI, 몬스터와 펫의 표시 크기, 프롤로그 음악도 함께 정리했다.

## 1. 대사 한 줄에 표정 넣기

**Content Browser → IsekaiClass → Data → DataTable → NPC → DT_IC_Dialogue**를 연다.

1. 대화 행을 고르고 `Nodes`에서 `NodeID`를 찾는다. 대사는 `EntryNodeID`에서 시작해 `NextNodeID`를 따라간다. 실제 문장은 `TextKey`를 `ST_IC_Dialogue`에서 찾아 확인한다.
2. 노드의 `SpeakerNPCID`에 말할 NPC ID를 지정한다. 플레이어가 직접 말할 줄에는 `CHR_PLAYER`를 넣는다. 행 상단의 `NPCID`는 대화 상대를 지정하는 별도 필드다.
3. **Presentation → Expression**에서 기본·기쁨·미소·화남·슬픔·놀람 중 하나를 고르고, **Expression Strength**를 `0~1`에서 조절한다. 에셋을 저장한 뒤 PIE에서 확인한다.

첫 퀘스트 **이세계에 온 친구**의 친구1 재회 장면 `DLG_SCN_R01_001_READY`에 적용했다.

| 노드 | 화자 | 대사 | 표정 |
| --- | --- | --- | --- |
| `N001` | 친구1 · NPC 09 | 야! 여기야! 진짜 너 맞네! | 기쁨 `0.65` |
| `N002` | 플레이어 | 목소리만 듣고도 알겠더라. 다친 데는 없어? | 슬픔 `0.28`로 가벼운 걱정 |
| `N003` | 친구1 · NPC 09 | 없어. 숲에서 좀 헤매긴 했는데, 여관에서 재워 줬어. | 미소 `0.40` |

![[20261105-first-dialogue-player-speech.gif]]

`ICFacialAnimationComponent`는 기존 VRoid 눈썹·눈·입 모프를 섞는다. 말할 때는 감정 표정의 입 가중치를 낮추고, 대사 텍스트에서 읽은 모음을 A·I·U·E·O 입 모양으로 바꾼다. 눈을 깜빡일 때는 감정 표정의 눈 가중치도 잠시 줄인다. 근접 대화 카메라가 켜져 있으면 지정된 화자로 화면이 전환되고, 대화를 닫으면 양쪽 얼굴과 플레이 카메라가 초기화된다.

현재 감정을 지정한 범위는 위 세 줄이다. 다른 대사에 적용할 때는 `Docs/Characters/Dialogue_Expressions.ko.md`를 참고한다. 게임 에셋은 177개 대화·540줄, 저장소 CSV는 210개 대화·573줄로 집계됐다. 일괄 작업 시 최신 에셋을 먼저 내보내고 **대화 행 ID와 NodeID**를 기준으로 필요한 필드만 합치는 편이 안전하다.

## 2. 입력 장치 안내와 커서는 별도로 제어

`CommonInput`에서 마지막 입력 장치를 읽어 화면의 키 안내를 바꾼다. 메인 화면, 게임 메뉴, NPC 대화, 저장·불러오기 화면에서는 장치가 바뀌어도 마우스 커서와 클릭을 유지하고, 실제 조작 HUD로 돌아가면 커서를 숨긴다. 저장 슬롯과 확인 버튼도 마우스로 누를 수 있게 했다.

캐릭터 생성의 이름 입력은 키보드·마우스에서 텍스트 칸을 사용하고, 게임패드 입력을 받으면 화면 가상 키보드를 표시한다. 입력 장치를 바꿔도 적어 둔 이름이 이어진다.

## 3. 몬스터와 펫 크기, 보스 재질

스켈레탈 메시의 바운드 높이를 기준으로 일반 필드 몬스터 10종을 **160cm**로 맞췄다. 크기를 바꿀 때 발 위치를 다시 맞췄다. 펫은 이전 펫 기준의 0.5배로 줄여 **일반 56cm, 지역 보스 80cm**로 설정했다. 지역 보스의 필드 크기는 원래 설정을 사용한다.

**IsekaiClass → Enemy → Blueprints → Monsters → BP_R01_Boss_DragonTheUsurper**에서 메시의 0번 재질 슬롯에 `M_R01Boss_DragonGreen_Lit`를 지정했다. 기존 재질은 원본 텍스처가 Emissive에 연결돼 있었다. 새 재질은 `GreenHPTex`의 RGB를 **Default Lit → Base Color**에 연결하고 Emissive 연결을 제거했다. 필드 보스와 소환 펫이 같은 재질을 사용한다.

## 4. 프롤로그 BGM 종료 시점

프롤로그 마지막 줄을 넘기거나 길게 눌러 건너뛰면 `ICPrologueWidget`이 `EndPrologueMusic`을 호출한다. 프롤로그 음악을 그 시점에 끝내고, 오픈월드 진입 후에는 지역 BGM 전환 흐름을 사용한다.

## 5. 비교 실험으로 남긴 얼굴 직사광 보정

플레이어 남녀와 NPC 03을 대상으로 **밤 외부·밤 내부·낮 외부·낮 내부**에서 원본을 포함해 36장을 비교했다. 월드 조명과 눈 재질은 같은 조건으로 뒀다.

| 시험 | 바꾼 값과 관찰 |
| --- | --- |
| 1번 · 피부 기본색 감쇠 | 얼굴 피부의 `ICAlbedoScale`을 `0.65 → 0.60`으로 낮췄다. 밤과 실내에서도 피부가 함께 어두워졌다. |
| 4번 · 피부 하이라이트 압축 | 얼굴 피부 영역을 마스킹하고 강한 HDR 하이라이트를 압축했다. 밝은 부분에 변화가 집중됐고, 밤과 실내는 원본에 가까웠다. |

## 검증 기록

- 플레이어 남녀와 NPC 11명의 얼굴 모프, 첫 퀘스트 세 줄, 화자 카메라와 대화 종료 초기화를 포함해 대화 자동화 6건에서 실패 0건을 확인했다. 3건에는 경고가 기록됐다.
- 타이틀 진입·프롤로그 건너뛰기·몬스터 크기 자동화 3건에서 실패 0건을 확인했다. 2건에는 경고가 기록됐다.
