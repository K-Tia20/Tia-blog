# VRoid 캐릭터 밝기와 검은 선: 조명·눈·머리 재질을 나눠 해결하기

목표는 **툰 얼굴을 유지하면서 밝은 곳에서는 밝게, 어두운 곳에서는 어둡게** 보이게 하는 것이었다. 밝기만 낮춰서는 실내외 반응과 머리의 검은 선을 함께 해결할 수 없었다.

최종 선택은 **실제 조명을 받는 몸 + 원본 RGB를 쓰는 단순한 머리 표면 + 원본 눈 표현 + 캐릭터만 후처리 윤곽선 제외**다. NPC 003에서 확인한 방식을 플레이어 남·여와 NPC_R01_001~011, 총 **13개 외형**에 저장했다.

> [!note] 두 번의 ‘7번’은 다른 실험이다
> 초기 밝기 비교의 **7번은 조도 추정형 Unlit**, 8번은 단일 태양광이었다. 이후 NPC 003 머리 비교의 **7번은 원본 RGB의 단순 표면**이다. 최종 머리 재질은 두 번째 7번을 사용한다.

## 1. 먼저 밝기 조절 방법을 비교했다

Unlit은 주로 Emissive로 색을 내므로 주변이 어두워져도 표면이 같은 방식으로 빛을 받지는 않는다. Default Lit은 직접광·간접광을 받는다. **색을 어둡게 만드는 것과 조명에 반응하게 만드는 것은 다르다.** [Epic: Shading Models](https://dev.epicgames.com/documentation/en-us/unreal-engine/shading-models-in-unreal-engine)

| 초기 실험 | 결과와 한계 |
| --- | --- |
| 기준: 부위별 Lit + 툰 보조 밝기 | 외형은 유지됐지만 밤에도 몸이 배경보다 밝았다. |
| 1. Unlit 출력 × 0.35 | 전체 명도만 내려갔다. 실내외 조명 반응은 생기지 않았다. |
| 2. 역톤매핑 해제 | 피부·재킷 색이 옅어졌다. 원래 색 보존에 불리했다. |
| 3. MToon Lit | 낮밤 차이는 분명했지만 낮은 강하고 밤 표정은 너무 어두웠다. |
| 4. 피부 SSS | 밤 피부가 창백해지고 눈 주변과 대비가 커졌다. |
| 5. 캐릭터 전용 보조광 | 야간 가독성은 좋아졌지만 얼굴 음영도 바뀌었다. |
| 6. 캐릭터 화면 명도 보정 | 회색 기운과 윤곽 경계 흔적이 생겼다. |
| 7. 조도 추정형 Unlit | 태양·SkyLight·가림 검사로 밝기를 근사했다. 실제 표면 조명은 아니었다. |
| 8. 단일 태양광 | 중복 방향광의 영향을 확인했다. 낮의 배경도 달라졌고 실내 문제는 남았다. |

## 2. 몸은 Lit, 눈은 원본 RGB·알파로 분리했다

몸의 부모 재질을 전용 폴더로 복제해 색은 Base Color, 자체 발광은 0으로 보냈다. 원본 VRM4U 공용 재질은 직접 수정하지 않았다.

```text
몸: 원본 툰 색 계산 × ICAlbedoScale(0.65) → Base Color
    Emissive = 0 / Default Lit

눈·아이라인: 원본 diffuse RGB × 원본 tint RGB × 0.65 → Base Color
            diffuse Alpha × tint Alpha → Opacity Mask
            Emissive·Metallic·Specular = 0 / Roughness = 1
```

몸과 같은 변환을 눈에 적용하니 눈동자와 아이라인이 희게 흐려졌다. 텍스처는 정상이라, **별도 Masked Lit 부모 `M_ICAuthoredFeatureLit`**로 RGB·알파를 직접 연결했다. 기존 MToon 내부의 어느 한 노드가 단독 원인인지까지 확정한 것은 아니다.

| 눈 재질 설정 | 값 |
| --- | --- |
| Shading Model / Blend Mode / Two Sided | Default Lit / Masked / 켬 |
| Usage | Used with Skeletal Mesh·Morph Targets 켬 |
| `ICFeatureAlbedoTexture` / `ICFeatureAlbedoTint` | 각 캐릭터의 원본 diffuse / 원본 tint |
| Opacity Mask Clip Value | 약 0.3333 |

여성은 눈·눈썹·속눈썹·입 등의 슬롯, 남성은 얼굴 특징이 합쳐진 머리 아틀라스 슬롯에 적용했다. 이번 전신 보정에서도 이 눈 표현은 유지했다.

## 3. NPC 003 머리카락을 8방향으로 비교했다

앞서 NPC 001의 햇빛 아래 눈 주변 음영을 줄이려고 얼굴·눈에 Subsurface를 적용했다. 하지만 원본 아틀라스를 확인하니 실제 머리카락은 얼굴 슬롯이 아니라 **몸·옷과 합쳐진 두 번째 슬롯**에 있었다. 얼굴·눈 산란 실험은 철회하고 해당 MI를 백업과 동일하게 복원했다. 이후 머리카락 UV만 산란을 적용한 뒤 NPC 003으로 옮겨 더 비교했다. NPC 001은 산란 0.4/밀도 0.6, NPC 003은 0.25/0.65를 시험했으며 이 머리 산란 경로도 최종 7번으로 대체했다.

몸의 밝기를 고친 뒤에는 그림자와 실내에서 머릿결을 따라 검은 선이 남았다. NPC 003의 머리 UV에만 변경을 적용하고 얼굴·눈은 같은 상태로 비교했다. 밤/낮 × 실내/실외 × 전신/근접으로 **64장**을 촬영했다.

| 머리 실험 | 관찰 |
| --- | --- |
| 1. 당시 기준 재질 | 어두운 선이 남았다. |
| 2. 노멀맵·추가 Normal 계산 우회 | 선이 크게 줄었지만 낮에 밝은 면이 넓어졌다. |
| 3. 뒷면 노멀 보정 | 이 정면 사선 시점에서는 차이가 작았다. |
| 4. 빛 산란 확대 | 낮의 빛 퍼짐은 늘었지만 가는 선은 남았다. |
| 5. Two Sided Foliage | 얇은 면의 빛 전달을 바꿔도 선은 남았다. |
| 6. Preintegrated Skin | 현재 조명·수치에서는 개선이 작았다. |
| **7. 원본 RGB의 단순 표면** | 선이 줄고 낮의 넓은 입체 그림자는 남았다. 최종 기반으로 선택했다. |
| 8. 캐릭터 그림자 끄기 | 얼굴·목·바닥 그림자까지 사라졌다. 가는 선은 남아 진단용으로만 사용했다. |

## 4. Kawaii Toon Shading도 시험한 뒤 제거했다

원본 재질 복사본에 Kawaii Toon Shading v0.1.2 기본값을 적용해 여성 플레이어와 NPC 003을 비교했다. 전신 8장·얼굴 8장, 총 **16장**을 촬영했다. 플러그인은 Unlit 기반으로 태양광·하늘광을 자체 계산하는 구조다. [원본 구현 설명](https://github.com/pookiepied/KawaiiToonShading/blob/main/docs/how-it-works.md)

## 5. 최종: 7번 머리 + 캐릭터 전체의 후처리 선 제외

처음에는 머리만 후처리 선을 줄였다. 이후 피부·옷 경계도 거칠게 보여 **같은 예외를 캐릭터 전체**로 넓혔다. 원본 눈동자·옷 무늬와 실제 조명·자기 그림자는 유지한다. 텍스처에 그려진 선이나 메시가 만드는 그림자까지 지우는 방식은 아니다.

```text
머리: 원본 diffuse RGB × 해당 캐릭터 tint × 0.65 → Base Color
      Default Lit / 기본 메시 Normal / Roughness = 1
      Emissive·Metallic·Specular = 0 / 원본 알파 유지

후처리: 보이는 캐릭터 픽셀을 Custom Stencil 249로 찾기
        기존 노멀 Edge × lerp(1, ICCharacterOutlineStrength, 캐릭터 마스크)
        ICCharacterOutlineStrength = 0 (1이면 기존 선 복원)
```

초기 필터가 안 보였던 이유도 있었다. `r.CustomDepth=1`은 깊이만 쓰는 상태여서 **Stencil을 읽을 수 없었다**. 3(Enabled with Stencil)으로 바꾼 뒤 태그가 정상 검출됐다. SceneDepth와 CustomDepth를 비교해 벽 뒤 캐릭터가 보정되지 않게 하고, 약 1.5픽셀 주변 3×3 검사로 머리·얼굴 경계의 남는 선을 줄였다. 머리 전용 시험의 Roughness 표식은 최종 전신 필터에는 필요 없다.

Custom Depth/Stencil과 Scene Texture를 이용한 후처리 분리는 엔진 기능이며, 여기서는 기존 월드 후처리의 **윤곽선 혼합 부분에만** 예외를 넣었다. [Epic: Post Process Materials](https://dev.epicgames.com/documentation/en-us/unreal-engine/post-process-materials-in-unreal-engine)

### 배경이 바뀌지 않았는지도 확인했다

캐릭터를 숨기고 같은 카메라·시간에서 원본/수정 후처리를 대조했다. NPC 003 시험의 정적 벽 영역에서 RGB 절대 차이 평균은 **0.213/255**, 95% 지점은 **1/255**였다. 렌더링의 작은 프레임 차이는 있지만 배경 색을 바꾸는 보정은 넣지 않았다.

![[20261103-vroid-final-world-control.png]]

전체 적용에서도 기존 광원·노출·후처리 설정을 복사해 비교했고, 월드에서 허용한 차이는 **후처리 재질 참조 1개 교체**였다. 단일 태양광을 선택했던 앞 단계와 이번 캐릭터 선 제거 단계를 구분해서 봐야 한다.

## 6. 에디터에서 바꾼 위치

| 에디터 위치 | 최종 설정 |
| --- | --- |
| `L_OpenWorld` → World Outliner → 태양광 | 앞 단계의 `DirectionalLight_0` 단일 태양광 유지. 주간 6 lux, 다른 방향광 2개는 Visible 끔·Intensity 0. 낮밤 컨트롤러 Sun Lights에도 하나만 연결. |
| Content Browser → `IsekaiClass/Player/Materials/WorldReactive` 및 `NPC/Materials/WorldReactive` | 원본 공용 부모를 직접 고치지 않고 캐릭터별 복제본 사용. 몸의 색은 Base Color, Emissive 0. 표면색 배율 0.65는 화면 밝기 65%를 뜻하지 않는다. |
| 각 캐릭터 `SelectedRawRGB`의 부모 그래프 | 머리 영역만 원본 RGB의 단순 Default Lit 표면으로 선택. `From Material Expression`을 사용하며 자식 MI에 Unlit 고정 오버라이드가 남지 않게 정리. |
| 각 머리 MI → `ICResearchHairDiffuse`, `ICResearchHairTint` | NPC 003의 텍스처를 재사용하지 않고 **각 캐릭터의 원본 텍스처·색** 연결. NPC별 아틀라스 UV 위치도 개별 지정. 여성 플레이어는 별도 머리 슬롯 14·16. |
| `WorldReactive/Shared/M_ICAuthoredFeatureLit` | 원본 RGB·알파로 눈/입/아이라인 표현 유지. 눈을 어둡게 칠하거나 텍스처를 수정하지 않음. |
| `BP_ICPlayerCharacter`와 NPC 11개 BP → Mesh → Rendering | `Render CustomDepth Pass` 켬, `CustomDepth Stencil Value = 249`. |
| Project Settings → Rendering → Postprocessing | `Custom Depth-Stencil Pass = Enabled with Stencil`. `DefaultEngine.ini`에는 `r.CustomDepth=3`. |
| `L_OpenWorld` → `PostProcessVolume_1` → Post Process Materials | 원래 MI 대신 전용 복제본 `MI_ICCharacterWorldPostProcess` 연결. 다른 후처리 설정은 유지. |
| 위 MI → Parent `M_ICCharacterWorldPostProcess` | `IC Visible Character Outline Gate`가 기존 노멀 Edge의 혼합량만 제어. `ICCharacterOutlineStrength=0`. |

전신 후처리 재질 경로는 `IsekaiClass/NPC/Materials/WorldReactive/Shared/CharacterOutline`이다. 최종 머리 바인딩은 **14개 MI**(NPC 11 + 남성 1 + 여성 2), 기본 BP 저장 대상은 **12개**(NPC 11 + 남녀 공통 플레이어 1)다. 스켈레탈 메시의 슬롯 배치와 스켈레톤·애니메이션·물리는 유지했다.

몸 단계의 부위별 설정도 이어받았다. 여성 피부는 `NormalToCameraMat=0.95`, `NormalFresnelScale=2`, 노멀맵 끔으로 얼굴을 정리했다. 머리의 최종 경로는 위 단순 표면으로 교체했고 피부·옷을 머리와 같은 RGB 표면으로 통째로 바꾸지는 않았다. **전체 적용은 후처리 선의 범위**를 뜻한다.

프리셋 전환의 `ICPlayerAppearance::Apply`는 `EmptyOverrideMaterials()`로 이전 외형의 재질이 남지 않게 한다. 플레이어 여성 17개·남성 2개 기본 슬롯도 유지한다.

## 배운 점

**밝기, 표면 음영, 후처리 선은 서로 다른 단계다.** 색이 Base Color와 Emissive 중 어디로 가는지 먼저 보고, 몸·눈·머리의 목적을 나눠야 했다. 남은 검은 선을 모두 노멀맵 탓으로 생각하면 월드 후처리를 놓친다. 캐릭터만 바꾸려면 Stencil 설정과 가림 처리까지 확인하고, 저장 후 재실행한 결과로 비교해야 한다.

자동화에서도 `get_editor_property()`로 받은 구조체를 수정하면 원본 설정에 영향을 줄 수 있었다. 비교용 `PostProcessSettings`는 `.copy()`한 뒤 검사하도록 고쳤다.

재현 코드: `Tools/Characters/apply_all_character_outline.py` · 촬영: `review_all_character_outline.py`. 재질 종류와 부모 구조는 [VRM4U 공식 안내](https://ruyo.github.io/VRM4U/01_material/)도 참고했다.
