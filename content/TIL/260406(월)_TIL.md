## \[내일배움캠프 사전캠프 6일차\]특수액터와 머티리얼

[네이버 원본](<https://blog.naver.com/greentea_icecream/224242557788>) · 14:14

**\[액터의 특수한 자식 클래스\]**

**Pawn (폰)**

컨트롤러에 의해 빙의(Possess)되어, 플레이어 또는 AI가 조작할 수 있는 액터

**Character (캐릭터)**

Pawn을 상속받은 클래스

Character Movement Component를 기본 포함

**Controller (컨트롤러)**

: Pawn 또는 Character를 조종하는 주체

종류

- Player Controller 플레이어 입력(키보드, 마우스 등) 처리
- AI Controller AI 로직 및 행동 제어

**\[컴포넌트\]**

: 액터를 구성하는 기능 단위 요소

**1. 씬 컴포넌트**

트랜스폼을 지니는 위치 , 회전 , 스케일 지정이 가능한 컴포넌트

**2. 스태틱 메시 컴포넌트**

애니메이션이 없고 , 뼈가 없는 3D 에셋인 스태틱 메시 에셋을 표현하는 컴포넌트

**3. 스켈레탈 메시 컴포넌트**

애니메이션이 있고, 뼈가 있는 3D에셋인 스켈레탈 메시 에셋을 표현하며, 애니메이션을 넣을 수 있는 컴포넌트

**4. 머티리얼**

컴포넌트는 아니지만 3D 혹은 2D 물체에 적용되는 재질로써, 여러가지 외부 표현이 가능하게 하는 재질

**5. 라이트 컴포넌트**

빛을 발하는 컴포넌트입니다. 다양한 종류가 있으나 빛을 비추는 역할인 점은 같음

**6. 스프링 암과 카메라 컴포넌트**

각각 카메라 붐 스틱의 역할과 촬영하여 화면 또는 기록으로 나타내는 기능을 하는 컴포넌트

## \[내일배움캠프 사전캠프 6일차\]컴포넌트와 액터의 블루프린트

[네이버 원본](<https://blog.naver.com/greentea_icecream/224242746888>) · 16:24

**\[트랜스포메이션\]**

액터나 컴포넌트의 **위치(Location), 회전(Rotation), 크기(Scale)** 를 제어하는 핵심 기능

- **Add 함수 :** 기존 값 + 추가
- **Set 함수 :** 기존 값 무시, 새 값 적용
- **Get 함수 :** 값 조회

**\[활성화\]**

컴포넌트의 동작 여부(On / Off) 를 제어하는 기능

![[첨부파일모음/naver-224242746888-f3ec19635cc8.png]]

**1) activate 함수 :** 컴포넌트를 활성화(On)

**2) deactivate 함수 :** 컴포넌트를 비활성화(Off)

**3)is active 함수 :** 현재 컴포넌트가 활성화 상태인지 True / False로 확인

**\[Is Valid 노드\]**

![[첨부파일모음/naver-224242746888-62741eb94a02.png]]

- **함수형(Is Valid - f)** : 객체의 유효 여부를 True / False로 반환하는 순수 함수
- **실행형(Is Valid - ?)** : 실행 흐름을 유효/무효로 분기하는 노드
