**3. 문제/오류/해결**

**문제 :**

배열과 벡터가 헷갈림

**정리 :**

배열(Array)과 벡터(Vector)

|  |  |  |
| --- | --- | --- |
| **구분** | **배열(Array)** | **벡터(Vector)** |
| 크기 변경 | 불가능 | 가능 |
| 메모리 크기 | 고정 | 자동 확장 |
| 사용 난이도 | 낮음 | 더 편리 |
| 기능 | 거의 없음 | 기능 많음 |
| 추천도 | 제한적 | 실무에서 더 많이 씀 |

배열 기본 형태

```
int nums[3] = {10, 20, 30};

cout << nums[0]; // 10
cout << nums[1]; // 20
```

벡터 기본 형태

```
vector<int> nums;

nums.push_back(10);
nums.push_back(20);
nums.push_back(30); 

cout << nums[0]; // 10
cout << nums[1]; // 20
```
