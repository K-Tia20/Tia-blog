코드 편집기를 연결하는 과정에서도 문제가 있었다. 프로젝트를 열지 못하거나 빌드는 끝났는데 연결 도구가 실패로 표시하는 상황이었다.

## 문제의 원인

프로젝트를 여는 데 필요한 실행 환경과, 작업 결과를 전달하는 연결 도구를 따로 살펴야 했다.

## 바꾼 방법

![[T20-Flow-clean-v1.webp]]

- 언리얼에 포함된 실행 환경을 편집기에 알려 주었다.
- 연결 도구의 짧은 응답과 실제 빌드 결과를 따로 읽었다.
- 코드 열기·변경·빌드 흐름을 맞춘 뒤 임시 변경은 원래대로 돌렸다.
