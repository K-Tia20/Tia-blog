## 캐릭터 한 번에 만들기
JSON 한 장에 원하는 것을 적으면 순서대로 실행합니다: 새 모델 → 프리셋 → 슬라이더 → 색 → 피부 → 얼굴 → 헤어 → 옷 → 체형 → 헤어 본 → 저장 → VRM.

```json
{
  "new": "female",
  "recipes": ["elf_ears", "orc_skin"],
  "colors": {"Iris": {"LeftOverlayColor": "#c03030", "RightOverlayColor": "#c03030"}},
  "save": "orc_elf.vroid",
  "export_vrm": {"out": "orc_elf.vrm"}
}
```
- 명령어: `classvroid character my_character.json` (`--check`로 미리 검사만)
- API: `POST /v1/jobs/character` → 작업 번호로 진행 상황 확인(`GET /v1/jobs/{id}`)
- **레시피**: VRoid에서 직접 확인한 값 묶음 — 엘프 귀, 오크 피부, 볼터치, 빨간 입술, 긴 생머리, 인너 컬러 등 (`classvroid recipes`)

## 기본 조작
| 하고 싶은 것 | 명령어 | API |
| --- | --- | --- |
| 상태 확인 | `classvroid live status` | `GET /v1/live/status` |
| 새 모델 / 열기 / 저장 | `live new female`, `live open a.vroid`, `live save b.vroid` | `POST /v1/live/new`, `/open`, `/save` |
| 슬라이더 바꾸기 | `live set Ear.EarTipUp=2.2` | `PATCH /v1/live/params` |
| 색 / 피부색 | `live color Iris.LeftOverlayColor=#33aa77`, `live skin #739952` | `PATCH /v1/live/colors`, `PUT /v1/live/skin` |
| 프리셋 찾기·입히기·벗기기 | `live presets CatEar`, `live preset CatEar`, `live remove Tops` | `GET /v1/live/presets`, `POST /v1/live/presets/apply`, `DELETE /v1/live/items/{group}` |
| 되돌리기 | `live undo`, `live redo` | `POST /v1/live/undo`, `/redo` |
| 화면 찍기 / VRM | `live screenshot a.png`, `live export-vrm a.vrm` | `GET /v1/live/screenshot.png`, `POST /v1/jobs/export-vrm` |

## 얼굴
![[face_generated_styles.png]]
*코드로 만든 눈동자·하이라이트·아이라인·눈썹 그림.*

- **17부위를 이름 하나로**: 눈동자, 흰자, 하이라이트, 눈 모양, 눈꺼풀, 아이라인, 속눈썹, 눈썹, 코, 입, 입술, 볼터치, 페이스페인트, 얼굴 모양, 귀 …
- 부위마다 프리셋(그 부위 안에서만 검색), 슬라이더, 색(좌우 눈 따로, 볼터치 세기), 텍스처(꺼내기·넣기·색 바꾸기)
- **그림 생성기**: 동공 모양(세로·하트·별), 오드아이, 스파클 하이라이트, 고양이 눈 아이라인, 털 결 눈썹, 입술 광택·반짝이, 볼터치 무늬(빗금·하트·주근깨), 흰자 그늘, 입 안(이·혀)
- 명령어: `classvroid face apply face.json`, `face draw iris color=#3a8fd8 pupil=slit --apply`
- API: `GET/PATCH /v1/live/face`, `POST /v1/face/{part}/draw.png`(VRoid 없이 미리 보기)

## 헤어
![[hair_long.png]]
*가이드 모양을 바꿔 만든 긴 생머리 (꼬리 → 넓히기 → 뿌리 띠 → 최종).*

- **프리셋 조합**: 앞·뒤·일체형·옆·묶음·아호게·하네게·두피·세트 칸별로 고르거나 빼기
- **색·그림**: 헤어 색, 하이라이트, 그러데이션 끝 색, 뿌리 색, 천사 링
- **새 가닥 그리기**: VRoid 펜 명령 그대로(되돌리기 한 번). 부채꼴·한쪽 쓸림·직선 패턴, 좌우 대칭
- **새 가닥 그룹·가이드 모양**: 이름, 높이, 옆 넓히기, 머리 쪽 좁히기
- **재질**: 이름 붙인 재질로 인너 컬러·옆 메시
- **흔들림 본**: 그룹 이름에 역할(흔들림·땋은 머리·수염·단단한 소품)만 적으면 공식 샘플 값으로 본을 다시 짜고, 본 없는 가닥을 점검·보충
- 명령어: `classvroid hair style set=005 ahoge=500`, `hair strands front pattern=fan count=5`, `classvroid hair-bones audit --check`
- API: `GET/PATCH /v1/live/hair`, `POST /v1/live/hair/strands`, `POST /v1/jobs/hair-bones`

## 옷 모양 (cm로)
![[outfit_controls.png]]
*드레스 기장 +10 cm·퍼짐 +6 cm / 바지 기장 −8 cm·롱부츠 밑창 +4 cm.*

- 옷 템플릿 33종(상의·원피스·보디슈트·하의·넥타이 4종 + 신발 8종)의 슬라이더 **538개를 직접 재서** "값 100이면 몇 cm"인지 표로 만들었습니다.
- 템플릿마다 슬라이더 이름·세기가 달라도 **같은 말로** 요청합니다: 기장, 밑단 퍼짐, 소매 길이·굵기, 허리, 몸통 폭, 부피, 바짓가랑이 폭, 밑창, 굽, 앞코, 부츠 입구 등 13가지
- VRoid 화면에서 재 보니 요청한 cm의 0.85–1.15배
- 명령어: `classvroid outfit set Onepiece length_cm=10 flare_cm=6`, `outfit catalog --md`
- API: `GET /v1/outfit/catalog`, `GET/PATCH /v1/live/outfit`

## 체형 (cm로)
- VRoid 체형 패널 슬라이더 23개를 여성·남성 기본 모델에서 하나씩 재서, 양 끝에서 **치수 30가지**(키·어깨·가슴·허리·엉덩이·다리·팔·손·발 …)가 몇 cm 바뀌는지 표로 만들었습니다.
- **이름과 다르게 움직이는 것**도 표에 그대로 적었습니다.
  - `FigureHeight…`는 키를 **줄이고**, `FigureSlender…`가 키를 **늘립니다**.
  - "허리 크기"는 허리보다 주로 엉덩이·허벅지를 바꿉니다.
- **cm 목표**: 표로 값을 풀고 → 넣고 → VRoid에서 다시 재서 고칩니다.
  - 여성: 키 165·다리 83·가슴 76·엉덩이 84·어깨 22.5·팔 46을 22초에 모두 0.2 cm 안으로
  - 남성: 키 180 등 5개를 11초에
- 명령어: `classvroid body set height_cm=165 leg_cm=83`, `body catalog --md`, `body show`
- API: `GET /v1/body/catalog`, `GET/PATCH /v1/live/body`

## 텍스처 지도 (옷·피부)
텍스처 그림의 어느 부분이 몸 어디에 붙는지 알려 줍니다. 무늬·문신·근육을 **감으로 그리지 않게** 하려는 기능입니다.
- **옷 33종**(2048): 앞판·뒤판·소매·깃·후드·치마 앞/옆/뒤·바지 다리·밑창·앞코 …
- **몸 피부**(2048): 가슴·등·배·엉덩이·위팔·손등·손바닥·손톱·허벅지·발바닥·뒤통수 … (양말·이너도 이 그림 위에 그려짐)
- **얼굴 피부**(1024): 이마·눈가·코·볼·입가·턱·귀
- 조각마다 위 방향, 캐릭터 오른쪽 방향, 좌우 반전, px/cm, 이음선, 슬라이더를 바꿀 때 늘어나는 양
- VRoid에서 시험 텍스처를 입혀 확인했습니다. 옷 조각 656개, 피부 조각 99개 모두 방향·반전이 맞았습니다.
- 명령어: `classvroid outfit uv 티셔츠 --md`, `classvroid skin uv body --md --stretch`
- API: `GET /v1/outfit/uv`, `GET /v1/skin/uv`
- 지도 그림은 내 PC의 VRoid 메시로 만들어지므로 **공유하지 않습니다**.

## .vroid 파일 직접 편집 (VRoid 없이)
![[hero_tunic_before_after.png]]
*같은 튜닉: 원본(왼쪽) vs 자동 칠하기(오른쪽) — 주름·바늘땀·천 결·노멀맵.*

- 옷·레이어·템플릿·슬라이더 값 읽기, 레이어 추가·숨김·불투명도
- **화면에 없는 재질 칸**: 노멀맵, 그늘 텍스처, 매트캡, 외곽선 굵기 (헤어 가닥 소품의 금속 광택 등)
- **옷 자동 칠하기**: 공식 샘플 20개를 재서 만든 기준으로 주름·이음선·바늘땀·천 결·장식을 그리고 노멀맵까지 (2048² 한 벌 21–28초)
- 명령어: `classvroid info a.vroid`, `classvroid paint spec.json a.vroid -o b.vroid`
- API: `/v1/files/...` (올리기·내려받기·레이어·재질 칸·룩), `POST /v1/jobs/paint`
