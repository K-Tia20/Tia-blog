# 5. 최종 정리

[[ClassVroid]]로 돌아가기

## 구성

| 구성 | 역할 |
| --- | --- |
| Python·CLI·HTTP API | 파일 편집, 제작 요청과 검증 |
| VRoid 브리지 | 실행 중인 Studio의 편집 기능 연결 |
| 템플릿·측정 자료 | 의상 UV, 슬라이더와 체형 조절 참고 |
| 테스트·예제·문서 | 사용 방법과 검증 기록 |

## 1.16.0에서 확인한 작업

- 제작 요청의 입력과 템플릿 연결을 검사하고, 저장 후 모델을 다시 열어 의상·얼굴·헤어 설정을 확인했다.
- 그란 예제에서 수염과 머리카락을 가닥 그룹으로 만들고 저장 후 길이를 검증했다.
- 마지막 자동 테스트 기록은 **236개 통과**다. 기존 글의 0.15.0 수치는 당시 기록이다.

## 사용 시 확인할 점

원화는 디자인 참고용이며 의상 텍스처는 VRoid 기본 템플릿 UV에 맞춘다. 소매·몸판의 연결, 여러 템플릿의 겹침, 앞·옆·뒤와 움직임은 실제 모델에서 확인해야 한다. 원화와 완벽히 일치하는 자동 제작이나 모든 동적 충돌 검사를 보장하지 않는다.

최신 배포본에는 `README.md`, `docs/RELEASE_1.16.0.ko.md`, `docs/ClassVroid_API.pdf`와 예제가 들어 있다. 인터넷 공개나 제3자 공유 전에는 브리지 라이선스와 VRoid 관련 데이터의 배포 범위를 다시 확인한다.
