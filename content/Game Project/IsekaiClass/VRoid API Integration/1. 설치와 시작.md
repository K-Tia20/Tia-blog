## 필요한 것
- Windows 10/11
- Python 3.10 이상
- VRoid Studio **2.14.0** (VRoid를 움직이는 기능에만 필요 — 파일 편집·텍스처 지도는 없어도 됨)
- 처음 설치할 때 인터넷 (BepInEx 내려받기)

## 설치 — 방법 A: 더블클릭 (추천)
1. VRoid Studio를 **닫습니다.**
2. `ClassVroid/setup_windows.cmd`를 더블클릭합니다.
3. 자동으로 진행됩니다.
   - 가상 환경(`.venv`)을 만들고 ClassVroid를 설치합니다.
   - BepInEx 6를 공식 서버에서 받아 **SHA-256이 맞을 때만** 풉니다.
   - 브리지 플러그인을 넣습니다.
   - VRoid를 처음 실행하고 브리지가 응답할 때까지 기다립니다(1–2분).
4. 끝나면 `classvroid bridge status`로 확인합니다.

> [!tip] 안전장치
> - 기존 파일은 **지우지 않고** VRoid 폴더의 `ClassVroid_backup_날짜` 폴더로 옮깁니다.
> - VRoid가 켜져 있으면 설치하지 않습니다.
> - 시험한 VRoid 버전(2.14.0)이 아니면 `--force` 없이는 설치하지 않습니다.

## 설치 — 방법 B: 직접
```powershell
cd ClassVroid
python -m venv .venv
.venv\Scripts\pip install -e ".[server,templates]"
.venv\Scripts\classvroid bridge install --launch
```

## 처음 한 번: 내 PC의 VRoid에서 메시 꺼내기
```powershell
classvroid templates extract
```
- 옷 템플릿 33종과 몸·얼굴 피부 메시를 **내 PC의 VRoid 설치에서** 읽어 캐시(`%LOCALAPPDATA%\classvroid\templates`)에 저장합니다.
- 옷 cm 조절, 텍스처 지도, 체형 측정에 씁니다.
- pixiv 데이터라서 **ZIP에는 들어 있지 않고, 다른 사람에게 보내지 않습니다.**

## 첫 실행
VRoid Studio를 켠 상태에서:

```powershell
classvroid live status                                  # 브리지 연결 확인
classvroid character examples/character_orc_elf.json    # JSON 한 장으로 캐릭터 만들기 → 저장 → VRM
```

## HTTP API로 쓰기
```powershell
classvroid serve        # http://127.0.0.1:8000  (자동 문서: /docs, 웹 콘솔: /)
```

```bash
# 체형을 cm로 맞추기
curl -X PATCH localhost:8000/v1/live/body -H "content-type: application/json" \
     -d '{"values": {"height_cm": 165, "leg_cm": 83, "bust_cm": 76}}'

# 열린 모델 상태
curl localhost:8000/v1/live/status
```

## 알아 두면 좋은 규칙
- **저장은 덮어쓰지 않습니다.** 같은 이름이 있으면 거부합니다.
- 열린 모델에 **저장 안 한 변경**이 있으면 새로 열기·만들기를 거부합니다. 버려도 될 때만 `--discard`를 씁니다.
- 외곽선·림라이트는 **항상 0**으로 맞춥니다(새 모델, 저장, VRM 직전).
- 슬라이더 범위 밖 값은 들어가지만 **경고**를 줍니다. 범위의 2배를 넘는 체형 값은 거부합니다.
- 모든 편집은 VRoid에서 **되돌리기**가 됩니다.

## 막힐 때
| 증상 | 확인할 것 |
| --- | --- |
| `bridge not answering` | VRoid가 켜져 있는지, `classvroid bridge status` |
| "template not cached" | `classvroid templates extract` (피부만: `classvroid templates extract skin`) |
| PDF가 안 만들어짐 | Git Bash가 아니라 **PowerShell이나 cmd**에서 실행 |
| VRoid 업데이트 후 안 됨 | VRoid 2.14.0 기준이라 내부가 바뀌면 다시 확인해야 함 |
