풀이 코드

```
int solution(int n) 
{
    /*
        y 변수 생성

        n - 1 값을 저장

        ------------------------------------------------

        예시:

        n = 12

        y = 11

        ------------------------------------------------

        왜 n - 1 을 하는가?

        이 문제는 보통:

        "n을 1로 나눈 나머지가 1이 되게 하는 가장 작은 수 찾기"

        문제이기 때문

        ------------------------------------------------

        공식:

        n % x == 1

        ------------------------------------------------

        이걸 변형하면:

        n - 1 이 x로 나누어 떨어진다

        즉:

        (n - 1) % x == 0

        ------------------------------------------------

        그래서:
        y = n - 1

        로 저장해두고
        y의 약수를 찾는 방식
    */
    int y = n - 1;


    /*
        for 반복문

        ------------------------------------------------

        int x = 2;
        -> x를 2부터 시작

        ------------------------------------------------

        x <= y;
        -> x가 y 이하인 동안 반복

        ------------------------------------------------

        x++
        -> 반복마다 1 증가

        ------------------------------------------------

        예시:

        y = 11

        반복:

        x = 2
        x = 3
        x = 4
        ...
        x = 11
    */
    for (int x = 2; x <= y; x++)
    {
        /*
            y % x

            -> y를 x로 나눈 나머지

            ------------------------------------------------

            나머지가 0이라는 뜻:

            "딱 나누어 떨어진다"

            즉:
            x가 y의 약수라는 의미

            ------------------------------------------------

            예시:

            y = 12

            x = 3

            12 % 3 = 0

            -> 나누어 떨어짐
            -> 3은 약수
        */
        if (y % x == 0)
        
        /*
            조건을 만족하면 바로 반환

            return x;

            ------------------------------------------------

            중요한 점:

            반복문이 작은 숫자부터 검사하므로

            가장 먼저 발견되는 약수 = 가장 작은 약수

            ------------------------------------------------

            예시:

            y = 12

            검사 순서:

            x=2 -> 가능

            바로 return 2

            종료
        */
        return x;
    }
}
```
