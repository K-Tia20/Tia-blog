## x만큼 간격이 있는 n개의 숫자

[코딩테스트 연습 - x만큼 간격이 있는 n개의 숫자](<https://school.programmers.co.kr/learn/courses/30/lessons/12954>)

```cpp
#include <string>

vector<long long> solution(int x, int n) {
    vector<long long> answer;

```

풀이 코드

```cpp
#include <string>
#include <vector>

using namespace std;

vector<long long> solution(int x, int n) 
{
    vector<long long> answer;

    for (int i = 1; i <= n; i++)
    {
        answer.push_back((long long)x * i);
    }

    return answer;
}
```

타 답안

```cpp
#include <string>   // string 헤더 (현재 코드에서는 사용하지 않음)
#include <vector>   // vector 사용을 위한 헤더

using namespace std; // std::vector 등을 간단하게 사용하기 위해 작성


/*
    solution 함수

    매개변수:
    x -> 증가할 숫자
    n -> 몇 개 만들 것인지

    반환값:
    vector<long long>

    long long형 숫자 배열 반환
*/
vector<long long> solution(int x, int n) 
{
    /*
        vector<long long> answer(n, x);

        vector 생성과 동시에 값 채우기

        ------------------------------------------------

        형식:

        vector<자료형> 변수이름(개수, 초기값);

        ------------------------------------------------

        현재 코드 의미:

        길이가 n인 배열 생성
        모든 값을 x로 초기화

        ------------------------------------------------

        예시:

        x = 3
        n = 5

        결과:

        answer = {3, 3, 3, 3, 3}

        ------------------------------------------------

        왜 long long 사용?

        숫자가 계속 커질 수 있기 때문

        int 범위를 넘을 가능성 방지
    */
    vector<long long> answer(n, x);


    /*
        for 반복문

        ------------------------------------------------

        int i = 1;
        -> i를 1부터 시작

        왜 1부터 시작?

        answer[0] 은 이미 x 값이 들어있기 때문

        ------------------------------------------------

        i < n;
        -> n 전까지 반복

        ------------------------------------------------

        i++
        -> 반복마다 1 증가

        ------------------------------------------------

        예시:

        n = 5

        반복:

        i = 1
        i = 2
        i = 3
        i = 4
    */
    for (int i = 1; i < n; i++)

        /*
            현재 위치 값 계산

            ------------------------------------------------

            answer[i - 1]
            -> 이전 값

            + x
            -> x만큼 증가

            ------------------------------------------------

            예시:

            x = 3

            시작 상태:
            {3, 3, 3, 3, 3}

            ------------------------------------------------

            i = 1

            answer[1]
            = answer[0] + 3

            = 3 + 3

            = 6

            결과:
            {3, 6, 3, 3, 3}

            ------------------------------------------------

            i = 2

            answer[2]
            = answer[1] + 3

            = 6 + 3

            = 9

            결과:
            {3, 6, 9, 3, 3}

            ------------------------------------------------

            계속 반복하면:

            {3, 6, 9, 12, 15}

            완성
        */
        answer[i] = answer[i - 1] + x;


    /*
        완성된 배열 반환

        예시:

        x = 2
        n = 5

        결과:

        {2, 4, 6, 8, 10}
    */
    return answer;
}
```

```cpp
}
```
