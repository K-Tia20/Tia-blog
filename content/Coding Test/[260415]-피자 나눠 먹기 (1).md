풀이 코드

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(int n) {
    int b = 0;
    if (n%7 >= 1){
        b = n/7;
        b++;
    }
    else{
        b = n/7;
    }
    return b;
}
```
