## 하샤드 수

[코딩테스트 연습 - 하샤드 수](<https://school.programmers.co.kr/learn/courses/30/lessons/12947>)

**하샤드 수란?**

주어진 진법에서 그 수의 각 자릿수 숫자의 합으로 나누어떨어지는 자연수

**하샤드 수 판별 과정**

숫자 x가 있을 때:

1. 각 자리수를 구한다.
2. 모두 더한다.
3. x % 자리수합 == 0 인지 확인한다.
4. 0이면 하샤드 수.

풀이 코드

```
bool solution(int x)
{
    // x의 값을 따로 저장
    // 원본 x는 마지막에 나눗셈 판별에 사용해야 하므로 보존
    int num = x;

    // 각 자리수의 합을 저장할 변수
    int sum = 0;

    // num이 0보다 큰 동안 반복
    // 모든 자리수를 하나씩 꺼낼 때까지 반복함
    while(num > 0)
    {
        // num의 마지막 자리수를 구해서 sum에 더함
        //
        // 예:
        // num이 123이면
        // 123 % 10 = 3
        //
        // num이 45이면
        // 45 % 10 = 5
        sum = sum + (num % 10);

        // 마지막 자리수를 제거
        //
        // 예:
        // 123 / 10 = 12
        // 12 / 10 = 1
        // 1 / 10 = 0
        //
        // int형끼리 나누면 소수점은 버려짐
        num = num / 10;
    }

    // 원래 숫자 x를
    // 자리수의 합 sum으로 나누었을 때
    // 나머지가 0인지 확인
    //
    // 나머지가 0이면 하샤드 수
    // 아니면 하샤드 수가 아님
    return (x % sum) == 0;
}
```
