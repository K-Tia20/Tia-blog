## 머쓱이보다 키 큰 사람

#배열 + 조건 비교 + 개수 세기

[코딩테스트 연습 - 머쓱이보다 키 큰 사람](<https://school.programmers.co.kr/learn/courses/30/lessons/120585?language=python3>)

---

템플릿 코드(Python)

```python
def solution(array, height):
    answer = 0
    return answer
```

풀이 코드(Python)

```python
def solution(array, height):
    b = 0
    for a in array:
        if a > height:
            b += 1
    return b
```

타 답안(Python)

```python
def solution(array, height):
    return sum(1 for a in array if a > height)
```

템플릿 코드(Java)

```java
class Solution {
    public int solution(int[] array, int height) {
        int answer = 0;
        return answer;
    }
}
```

풀이 코드(Java)

```java
class Solution {
    public int solution(int[] array, int height) {
        int a = 0;
        for (int i = 0; i < array.length; i++) {
            if (array[i] > height) {
                a++;
            }
        }
        return a;
    }
}
```

타 답안(Java)

```java
class Solution {
    public int solution(int[] array, int height) {
        int answer = 0;
        for(int i : array) {
            if(i > height) answer++;
        }
        return answer;
    }
}
```

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(vector<int> array, int height) {
    int a = 0;

    for (int i = 0; i < array.size(); i++) {
        if (array[i] > height) {
            a++;
        }
    }
    return a;
}
```

타 답안(C++)

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(vector<int> array, int height) {
    int answer = 0;
    for(const auto v : array)
    {
        answer += (v > height);
    }
    return answer;
}
```
