타 답안(C++)

```cpp
int kake(int a, int b) { 
    int res = 0; 
    while (b > 0) { 
        if (b & 1) res = res + a; 
        a = a << 1; 
        b = b >> 1; 
    } 
    return res; 
} 

int solution(int num1, int num2) {
    return kake(num1, num2);
}
```
