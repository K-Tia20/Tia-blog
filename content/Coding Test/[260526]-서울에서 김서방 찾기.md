풀이 코드

```cpp
#include <string>      // string 자료형을 사용하기 위한 헤더
#include <vector>      // vector(동적 배열)를 사용하기 위한 헤더
#include <algorithm>   // find() 함수가 들어있는 헤더

using namespace std;   // std::string, std::vector 처럼 std::를 생략 가능하게 함


// solution 함수
// vector<string> seoul : 문자열 배열을 전달받음
// 반환값은 string 타입
string solution(vector<string> seoul) 
{
    /*
        find 함수

        형식:
        find(시작위치, 끝위치, 찾을값)

        의미:
        배열(또는 vector) 안에서 원하는 값을 찾아주는 함수

        여기서는:
        seoul.begin() ~ seoul.end() 범위 안에서
        "Kim" 이라는 문자열을 찾아라 라는 뜻

        ------------------------------------------------

        seoul.begin()
        -> vector의 첫 번째 위치를 가리킴

        seoul.end()
        -> vector의 마지막 "다음 위치"를 가리킴
           (마지막 원소 자체가 아님)

        ------------------------------------------------

        예시:

        vector<string> seoul = {"Jane", "Kim"};

        위치 개념:

        [0] "Jane"
        [1] "Kim"

        begin() 은 0번 위치를 가리킴
        end() 는 마지막 다음 위치를 가리킴

                    end()
                      ↓
        [Jane][Kim][ ]
           ↑
        begin()

        ------------------------------------------------

        find는 내부적으로 앞에서부터 하나씩 비교함

        1번째 비교:
        "Jane" == "Kim" ? -> false

        2번째 비교:
        "Kim" == "Kim" ? -> true

        찾았으므로 "Kim"의 위치를 반환

        ------------------------------------------------

        auto 는 자료형을 자동으로 추론하는 키워드

        원래 자료형은 iterator 라는 긴 타입인데
        auto를 쓰면 컴파일러가 자동으로 타입을 결정해준다.

        즉:

        auto it

        은

        vector<string>::iterator it

        과 거의 같은 의미
    */
    auto it = find(seoul.begin(), seoul.end(), "Kim");
    

    /*
        iterator(반복자)란?

        쉽게 말하면:
        "배열의 위치를 가리키는 포인터 비슷한 것"

        ------------------------------------------------

        예시:

        vector<string> seoul = {"Jane", "Kim", "Park"};

        index:
          0       1       2

        값:
        "Jane"  "Kim"  "Park"

        ------------------------------------------------

        현재 it 은 "Kim" 위치를 가리키고 있음

                    it
                    ↓
        [Jane][Kim][Park]

        seoul.begin() 은 시작 위치를 가리킴

           begin()
              ↓
        [Jane][Kim][Park]

        ------------------------------------------------

        iterator끼리 빼기 가능

        it - seoul.begin()

        의미:
        "시작 위치로부터 몇 칸 떨어져 있는가?"

        ------------------------------------------------

        계산 과정:

        Kim 위치 = 1
        begin 위치 = 0

        1 - 0 = 1

        따라서 결과는 1

        ------------------------------------------------

        즉:

        iterator - iterator

        를 하면 index 번호처럼 사용할 수 있다.
    */
    int x = it - seoul.begin();


    /*
        to_string(x)

        숫자를 문자열로 바꿔주는 함수

        ------------------------------------------------

        예시:

        int x = 1;

        to_string(x)

        결과:
        "1"

        ------------------------------------------------

        왜 필요한가?

        현재 문장은 문자열끼리 이어붙이고 있음

        "김서방은 " + ??? + "에 있다"

        여기서 x는 숫자(int)라서 바로 붙일 수 없음

        따라서:
        숫자 -> 문자열 변환 필요

        ------------------------------------------------

        최종 결과:

        "김서방은 1에 있다"
    */
    return "김서방은 " + to_string(x) + "에 있다";
}
```

타 답안

```cpp
#include <bits/stdc++.h>
using namespace std;
#define 문자열 string
#define 함수 solution
#define 배열 vector
#define 반복 for
#define 반복자 iterator
#define 문자열로 to_string
#define 시작 begin
#define 끝 end
#define 반환 return

문자열 함수(배열<문자열> 서울) {
    for(배열<문자열>::반복자 반 = 서울.시작(); 반 != 서울.끝(); ++반)
        if(*반 == "Kim")
            반환 "김서방은 " + 문자열로(반 - 서울.시작()) + "에 있다";
}
```
