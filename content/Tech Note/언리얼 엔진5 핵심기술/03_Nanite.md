
> **한 줄 요약:** 복잡한 3D 모델을 화면에 필요한 수준으로 그리는 가상화 지오메트리  
> **핵심 장면:** 고해상도 바위 조각을 세밀하게 표현  
> **기준 버전:** Unreal Engine 5.8 (2026년 11월 기준)

## 1. Nanite은 무엇인가요?

3D 물체를 구성하는 작은 삼각형이 많아질수록 표현은 정교해지지만 처리 비용도 커질 수 있습니다. Nanite는 복잡한 메시를 화면의 크기와 시점에 맞게 처리해 디테일 유지와 렌더링 효율을 돕습니다.

복잡한 3D 물체의 삼각형을 하나하나 화면에 모두 그리는 대신 시점에 맞는 형태를 효율적으로 다루어 디테일과 성능의 균형을 돕습니다.

### 알아두면 쉬운 용어

- **폴리곤:** 3D 모델 표면을 이루는 작은 면
- **Static Mesh:** 일반적인 고정 형태의 3D 모델 에셋

## 2. 어떻게 활용할 수 있나요?

대표적으로 **바위·건축물·폐허·조각상** 같은 작업에 활용됩니다.

수많은 균열이 새겨진 큰 바위 메시를 멀리서 보다가 가까이 다가가도 세부 형태가 자연스럽게 보이도록 사용하는 사례가 대표적입니다.

## 4. 언리얼 엔진에서 직접 만들어 보기

**이번에 만들 결과:** 고해상도 바위 조각을 세밀하게 표현.

**준비물:** Epic Games Launcher, Unreal Engine 5.8, 저장 공간이 충분한 테스트 프로젝트, 기술에 맞는 기본 메시 또는 샘플 에셋.

### 단계별 진행

1. 복잡한 바위나 석상 **Static Mesh**를 프로젝트에 가져옵니다.
2. 콘텐츠 브라우저에서 메시를 더블클릭해 **Static Mesh Editor**를 엽니다.
3. 디테일 패널의 **Nanite Settings → Enable Nanite Support**를 체크하고 적용·저장합니다. 또는 에셋 우클릭의 Nanite 활성화 작업을 이용합니다.
4. 레벨에 해당 메시를 두 개 배치해 가까이서 보고 멀어지면서 형태를 확인합니다.
5. 뷰포트의 **View Mode → Nanite Visualization**에서 **Triangles / Clusters / Overview** 등 이용 가능한 모드를 선택합니다.
6. 폴리곤 분포가 카메라 거리와 화면 크기에 따라 어떻게 달라지는지 캡처합니다.
7. 뷰포트에서 `stat unit`, `stat gpu` 등 성능 정보를 비교해 봅니다. 가능하면 같은 프로젝트에서 측정합니다.

### 진행 중 무엇이 달라지는지 확인해 보세요

같은 메시를 일반 렌더링과 Nanite 활성화 상태로 살펴보고, 카메라 거리 변화에 따른 Nanite Triangles 시각화를 함께 확인합니다.

## 5. 완성 결과 확인하기

다음 항목을 확인하면 **Nanite**이 제대로 적용됐는지 판단하는 데 도움이 됩니다.

- [ ] Static Mesh Editor에서 Nanite 지원이 활성화됐는가?
- [ ] Nanite Visualization에서 삼각형/클러스터가 표시되는가?
- [ ] 동일한 카메라와 화면 해상도에서 성능을 비교했는가?

## 6. 자주 막히는 부분과 해결 방법

**Q. 나나이트 옵션이 비활성화돼요**

메시 유형과 머티리얼 지원 조건을 확인합니다.

**Q. 화면 차이가 거의 없어요**

Nanite는 외형을 극적으로 바꾸는 효과가 아니라 지오메트리 처리 방식이므로 시각화 모드로 확인합니다.

**Q. 성능이 무조건 좋아지지 않아요**

재질·그림자·조명·메모리 비용은 별개이며 장면별 측정이 필요합니다.

## 7. 화면별 이미지 구성 예시

블로그에 실제 실습 화면을 넣는다면 아래 순서가 자연스럽습니다.

1. **사진 1 — 원본 고밀도 바위 메시**
2. **사진 2 — Enable Nanite Support 설정**
3. **사진 3 — Nanite Triangles 또는 Overview 화면**
4. **사진 4 — 근거리/원거리 비교**

각 사진 아래에는 “어떤 메뉴를 눌렀고, 화면에서 무엇이 달라졌는지”를 한두 문장으로 적으면 처음 보는 분도 훨씬 쉽게 따라올 수 있습니다.

## 8. 마지막으로 알아둘 점

모든 메시에서 성능이 무조건 좋아지는 것은 아닙니다. 투명 재질·변형 애니메이션·충돌·메모리 사용량 등은 별도 검토해야 하고, 엔진 버전에 따라 지원 범위가 달라집니다.

정리하면 **Nanite**은(는) 복잡한 3D 모델을 화면에 필요한 수준으로 그리는 가상화 지오메트리 기술입니다. 처음에는 모든 옵션을 이해하려고 하기보다 하나의 작은 장면에서 변화를 확인하는 것이 중요합니다.
