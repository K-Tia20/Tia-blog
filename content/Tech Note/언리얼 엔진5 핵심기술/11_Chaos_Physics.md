
> **한 줄 요약:** 충돌·낙하·파괴 같은 물리 현상을 시뮬레이션  
> **핵심 장면:** 벽이 부서지고 파편이 흩어짐  
> **기준 버전:** Unreal Engine 5.8 (2026년 11월 기준)

## 1. Chaos Physics은 무엇인가요?

게임 속 물체가 중력에 따라 떨어지고 서로 충돌하는 기능이 물리 시뮬레이션입니다. Chaos는 이를 처리하는 기반 시스템이며, **Chaos Destruction**은 물체가 여러 조각으로 부서지는 연출에 사용합니다.

물체의 낙하 같은 일반 물리와 벽이 조각으로 부서지는 파괴 시뮬레이션을 구현할 수 있습니다. 파괴는 메시를 분할하는 작업과 실제 충돌·파괴 조건 설정이 함께 필요합니다.

### 알아두면 쉬운 용어

- **Geometry Collection:** 파괴할 물체의 조각과 물리 구조를 저장하는 에셋
- **Fracture:** 메시를 여러 조각으로 나누는 작업

## 2. 어떻게 활용할 수 있나요?

대표적으로 **건물 파괴·자동차·물체 충돌·래그돌** 같은 작업에 활용됩니다.

캐릭터가 돌 기둥을 공격했을 때 여러 조각이 떨어지고 바닥에 부딪히는 장면을 만들 수 있습니다.

## 4. 언리얼 엔진에서 직접 만들어 보기

**이번에 만들 결과:** 벽이 부서지고 파편이 흩어짐.

**준비물:** Epic Games Launcher, Unreal Engine 5.8, 저장 공간이 충분한 테스트 프로젝트, 기술에 맞는 기본 메시 또는 샘플 에셋.

### 단계별 진행

1. 새 레벨에 바닥과 큐브를 놓고 큐브의 **Simulate Physics**를 활성화해 먼저 낙하 실험을 해 봅니다.
2. 큐브를 다시 선택하고 파괴할 오브젝트를 Static Mesh로 준비합니다.
3. 에디터 상단 **Modes → Fracture** 모드를 엽니다. 보이지 않으면 플러그인과 관련 메뉴를 검색합니다.
4. 대상 메시를 선택해 **New Geometry Collection**을 생성합니다.
5. Fracture 모드에서 **Uniform Fracture**와 같은 분할 도구를 사용해 적당한 수의 조각으로 쪼갭니다.
6. 조각이 너무 작아지지 않게 분할 수를 낮춰 실험합니다.
7. Geometry Collection을 레벨에 놓고 물리 및 충돌 옵션을 점검합니다.
8. 게임 실행 중 다른 물체나 충돌을 통해 파괴되는지 확인합니다. 필요하면 Field System 등으로 파괴를 유도합니다.
9. 충돌 전후 화면과 Fracture 편집 화면을 각각 캡처합니다.

### 진행 중 무엇이 달라지는지 확인해 보세요

분할 전의 온전한 물체, Fracture 모드의 조각 구조, 실제 충돌 뒤 흩어진 파편을 차례로 비교합니다.

## 5. 완성 결과 확인하기

다음 항목을 확인하면 **Chaos Physics**이 제대로 적용됐는지 판단하는 데 도움이 됩니다.

- [ ] Static Mesh가 Geometry Collection으로 변환됐는가?
- [ ] Fracture에서 여러 조각이 보이는가?
- [ ] 게임 모드에서 충돌/필드에 의해 파괴가 발생하는가?

## 6. 자주 막히는 부분과 해결 방법

**Q. 조각을 냈는데 부서지지 않아요**

Geometry Collection의 클러스터 결합·파괴 임계값·필드·충돌을 확인합니다.

**Q. 조각이 바닥을 뚫어요**

충돌 형상과 물리 설정을 점검합니다.

**Q. 파편 때문에 느려요**

분할 수와 파편 충돌 비용을 줄입니다.

## 8. 마지막으로 알아둘 점

분할만 했다고 반드시 즉시 부서지지는 않습니다. **충돌 강도·클러스터 결합·필드·물리 시뮬레이션** 조건이 맞아야 파괴가 발생합니다. 파편이 많으면 성능 비용이 커집니다.

정리하면 **Chaos Physics**은(는) 충돌·낙하·파괴 같은 물리 현상을 시뮬레이션 기술입니다. 처음에는 모든 옵션을 이해하려고 하기보다 하나의 작은 장면에서 변화를 확인하는 것이 중요합니다.
