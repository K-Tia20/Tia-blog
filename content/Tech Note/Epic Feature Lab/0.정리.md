언리얼 기능을 하나씩 써 보면서, 실제로 어디에 쓰는 도구인지 정리했다.
이름이 많아 헷갈릴 때는 이렇게 나누면 편하다.

## 사람과 움직임

| 기능 | 쉽게 말하면 |
|---|---|
| 메타휴먼 제작 · MetaHuman Creator | 얼굴과 체형을 조절해 디지털 인물을 만든다. |
| 메시 투 메타휴먼 · Mesh to MetaHuman | 준비한 입체 형태를 메타휴먼 제작에 활용한다. |
| 메타휴먼 애니메이터 · MetaHuman Animator | 음성이나 촬영 자료에서 얼굴 연기를 만든다. AI 음성도 입력으로 쓸 수 있다. |
| 컨트롤 리그 · Control Rig | 캐릭터의 팔·다리·표정을 직접 조절한다. |
| 스켈레탈 에디터 · Skeletal Editor | 입체 모델 안에 움직임의 기준이 되는 뼈대를 만든다. |
| 직접 메시 조작 · Direct Mesh Controls | 모델의 모양을 직접 잡아 변형한다. |
| 컨트롤 리그 피직스 · Control Rig Physics | 리그에 물리 반응을 연결한다. |
| 컨트롤 리그 다이내믹스 · Control Rig Dynamics | 움직임에 따라 흔들리는 부분을 만든다. |
| 게임 애니메이션 샘플 · GASP | 자연스러운 캐릭터 이동을 배우는 에픽 공식 샘플이다. |
| 모션 매칭 · Motion Matching | 지금 이동 상황에 어울리는 동작을 골라 준다. |
| 무버 · Mover | 캐릭터가 실제로 이동하는 규칙을 다룬다. |
| 언리얼 애니메이션 프레임워크 · UAF | 여러 애니메이션 계산을 연결해 실행한다. |
| 애님젠 · AnimGen | 학습한 자료를 활용해 동작을 생성하거나 제어한다. |
| 뮤터블 · Mutable | 의상과 외형을 조합해 캐릭터 모습을 바꾼다. |
| 메타휴먼 군중 · MetaHuman Crowds | 여러 디지털 인물을 함께 구성한다. |
| 매스 · Mass | 많은 개체의 상태와 행동을 묶어서 처리한다. |
| 카오스 클로스 · Chaos Cloth | 망토나 옷이 움직임과 바람에 반응하게 한다. |
| 데이터플로 · Dataflow | 메시나 옷을 만드는 처리 단계를 연결한다. |

## 배경과 화면

| 기능 | 쉽게 말하면 |
|---|---|
| 절차적 배치 · PCG | 규칙에 따라 나무·돌·배경을 배치한다. |
| 메시 터레인 · Mesh Terrain | 동굴이나 돌출부가 있는 입체 지형을 만든다. |
| 식생 제작 · PVE | 식물의 형태와 변형을 절차적으로 제작한다. |
| 나나이트 식생 · Nanite Foliage | 복잡한 식생을 효율적으로 표시한다. |
| 메가플랜츠 · Megaplants | 배경 제작에 활용하는 고품질 식물 에셋이다. |
| 메가라이츠 · MegaLights | 많은 동적 조명을 다루는 기능이다. |
| 루멘 라이트 · Lumen Lite | 이번 연구에서 확인한 가벼운 간접광 처리 경로다. |
| 서브스트레이트 · Substrate | 여러 표면 특성을 조합해 재질을 만든다. |
| 툰 셰이더 · Toon Shader | 명암과 색을 단순화한 만화풍 재질을 만든다. |

## 제작을 돕는 도구

| 기능                             | 쉽게 말하면                      |
| ------------------------------ | --------------------------- |
| 언리얼 MCP · Unreal MCP           | AI 도구와 언리얼 작업을 연결한다.        |

| 모캡 매니저 · Mocap Manager         | 촬영 세션·대상·테이크를 관리한다.         |

| 팹 · Fab                        | 에셋을 찾아 프로젝트에 가져오고 출처를 관리한다. |
