### 설정 방법

1. Edit → Editor Preferences
2. 검색창에 Asset Editor Open Location 입력
3. General → Appearance에서 Asset Editor Open Location을 찾습니다.
4. 값을 다음 중 하나로 변경합니다.

- **Main Window** ⭐ 추천
    - 블루프린트를 열면 새 창이 아니라 메인 에디터 안에 탭으로 열립니다.
- Last Docked Window
    - 마지막으로 도킹했던 위치에 계속 탭으로 열립니다.

보통 Main Window로 설정하면 원하는 동작입니다.
