### 오늘 한일

언리얼 엔진 환경 에셋 가져오기 및 블루프린트 변환

---

## 1. Fab 에셋을 기존 프로젝트로 가져오기

- Fab에서 구매한 에셋이 새 프로젝트에 설치되어도 기존 프로젝트로 가져올 수 있다.
    
- `Asset Actions → Migrate`를 사용하면 에셋과 의존 파일을 함께 복사할 수 있다.
    
- 파일 충돌이나 기존 프로젝트 손상에 대비해 백업하는 것이 안전하다.
    

## 2. 환경 에셋 종류와 역할

| 에셋                            | 역할                             |
| ----------------------------- | ------------------------------ |
| Static Mesh                   | 나무, 바위, 건물 등 3D 모델             |
| Material / Texture            | 모델의 표면 재질과 이미지                 |
| PCG Graph                     | 나무, 풀, 바위 등의 자동 배치             |
| Landscape Layer               | 지형의 흙, 풀, 바위 영역 구분             |
| Landscape Grass Type (LGT)    | 지형에 풀 등을 자동 생성                 |
| Runtime Virtual Texture (RVT) | 지형과 오브젝트의 재질을 자연스럽게 혼합         |
| Static Mesh Foliage           | 식생을 대량 배치하기 위한 설정              |
| BPC_CharacterInteraction      | 캐릭터 상호작용용 블루프린트 컴포넌트일 가능성      |
| SplineMeshItem                | 스플라인 메시 배치 관련 데이터 구조체일 가능성     |
| BS_GoboldLocomotion           | 캐릭터 이동 애니메이션용 1D 블렌드 스페이스일 가능성 |
| NPC_Environment               | 나이아가라 환경 파라미터 관련 에셋일 가능성       |

## 3. 레벨과 레이어의 차이

- **Level:** 게임 월드 공간. 하나의 레벨에 건물, 나무, 바위 등을 모두 배치할 수 있다.
    
- **Landscape Layer:** 지형에서 흙, 잔디, 바위 등의 표면을 구분한다.
    
- **Landscape Grass Type:** 지형에 풀 등의 식생을 자동 생성한다.
    
- **PCG:** 규칙에 따라 오브젝트를 자동 배치한다.
    

기존 레벨에서 환경 에셋을 직접 배치한다면 PCG나 Landscape 관련 에셋은 당장 필요하지 않을 수 있다. 다만 다른 에셋의 의존 파일이라면 함께 가져와야 한다.

## 4. 여러 메시로 구성된 건물 200개를 하나의 블루프린트로 묶기

건물의 메시를 하나씩 추가할 필요 없이, 선택한 액터를 한 번에 블루프린트로 변환할 수 있다.

1. **건물 조각 선택:** 월드 아웃라이너에서 건물에 해당하는 액터 200개를 다중 선택한다.
    
2. **변환 메뉴 열기:** 에디터 상단 툴바의 `Blueprints` 드롭다운에서 `Convert Selection to Blueprint Class`를 선택한다.
    
3. **변환 방식 선택:** 변환 창에서 `Harvest Components`를 선택하고 부모 클래스를 `Actor`로 지정한다.
    
4. **저장:** `Content/Buildings` 폴더 등에 `BP_Building`이라는 이름으로 저장한다.
    
5. **재사용:** 다른 레벨에서 저장된 블루프린트를 배치해 건물 전체를 재사용한다.
    

- **블루프린트:** 여러 메시를 구성 요소로 유지하면서 하나의 액터처럼 관리한다.
    
- **Merge Actors:** 여러 스태틱 메시를 하나의 스태틱 메시로 병합한다.
    

변환 전에는 레벨을 저장하고 백업한다. 변환 과정에서 기존 액터가 대체될 수 있으므로 결과를 확인한다.

## 오늘의 핵심

사용할 메시와 머티리얼을 우선 가져오고, 필요한 기능의 의존 파일을 함께 가져온다. 여러 메시로 구성된 건물은 블루프린트로 묶어 재사용할 수 있다.
