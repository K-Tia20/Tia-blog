오늘 한일

  • WBP_Ammo의 현재 탄약/최대 탄약 표시 UI 구현
  • WBP_HUD.UpdateAmmoUI 이벤트와 UI_Ammo 자식 위젯 연결
  • 탄약 자릿수가 변경되어도 / 위치가 움직이지 않도록 정렬 수정
  • 히트마커 UI 이벤트와 애니메이션 연결 구조 점검
  • 다음 HUD 갱신 이벤트 구현
    • UpdateDashCooldownUI
    • UpdateGrenadeCountUI
    • UpdateWeaponNameUI
  • UI_ItemNotification 아이템 획득 알림 구현
  • 아이템 이름과 획득 개수를 {ItemName} x{Amount} 형식으로 표시
  • 아이템 알림이 3초 후 자동으로 사라지도록 처리
  • UI와 캐릭터, 게임매니저 코드 사이의 담당 범위 정리

문제

  • 게임 시작 시 탄약 숫자가 나오지 않고 /만 표시됐다.
  • 탄약이 10에서 9처럼 한 자리로 줄어들 때 숫자가 잘못된 방향으로 정렬됐다.
  • 현재 탄약과 최대 탄약의 자릿수가 달라지면 / 위치가 움직였다.
  • 히트마커 위젯과 애니메이션은 존재하지만 몬스터 명중 시 표시되지 않았다.
  • 대시 쿨다운, 수류탄 개수, 무기 이름 자식 UI는 있었지만 실제 값과 연결되지 않았다.
  • 아이템 알림 위젯은 HUD에 배치되어 있었지만 알림을 표시하는 이벤트가 없었다.
  • 아이템 알림을 숨길 때 웨이브와 타이머 UI까지 같이 사라졌다.

오류

  • WBP_HUD에 UpdateAmmoUI 이벤트가 없어서 C++ 호출을 받지 못했다.
  • Txt_CurrentAmmo의 자동 크기와 왼쪽 정렬 때문에 숫자가 감소할 때 위치가 앞으로 이동했다.
  • 히트마커 애니메이션은 구현되어 있었지만 C++ 명중 처리에서 실행 이벤트를 호출하지 않았다.
  • UpdateGrenadeCountUI와 UpdateDashCooldownUI는 PlayerController에만 있고 실제 캐릭터 코드에서 호출되지 않았다.
  • 아이템 알림 이벤트 이름을 ShowNotification으로 만들어 C++의 ShowItemNotification 호출과 일치하지 않았다.
  • 두 개의 Set Text를 연속으로 사용하여 아이템 이름이 수량으로 덮어써지는 문제가 있었다.
  • Set Visibility의 Target을 전체 HUD 컨테이너로 지정해 다른 HUD 요소도 함께 숨겨졌다.

원인

  • C++에서는 함수 이름을 문자열로 찾아 블루프린트 이벤트를 호출하기 때문에 이름이 정확히 일치해야 했다.
  • 자식 위젯과 TextBlock을 생성한 것만으로는 값이 자동으로 갱신되지 않았다.
  • 게임 시작 시 탄약 UI를 초기화하는 호출이 없고, 첫 발을 발사한 뒤에야 UpdateAmmoUI가 호출됐다.
  • TextBlock의 Auto Size와 Justification 설정 때문에 숫자 자릿수에 따라 위젯 크기와 위치가 바뀌었다.
  • 히트마커는 UI 내부 연결은 되어 있었지만 캐릭터 명중 판정에서 PlayerController로 신호를 보내지 않았다.
  • 수류탄은 개수 감소 후 UI 갱신 호출이 없었고, 대시 컴포넌트는 기능 자체가 아직 구현되지 않은 상태였다.
  • 아이템 알림의 Visibility Target을 알림 TextBlock이 아닌 상위 HUD 패널로 잘못 지정했다.

해결

  • WBP_HUD에 다음 이벤트를 C++ 함수와 같은 이름으로 생성했다.
    • UpdateAmmoUI
    • UpdateDashCooldownUI
    • UpdateGrenadeCountUI
    • UpdateWeaponNameUI
    • ShowItemNotification
  • UI_Ammo의 Txt_CurrentAmmo, Txt_MaxAmmo를 각각 Set Text와 연결했다.
  • 탄약 UI를 Canvas Panel에 분리 배치하고 다음과 같이 설정했다.
    • 현재 탄약: 고정 너비, 오른쪽 정렬
    • /: 고정 위치
    • 최대 탄약: 고정 너비, 왼쪽 정렬
  • TextBlock의 Auto Size를 끄고 자릿수가 바뀌어도 정렬 기준이 유지되도록 수정했다.
  • 히트마커 UI 흐름을 다음과 같이 구성했다.
WBP_HUD.PlayHitMarkerAnim
→ WBP_HitMarker.PlayAnim
→ Anim_HitMarker 재생
  • 히트마커가 실제로 작동하려면 캐릭터 담당자가 몬스터 명중 후 ShowHitMarker()를 호출해야 한다는 점을 확인했다.
  • 수류탄, 무기 이름, 대시 쿨다운 값을 각각 자식 위젯 TextBlock에 연결했다.
  • 대시 쿨다운은 Float 값을 Ceil 처리하여 3 → 2 → 1 → 0 형식으로 표시하도록 구성했다.
  • 아이템 알림은 하나의 Format Text를 사용해 다음 형식으로 합쳤다.
{ItemName} x{Amount}
  • 알림 표시 흐름을 다음과 같이 구성했다.
ShowItemNotification
→ 알림 Text 설정
→ Visibility: Visible
→ Retriggerable Delay 3초
→ Visibility: Hidden
  • Visibility Target을 Txt_Notification으로 한정하여 웨이브와 타이머가 함께 사라지는 문제를 해결했다.
  • UI 담당은 이벤트와 화면 표시를 구현하고, 캐릭터 담당은 실제 값 변경 시 PlayerController 함수를 호출하도록 역할을 구분했다.
